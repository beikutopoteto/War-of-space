# ユーザーが決めた仕様

ユーザーが決めた仕様の一覧。勝手に変えない。変わったら日付つきでここを直す。
戦闘や画面の動きを変える前に、このファイルを読む。細かい操作と仮の数値は `docs/menu.md`。

- **見た目:** 戦況図風。中央に要塞小惑星、同心円のグリッド、陣営アイコン、太い進軍矢印、時刻と解説パネルを置く。版権の名前は使わない。
  - 自軍は「地球連合」（青）、敵は「惑星共和国（アストラルリパブリック）」（赤）。要塞は「カリュブディス」。設定は `docs/story.md`。
- **3D の意味:** モデルではなく戦闘空間が 3D で、上下にも自由に動ける。
  - 操作は「タップで選ぶ → タップで移動」のまま、高度は左の高度バーか Q/E で指定する。高度バーの ▲▼ は 0 から上下に15ずつの段へ動く。バーのドラッグと Q/E は自由に動かせる（ユーザー決定 2026-10-03）。
  - 射程と距離は 3D で測る。
  - 艦隊ごとに「自動交戦」か「命令優先」を選べる（2026-10-02 に「交戦/回避」から変更）。自動交戦は射程内の敵を撃ち、母艦は近い敵に小型機を出す。命令優先は攻撃を命じた敵だけを撃ち、母艦も命じた敵にだけ小型機を出す。どちらでも攻撃を命じた敵を優先する。高度バーの下で切り替え、その横に「戻す」（一つ前の指示の取り消し）を置く。右下の艦隊一覧でも、各隊ごとと戦区軍の全軍まとめて切り替えられる。戦区軍の速度同期もそこで切り替える（ユーザー決定 2026-10-02）。
  - 後退（ユーザー決定 2026-10-17 夜。全部の作戦、敵・友軍・自軍とも。空母系も同じ）: 命令なしで戦っているとき、自分が相手の射程を上回っていれば、向きを変えず（艦首を相手に向けたまま）方向だけ後ろへ下がる。速さは半分、攻撃は100%（足止めしながら下がる）。艦の後ろ方向（艦首から90度より後ろ）への攻撃は前への25%で、撤退（全速で離れる）のときは速さ100%・攻撃25%になる。射程で上回っていない隊は、寄られても下がらずその場で撃ち合う。数値（半分、25%、90度）は仮で `docs/menu.md` に記録する。
  - 移動の矢印は勝手に曲げない。矢印は実際の航路と同じ。予約指示（経由地）を足すと、A→B→C を自然な曲線でつないで進む。敵への攻撃も予約できる（ユーザー決定 2026-10-02）。
  - 敵部隊をクリックしたら「その地点へ移動」か「その敵を攻撃」かを選べる（敵の真上や真下へも移動できる）。敵を追っている間の矢印は敵を追尾する。
- **戦闘の長さと規模（ユーザー決定 2026-10-12）:** 1倍速で、簡単な作戦は5〜10分、大きめの戦いは15〜20分。
  - 遅くするのは作戦の時計だけ。艦の速さ・撃ち合い・小型機は今のまま。空いた時間は敵の波や出来事を足して埋める。
  - 規模は4つ: 小規模 5〜10分、中規模 9〜15分（2026-10-13 に10〜15分から）、大規模 15〜20分、特大規模 20分〜。作戦ごとに指定し、時計の速さがその長さに合う。出撃画面に規模と目安の長さを出す。目安の長さは、`pace` で縮めた実際の長さで出す（ユーザー決定 2026-10-15。例: 第1節は「小規模（目安 2〜4分）」）。
  - 第1節と第2節は、敵の量を変えずに1倍速の長さを75%にする（ユーザー決定 2026-10-13。作戦データの `pace:.75`。第2節は航路も75%に縮める）。
  - 第1〜3節は、さらに今の半分ぐらいにする（ユーザー決定 2026-10-14: 全体に長く、内容が淡白。時計を速め、敵の量は変えない）。第1節は `pace:.375`、第3節は `pace:.5`。第2節も `pace:.375` で、航路を約1,125 に短くし、易しくもする（`docs/campaign.md`「第2節」）。
  - 第2節のプラズマ雲は戦場一面にばら撒き、航路は雲から雲へ曲がりくねる（ユーザー決定 2026-10-14: 航路の上だけに雲があるのはご都合すぎる）。
  - 第1節と第2節は、敵（艦と小型機）の耐久を0.9倍にしていた（2026-10-15）。2026-10-20 に外した（下の「両陣営の技術と強さ」）。
  - 規模で出撃の上限（出撃できる艦の合計）を制限する（数は仮。`docs/menu.md`）。
  - 割り当て: 小＝第1節 ネオ信濃奇襲・演習 カリュブディス、中＝第2節 後退・第3節 ナイル防衛線、大＝第4節 デナリの盾・第5節 フェブルアーリア防衛戦。
  - 第5節の長さの目標は10〜15分（ユーザー決定 2026-10-20。大規模の15〜20分から変更）。難しさは敵の数ではなく仕組みで合わせる（同じ日。案はストラテジーとバランスの専門家に出させ、ユーザーが選ぶ）。総攻撃では、地球の戦艦（ウォン中将の隊と前線の戦艦すべて）が前へ出て戦線を押し上げ、シールド（ゲート）へ向かう敵を受ける。1か所に重なるのは2隊まで（ユーザー決定 2026-10-20）。目安は「何もしないとゲートを失って負け、正しく動けば守り切る」。負けは守備隊が尽きたときだけ（駐屯隊の全滅では負けない）。ゲートのシールドは半分に（2026-10-21、ユーザー決定）。後半に友軍が棒立ちにならないように（ユーザー決定 2026-10-20）: 方面の戦線が崩れて残った友軍の隊は、一部が戦線を下げて守り、ほかはゲートの守りに回る。ゲートが残り一つになったら、友軍すべてを下げてそのゲートのまわりで守らせる（ここでも1か所に2隊まで）。東西のゲートには最初から守備の艦隊を置く（東翼から回す: 東ゲートに第12 護衛、西ゲートに第22 護衛）。分け方と数は `docs/campaign.md`「第5節」と `docs/menu.md`「友軍 AI」（仮）。
  - 第5節のバランス調節は 2026-10-21 に終わり（ユーザー）。押されている方面の印は任務欄のゲートの欄に、琥珀色の枠と山形（1つ＝押されている、2つ＝崩れかけ。文字なし。見本の案 A、ユーザー決定 2026-10-21）。総攻撃が主力の撃沈で早く来る動きは変えず、そのときだけソコロワ参謀大佐の傍受を「損害が見込みを超えた」にして台詞を合わせる（ユーザー決定 2026-10-21）。
- **釣り合い（ユーザー決定 2026-10-13）:**
  - 敵味方とも耐久2倍。全艦隊（敵・友軍・自軍・船団・ユーコン・砲台）、艦載機と W.A.S.、要塞とステーション。作戦ごとに変えられ、第2節は1.5倍（2026-10-20 に外すと決めた。下の「両陣営の技術と強さ」）。民間の被害の人数換算は倍率で割り、第4節の物語の約5,000人を保つ。第4節の本軍の戦艦と巡洋艦はデータを半分にする（戦闘では前と同じ。第5節の艦は修理中で装甲が十分でない、という説明）。
  - 倍率は作戦のあいだでそろえる（ユーザー決定 2026-10-19）: 第5節の耐久の倍率は第4節と同じ2（前は18と敵だけ3倍）。艦種ごとの倍率は使わず、データの値（地のステータス）に書く。作戦ごとの敵だけの倍率は頼まれたときだけ（第5節の敵の打撃2倍 `enemyDmg`、第1・2節の敵の耐久0.9倍）。硬さと長さは地のステータス（敵の数・耐久・打撃）で合わせる。2026-10-20 に、作戦ごとの倍率はすべて外すと決めた（次の「両陣営の技術と強さ」）。
  - 何もしないと確実に負ける。演習は 17:00 で時間切れの負け。第4節は 12:00 までにユーコンが着陸していなければ負け。第5節は護衛の重巡洋艦が地表の砲台を先に狙い、放っておくと砲台が沈み、揚陸艦の W.A.S. と揚陸艇の強化歩兵に基地守備隊を削られる（2026-10-18）。負けの理由は通信と結果の文で伝える。

  - 第2節の第16 追跡は 07:00 ごろに出す。第3節の第20・第21 突撃揚陸は W.A.S. を10に。出る時刻は右翼の突破と±15分にそろえる（2026-10-14。2026-10-13 の「40分・80分遅らせる」から変更。分は `docs/menu.md`「釣り合い」）。避難が90%になると小さな波を1つ。

- **両陣営の技術と強さ（ユーザー決定 2026-10-20。入れた。データは `data/ships.js` の `WOS_DATA.sides` と作戦の `stage`）:**
  - ユニットの性能の倍率は、作戦（節）ごとに変えない。全作戦に同じだけ掛かるもの（耐久2倍）はよい。今の作戦ごとの倍率（第1・2節の敵の耐久0.9倍、第2節の耐久1.5倍、第5節の敵の打撃2倍）はすべて外し、各節の難しさは敵の数・編成・布陣・時刻・目標・地形（砲台、シールド）で合わせ直す。
  - 例外は2つだけ: 演習（模擬戦なので値が違ってよい。要塞カリュブディスの耐久3倍・火力半分）と、物語の中の状態（修理中・損傷。倍率ではなく、最初から耐久が減っている形で見せる）。
  - 敵と味方の1隻の強さの差は、技術の差だけから来る。数・戦い方（ドクトリン）・地形はそれとは別の軸。
  - 艦種の性能は陣営ごとに違う。地球連合と惑星共和国それぞれに艦種の表（研究前の値と、研究しきった値）を持つ。研究前の値も研究しきった値も陣営で違う。地球は数が多く、火星は質が上。火星の表は、ドクトリン（`docs/story.md` 6.1）に合わせて艦種ごとに得意を変え、全体では地球より上にする。
  - 艦種の表（ユーザー決定 2026-10-20。数値は仮）: 研究前の値は地球が最大の3割（今の自軍と同じ）、火星が4.5割。地球の最大は `data/ships.js` の値。火星の最大（打撃/防御/回避/射程/速さ）はコルベット 3/1.5/10/3/11、フリゲート 4/2.5/8/4/9、駆逐艦 6/3.5/7/5/8、重巡洋艦 8/7/4/6.5/6、突撃揚陸艦 6/3/6/2.5/8。火星に戦艦と母艦はなく、鹵獲した戦艦は地球の表を使う。1隻の強さ（耐久×打撃）は、巡洋艦で開戦のとき火星が2.4倍、研究しきった同士で1.5倍（戦争が長引くほど差が縮む）。
  - W.A.S. の表（ユーザー決定 2026-10-20）: 火星の最大は地球の1.5倍（耐久15・打撃1.0・回避0.55。速さと射程は同じ）。研究前は4.5割。共和国の突撃揚陸艦は1隻に W.A.S. 8機を積む（揚陸艦そのものの性能。全部の作戦。2026-10-21 ユーザー決定）。
  - 表の外（ユーザー決定 2026-10-20）: 研究で強くならないものは表の外。作戦の目標になる特別な艦（第4節のユーコン）、揚陸艇、地形（砲台・ゲート）、民間の船（輸送船・避難船）、要塞とステーション。これらは作戦データに書いた値のまま。表を使うのは戦う艦隊（敵・友軍・自分の決まった艦隊）だけ。
  - 相手にも同じような技術ツリーがあり、作戦が進むと研究が進む。技術の段階は節ごとに決め、両陣営でそろえる。段階は、その節までの報酬で研究できる量（想定する自軍の研究の度合い。最大までのどこまでか）。第1・2節 0、第3節 0.15、第4節 0.25、第5節 0.35（ユーザー決定 2026-10-20。2つの兵科を研究した見積もり。1つに絞ると第5節で約0.5）。各節はこの段階の自軍で「正しく動けば勝てる」に合わせる（第4節の「研究をすべて終えた自軍で合わせる」から変更）。友軍は地球の表のその段階、敵は火星の表のその段階。敵の研究はプレイヤーの研究に合わせない。プレイヤーの艦隊は自分の研究の分なので、想定より研究していれば楽に、少なければ苦しくなる。
  - 速さ（ユーザー決定 2026-10-20）: 敵と友軍の速さは段階に関係なく、その陣営の表の研究しきった値（2026-10-12 の「艦の速さは今のまま」を保つ）。そのうえで両軍の艦はすべて少し速くする（1.2倍、仮。`WOS_DATA.balance.speed`。自分で編成した艦隊も。輸送船と砲台は除く）。
  - 精鋭: 惑星先進装備開発局に所属し、試製の装備と乗員の腕の両方で強い（アルバレス隊。名前は「第7・第8 試験強襲 エスカドラ」、説明は「惑星先進装備開発局 アルバレス隊」。2026-10-21 ユーザー決定）。第5節では2隊とも前線で艦を狩る（同じ日）。艦も W.A.S. も、すべての能力がその段階の火星の値の1.25倍。W.A.S. の打撃だけは3倍（ユーザー決定 2026-10-20。前の3倍・1.2倍・1.5倍から変えた）。

- **画面:** 戦場を隠すポップアップや説明パネルを嫌う。UI は小さく半透明で、たためるようにする。
  - パネルは H、名札は L で消せる。
  - 戦闘中は Esc か左上の「メニュー」でいつでもメニューを開く（続ける・やり直す・やめる・操作の一覧）。開いている間は止まり、やめると敗北になる。「戻す」（Ctrl+Z / Backspace）で一つ前の指示を取り消す（ユーザー決定 2026-10-02。左上へ移したのは 2026-10-03）。
  - 任務欄（いまやることとゲージ）は左上の時計の下に置く（ユーザー決定 2026-10-03）。
  - 視点は3つのボタン（斜め/真上/真横）を並べた押し分け式で、押したボタンの色が変わる。V で順に切り替える。視点のボタンは縦の角度だけを変え、横の角度は変えない。
  - 横回転と上下の角度は、画面の下に分けて置いた2本のスティック（倒している間回り続け、離すと戻る）と十字キーで変える。WASD は平行移動（ユーザー決定 2026-10-03）。
- **オプション（ユーザー決定 2026-10-08）:** メニューの一番下に「オプション」（ほかのゲームの設定画面にあたる）。「ストーリー」のオン／オフを置き、デフォルトはオフ。オフのときは作戦の前・勝利後・敗北後の会話をすべて出さず、すぐ配置や結果へ進む（作戦概要と任務欄は出す）。会話は Ctrl 長押しで早送りできる。
- **メニューと進行（ユーザー決定 2026-10-03）:** 第一章第2節をクリアすると「艦隊編集」（編成画面）と「技術ツリー」が開く。それまではメニューに鍵付きで並び、解放の条件を出す（隠さない）。メニューには DEBUG 欄（自由に選ぶ、戦闘中の即勝利・即敗北、一節だけクリア、全作戦クリア、資金、全兵科解放、全研究、進行のリセット（艦隊も戻す））を置く。全作戦クリアでは兵科は巡洋艦まで。戦艦・母艦・W.A.S. 部隊は全研究で出る。
- **技術ツリー（ユーザー決定 2026-10-03）:**
  - 艦種と小型機の能力値（`data/ships.js`）は、研究を終えた最終形態（最大）。自分で編成した艦隊は最大の3割から始まり、研究で上がる。自分の編成でない艦隊（ストーリーの決まった艦隊、友軍、クイック出撃）と敵には効かない。敵も最初は弱く、作戦が進むと強くなる（2026-10-20: 友軍と敵は節ごとの技術の段階で決める。上の「両陣営の技術と強さ」）。
  - 上に「宇宙軍」「地上軍」のタブ（地上軍は将来）。左の細い縦の欄で兵科を選ぶ。未解放の兵科は出さない（今は巡洋艦まで）。
  - 右は、どの研究も〇とアイコンで、始まりが複数あり、相互につながる樹形図。横スクロール。研究の上がり幅と前提の研究は、〇を押すと下の欄に出る。
  - 能力は百分率でなく数で出す。強化の上限（最大の値）は見せない。

  - 燃料があるので帰還が必要。
  - 帰還すると、失った数の半分を予備から補充する。予備がなければ増えない。例: 1隊30機×3隊、収容120。
  - 艦載機は W.A.S. より射程が長い。
  - 艦載機は W.A.S. より当たりやすい（ユーザー決定 2026-10-03）。今の当たりやすさが研究を終えた最終形態で、研究前は艦の対空照準が低く、小型機にかなり当たらない。
  - 小型機は相手側の要塞を自分からは狙わず、母艦が要塞の射程の外なら外の敵、内なら内の敵だけを狙う。母艦に攻撃を命じた相手は優先し、母艦を移動させても、倒れるか別の攻撃を命じるまで狙い続ける。敵も同じ（ユーザー決定 2026-10-02）。
  - 空母系だけの打撃群は、攻撃のとき敵が発進距離（短いほう）の0.8倍に入ったら止まる。混ざった打撃群は艦砲の射程で止まり、空母系は隊形の最後尾に並ぶ（ユーザー決定 2026-10-02）。
  - 艦砲は、攻撃を命じた敵が射程内なら優先して撃つ（ユーザー決定 2026-10-02）。
  - 小型機は、敵の小型機を見つけたら艦より先に狙い、お互いの小型機がぶつかる所が前線になる。敵の小型機が攻めてくると、自分の母艦に近いものから迎え撃つ（前線が下がる）。母艦に攻撃を命じた相手はそれより先（ユーザー決定 2026-10-02）。
- **要塞カリュブディス（最初の要塞戦）:** 要塞から艦載機が迎撃に出る。装甲が75%を切ると第5 要塞近衛 エスカドラ、50%を切ると防空隊が全隊一斉に迎撃に出る（ユーザー決定 2026-10-02。2026-10-04 に「近い隊から順に」から変更）。要塞を壊すと近衛艦隊は北の本国航路へ撤退を始め、任務は「近衛艦隊の撤退を阻止せよ」に変わる。ほかの敵艦隊は撤退を援護しようと自軍を攻撃してくる。近衛艦隊を撃破すれば完全勝利、逃げられたら普通の勝利（ユーザー決定 2026-10-04）。クイック出撃も同じ作戦なので同じ。
  - 艦載機だけの戦闘母艦は、巡洋艦以下を相手の射程に入らずに攻撃できる。艦載機が当たりやすくなったので、母艦が少し被弾するのはよい（ユーザー決定 2026-10-03。前は「一方的に」）。艦載機や W.A.S. に攻撃されている艦隊は遅くなる（ユーザー決定 2026-10-02。2026-10-04 に W.A.S. も加え、少し強めた）。空母系だけの打撃群が敵の接近に合わせて下がる動きはなくした（ユーザー決定 2026-10-04）が、2026-10-17 夜に「後退」（上の「3D の意味」）として、命令なしのときは半分の速さで下がるようにした。
