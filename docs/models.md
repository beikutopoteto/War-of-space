# 地上戦のモデルの設計方針

作成: 2026-11-12（Claude）。ユーザーが決めたことは「ユーザー決定」と書く。それ以外は Claude の考察と案で、すべて仮。
形のコードは `battle/ground-shapes.js`、見本ページは `tools/model-sheet.cjs` と `docs/mockups/models/*.json` で作る。

## 1. 決まっていること（ユーザー決定 2026-11-12）

- 作る順: 陸上の部隊 → 航空の部隊 → 地上戦のマップの艦（宇宙の艦の小さな手直し、海の上用）→ W.A.S. と強襲母艦（宇宙と地上の両方に出るので設計し直す）→ 宇宙の艦（時間があれば）。
- スタイルはローポリ（面の角が見える、少ない面の形）。
- 1つの隊は、その兵科に合った数で描く。
- 惑星共和国の車両はアルマータを元にする。少ない人数で動かすスタイル。
- 時代は今から約100年後（A.E. 45 ＝ 西暦2099年）。今の兵器より洗練され、進化した形にする。
- 宇宙のモデルは小さめに作ってあるので、地上用に大きくしてよい。
- 歩兵は背丈2mほど。外の強化外骨格を強調する。人体は人体図の比率で作る。
- 重強化歩兵は少し大きく見える。装甲は全身。脚は内側にも外骨格。背中に対装甲のマルチランチャー。大口径の速射砲を、ミニガンのように腰だめで構える。
- W.A.S. は4〜5m。
- 2章の考察に沿って全モデルを作る。装甲兵員輸送車の砲塔は真ん中でなくてよい。惑星共和国の戦車は少し小さくてよい。惑星共和国の自走砲は砲身が長いのがよい。
- 歩兵の姿勢は、重心を少し落とした歩き方にする（強化歩兵も重強化歩兵も）。移動中は小銃を胸の前に持って歩く形、戦闘中は腰を落として構える形。重強化歩兵の構え方（腰だめ）はそのまま。
- 航空機はもっと個性的でよい。広域戦略支援航空機は大型爆撃機と早期警戒機を元にする。設定上レーダーは使えないので、レーダーの皿は付けない。
- 参考の写真は見るだけにする。リポジトリには入れない（公開リポジトリのため）。写真の形をそのまま写さず、考え方だけを取る。

## 2. 両陣営の背景から見た、100年後の兵器のスタイル（考察）

根拠は `docs/story.md` の年表（2）、勢力（6）、両軍のドクトリン（6.1）。

### 2.1 地球連合: 「人が乗り、人が決める」重い兵器

- **成り立ち**: 2050年の核の誤射のあとに、各国の軍を束ねて作った軍。外に敵はおらず、45年のあいだ仕事は警備と救難だった。新しい型を一から作る理由がなく、旧NATO・中国・ロシアの車両を直しながら使い続けた。
  - だから形は、今の車両の延長にある。100年ぶんの改修で、後から足した装置（銃塔、照準器、追加の装甲板）が外に見える。
- **撃つ決まり**: 「人が決めずに撃つ兵器」を禁じ、撃つには人の判断が要る（二つの鍵）。
  - だから砲塔に人が乗る。砲塔は大きく幅があり、屋根に車長の照準器と銃塔が載る。ハッチと窓がある。
- **人と重さ**: 人口が多く、乗員を惜しまない。地球の上で作って地球の上で使うので、重さの制限がゆるい。
  - だから車体は高く、装甲は厚い板を重ねた形。履帯は見え、その上に板の覆い。砲は太い。
- **歩兵**: 兵の数が多いので、歩兵が主役。強化外骨格は「着る道具」で、兵の体の外に骨組みが見える。装甲は携帯火器を防げるくらい（`docs/story.md` 4）。
- **航空**: 大気の中で100年以上飛んできた。翼で飛ぶ形の延長で、宇宙の艦載機と同じ系統に見せる。

### 2.2 惑星共和国: 「少ない人数で、宇宙から持ってくる」軽く低い兵器

- **人口**: 地球の7〜8分の1。熟練した兵が戻らないことが最大の弱み。
  - だから1両の乗員を最小にする。乗員は車体の前の装甲のカプセルにまとめ、砲塔は無人で小さい。これがアルマータの考え方と重なる。
- **宇宙から運ぶ**: 車両は火星のまわりで作り、揚陸艦で地球へ降ろす。積める重さと大きさに限りがある。
  - だから車体は低く、砲塔は細い。戦車・自走砲・重い兵員輸送車が同じ車体を使う（共通の車体。作る種類を減らす）。
- **火星の育ち**: 火星は空気が薄く、外に体を出せない。車両は気密が前提。
  - だからハッチも窓も外に見えない。外を見るのは照準器とカメラだけ。面はつながった一枚の殻で、後から足した物が少ない。
- **会社の作る兵器**: 作るのはアストラルX。宇宙機と同じ作り方で、角の少ない面を合わせた殻になる。
- **砲**: 重い装甲を持ち込めないので、先に当てて勝つ。砲は細く長い。
- **歩兵にあたるもの**: 人が少ないので、地上の主力は W.A.S.（`docs/story.md` 6.1「岩と地上」）。歩兵は拠点を押さえる最小限。
- **航空**: 火星には翼で飛ぶ伝統がない。地球の空で使う機体は、軌道から降りる機体（揚陸艇や再突入機）の延長になる。腹が平たく厚い胴、小さな翼、下向きにも向く噴射口。

### 2.3 見分け方のまとめ

| | 地球連合 | 惑星共和国 |
|---|---|---|
| 全体の印象 | 高く、厚く、足し物が多い | 低く、長く、一枚の殻 |
| 砲塔 | 人が乗る。大きく幅がある。屋根に銃塔と照準器 | 無人。細く小さい。後ろ寄り |
| 車体 | 履帯が見え、板の覆い。車種ごとに違う車体 | 覆いと一体。戦車・自走砲で共通の車体 |
| 砲 | 太い | 細く長い |
| 車輪の車両 | 背の高い箱形、側面はまっすぐ | 側面に折れ目のある舟形（気密の殻） |
| 歩兵 | 強化外骨格の歩兵が主役 | W.A.S. が主役。歩兵は少ない |
| 航空機 | 翼で飛ぶ形 | 軌道から降りる機体の形（案） |

## 3. 兵科ごとの形（案）

### 3.1 車両

| 兵科 | 地球連合 | 惑星共和国 |

| 主力戦車 | 車体より幅のある低く大きな砲塔（西側の重い戦車とロシアの戦車を合わせた形。ユーザー指示 2026-11-12）、追加装甲、荷物の棚、格子の装甲、太い砲 | 長く浅い前面の下に乗員、細い無人砲塔、とても長い砲 |
| 装甲兵員輸送車 | 8輪、上から見て四角い箱、前面は長くゆるい斜面（ユーザー指示 2026-11-12）、片側寄りの小さな銃塔 | 8輪、折れ目のある舟形、上を向く船首、平たい無人砲塔 |
| 自走砲 | 後ろ寄りの幅広い砲の家、太い砲と箱形の砲口 | 共通の車体に背の高い細い砲の家。砲はレールガン（2本の長いレールを枠でつなぐ、両わきに蓄電器。案） |
| ロケット車両 | 装輪のトラックに、起こした箱形の発射機（6連） | 共通の車体に、低く寝かせた発射筒 |
| 自走対空砲 | 戦車の車体に、両わき2門ずつの砲塔と、柱の上の光学の追尾装置（レーダーは使えない） | 共通の車体に、無人の4連の砲塔と追尾装置 |
| 斥候 | 小さな4輪の偵察車、伸びる柱の先に照準器 | 小さく低い4輪、無人の小さな砲塔 |
| 工兵 | 戦車の車体に、前の排土板と上にたたんだ橋 | 共通の車体に、たたんだ橋 |
| 補給 | 装輪のトラック、荷台にコンテナ | 装輪のトラック、気密のタンク |

残りの兵科（強化コマンド歩兵、ドローンハイブ、機械化突撃兵）と陸戦型 W.A.S. は、まだ作っていない（強化コマンド歩兵は仮に強化歩兵と同じ形）。

### 3.1b 航空機

| 兵科 | 地球連合（翼で飛ぶ、暗い風防） | 惑星共和国（軌道から降りる機体、下面に耐熱の板、風防なし） |
|---|---|---|
| 戦闘機 | 宇宙の艦載機の系統。胴と翼がつながり、外に傾いた尾翼2枚 | 矢じり形の胴、両端に外へ傾いたひれ |
| 攻撃機 | まっすぐな広い翼、胴の後ろ上にエンジン2基、尾翼の両端にひれ、機首の下に大きな砲 | 揚陸艇の系統。箱形の胴の四隅に下へ向く推進器、あごの下に砲 |
| 広域戦略支援航空機 | 大型爆撃機と早期警戒機を合わせた形。長い胴、高い翼にエンジン4基、T字の尾翼、背中に長い光学の観測装置、腹に爆弾倉 | エイの形の全翼、背中に観測の出っ張り |

### 3.2 歩兵

- **人体**: 8頭身。上から、あごが1、胸が2、へそが3、股が4（背丈の半分）、膝が5.5、足の裏が8。肩幅は頭の高さ2つぶん。肘はへその高さ、手首は股の高さ。胴は肩から腰へ細くなる。ももは膝へ細くなり、すねはふくらはぎで一度太くなる。
- **強化歩兵（背丈2m）**: 暗い色の体の外に、陣営の色の骨組み。
  - 骨組み: 足の板、脚の外側の支柱と膝・腰の関節の円盤、腰の輪、背骨と背中の動力部、肩の横木と肩の関節、腕の外側の支柱。
  - 兜は陣営の色、目の所に暗い窓。
  - 姿勢は2つ（`EXO_POSE`）: 移動中は小銃を胸の前に斜めに持って歩く。戦闘中は腰をさらに落とし、銃床を右肩に当てて構える（ユーザー決定 2026-11-12）。重強化歩兵は1つの姿勢だけ（速射砲を腰だめにして歩く形。ユーザー決定 2026-11-12）。ゲームでは動いているかどうかで切り替える（`GROUND_MODELS` の `move`）。
- **重強化歩兵（強化歩兵の1.12倍、仮）**: 全身に装甲。
  - 大きな丸い兜と広い窓、首を囲む高い襟。厚い胸と腹の板、大きな肩の板、上腕・前腕・もも・すねの板。
  - 脚の骨組みは外側と内側の両方。
  - 背中に対装甲のマルチランチャー、腰の後ろに弾倉。弾倉から砲へ弾の帯がつながる。
  - 大口径の速射砲を右の腰で構える。右手は後ろの握り、左手は上の取っ手。
- 歩兵はまだ陣営で分けていない。共和国の歩兵を分けるなら、気密服の系統（窓のない丸い兜、骨組みが殻の内側）にする案。

## 4. 作り方の決まり

- 形は前が +Z、上が +Y、長さは約2。地上のものは y=0 に立つ。
- 面は平らに塗る（1つの面に1つの向き）。色は陣営の色1つに、暗い部分（履帯・車輪・砲・窓・体）の濃淡を掛ける。
- 新しい形は、見本ページでユーザーの許可をもらってから `GROUND_MODELS` に入れる（`CLAUDE.md`「会話」）。それまでゲームの表示は変わらない。
- 確かめ方: `node tools/model-sheet.cjs --config docs/mockups/models/pilot.json --out .shots/pilot-sheet.html --shots .shots/pilot-sheet` と、`node tools/ground-model-shots.cjs --models "<差し替え>"`（実際の画面の写真）。

## 5. 決めてほしいこと

1. 2章の考察の方向でよいか（地球連合は「人が乗る重い兵器」、惑星共和国は「少人数の、気密で低い兵器」）。
2. 共和国の航空機を「軌道から降りる機体の形」にしてよいか。地球連合は翼で飛ぶ形（見本の A）。
3. 共和国の歩兵を別の形にするか（案: 気密服の系統）。それとも歩兵は両陣営で同じ形にするか。
4. 1つの隊の数（3.4）。

## 6. 次の直し（ユーザー指示 2026-11-12 13:56。見本 第5回への返事。未着手）

参考の写真は見るだけ（戦車は今の西側の重い戦車とロシアの戦車の2台）。

1. **地球連合の主力戦車**: 写真の2台を合わせたような形に、もう一度作り直す（第5回の形でもまだ足りない）。
2. **地球連合の広域戦略支援航空機**（`awE`）:
   - 機首の風防（コックピット）が胴からはみ出ている。胴の中に収める。
   - 背中の長い棒（レーダーのように見える光学の観測装置）は、機体の下へ移す。背中にはごく短いものを少しだけ残す。
3. **惑星共和国の自走対空砲**（`aaM`）: 縦に長い所（起こした4連の砲のかたまり）を縮めて、全体をコンパクトにする。
4. **車輪の車両の足回り**: 惑星共和国の装甲兵員輸送車（`apcM`）は、車輪と車体のあいだに支柱も何もなく、車輪が浮いて見えて違和感がある。車軸・懸架の部品を足す。同じ傾向のもの（装輪の車両すべて: `apcE`・`scoutE`・`scoutM`・`truckE`/`truckM` を使う `mlrsE`・`supE`・`supM`）も確かめて直す。
5. **歩兵の歩き方**: 移動中の姿勢が全員同じ足を前に出していて「かなりキモい」。隊の1人ずつ、どちらの足を前に出すかと、足を出すタイミングをランダムにする（左右の鏡像の姿勢を足し、1人ずつ別の位相で切り替える案）。
6. **重強化歩兵の腕の装甲**（追加 2026-11-12）: 上腕と前腕に装甲の板を付ける（今は腕に装甲がない）。

## 7. 隊形の案（ユーザー案 2026-11-12。Fable の作業ではなく、モデルのあとで）

地上の部隊は、4つの状態で隊形を変える。

| 状態 | いつ | 隊形 |
|---|---|---|
| 待機 | 特に命令がなく止まっているとき | ランダムにばらけ、周囲で待機する |
| 防衛 | 布陣しているとき | 今の見本の隊形（`GROUND_FORMS`） |
| 侵攻 | 布陣のあと、計画を立てて実行したとき | 防衛と同じ隊形 |
| 移動 | 移動しているとき | 一列。歩兵は2列 |

- 航空機は、ふだんは編隊飛行。戦闘中は宇宙の艦載機のように飛び回る。
- 場所を取るため、低高度・高高度の座標を今より上げてもよい。
