## 2. 新しく決まったこと（未実装）

- 射程は武器の種類ごとに増やさず、操作用は最大2枠。通常の陸軍は直接照準1枠。自走砲・地上W.A.S.は直接／間接の2枠、ロケット車両は間接のみ。
- 空中W.A.S.と空軍は対地／対空で異なる射程を持つ。
- 航空の追加方針: 戦闘機はドッグファイト中心。爆撃はユーザーの表現で「測量爆撃」。広域戦略支援航空機は目測・目視による偵察と大質量爆弾の投下を担当する。レーダーによる長距離迎撃を戦闘機の基本にしない。具体的な射程・測量爆撃の照準手順は下の仮案と区別する。
- 海軍は基本的に直接／間接を持ち、直接照準は地平線までを許容する。具体的な兵器の到達距離と地平線の計算方法は設計時に決める。
- 航空機以外の対空は自動迎撃。対空は別射程として整理する。前の提案で明示した「操作用最大2枠＋自動対空別枠」を前提とし、対空装備のない兵科へ能力を自動追加しない。航空機の対空戦闘は通常の命令対象に残す。
- 海上の駆逐艦・巡洋艦はイージス艦に統合し巡洋艦モデルを使用。コルベット・フリゲートは高速艇に統合しフリゲートモデルを使用。戦艦は大型主砲中心。宇宙軍の既存艦種は今回変更対象にしない。
- 敵が新型エンジン由来の副産物（プラズマという呼称は仮）を作戦領域に発生させ、レーダーが使用不能となる設定を追加する。地上では常にレーダーが有効という旧前提を更新する。
- 自走砲は自動装填で1発ずつ継続射撃。ロケット車両は一気に連続発射し、その後の再装填が長い。ロケット砲の役割は面制圧、射程は自走砲より少し長い50km程度。前の70km案・携行誘導兵器8km案を置き換える。
- 間接照準は遠距離ほど最小指定円を大きくする。遠い地点では円を小さく絞れず、着弾が広がる。ユーザーの「最小の輪を縮める」は精度低下の意図であり、大きくする方式と確認済み。
- 戦場を広げる方針を了承。演習場48×36kmを残し、通常作戦150×100km程度、広域作戦300×200km程度という案を基準に設計する。寸法は仮。演習を必ず拡大する決定ではない。

### 航空の追加設計（未実装）

- 戦闘機の対空射程は2kmを新たに提案。武器ごとの機関砲・ミサイル射程を増やさず、1つの近距離交戦枠へまとめる。敵を発見しただけで射撃せず、射程まで接近して旋回・追尾する。射撃方向・射撃可能角・追尾方法はこれから設計する。
- 広域戦略支援航空機の偵察は目測・目視を主とし、索敵範囲と攻撃範囲を分ける。索敵距離は未決。地形・大部隊の発見と、細かい兵科・目標の識別を同じ保証範囲にしない案。
- 爆撃はユーザーの用語「測量爆撃」を保持する。測量済みの地形・地図座標と目視を照合して投下位置を決める方式を提案するが、用語の具体的な操作・照準手順までは未確定。誘導爆弾やレーダー照準を自動で追加しない。
- 大質量爆弾を投下するには投下可能位置まで進入する。高度・速度に応じた投下可能な帯と予想着弾範囲を表示する案。既存の一律5km地点攻撃を新設計の射程として確定しない。
- 大質量爆弾の搭載数、投下回数、補給、威力、爆風、散布誤差は未決。大質量という指示だけで爆風・威力を確定しない。陸の間接砲撃の距離依存最小円と、爆撃の高度・速度による誤差は区別して設計する。
- 攻撃機・空中W.A.S.・陸軍・海軍の前案は暫定維持。射程を維持することと、レーダー不能下の観測・誘導が解決済みであることを混同しない。

参考: [豪陸軍の榴弾砲](https://www.army.gov.au/equipment/artillery/m777-155mm-lightweight-towed-howitzer)、[英国陸軍のGMLRS](https://www.army.mod.uk/learn-and-explore/equipment/artillery-and-air-defence/guided-multiple-launch-rocket-system-gmlrs/)、[米海軍の艦砲](https://www.navy.mil/Resources/Fact-Files/Display-FactFiles/Article/2167864/mk-45-5-inch-5462-caliber-guns/)。実兵器の公表値と、上のゲーム用仮値は区別する。
