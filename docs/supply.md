# 地上戦の補給と士気

2026-11-08 第2段。今回の作業票の「ユーザーの答え」を正本とし、第1段の未承認案を更新した実装仕様。宇宙戦・船の補給・艦の耐久は変更しない。

## ユーザーの指示

- 補給は基本的に本営から出る。道は占領され、敵が去っても補給遮断が残る。
- 競合地点とその先へも半速で供給する。半速は重ね掛けしない。迂回できれば速い経路を使う。
- 補給部隊を支援兵科に新設し、分けた量だけ自身も減る。補給不足による性能低下だけ免除する。
- 士気を耐久より先に削る。ゼロで最寄りの味方へ敗走し、移動中は操作できない。撃たれても逃げ続け、被弾減速を受けない。通常時は被弾減速する。
- 士気も補給も自軍の占領色（拠点の円・道路の帯）で回復する。士気も道路で回復する。補給の補充には本営との接続が必要。士気は孤立しても回復できる。
- 船・航空機に士気はない。航空機は戦闘と飛行で補給を消費し、基地へ一時離脱して補給後に戻る。船の補給は対象外。
- 右下の一覧には士気・補給だけ。耐久は棒・割合・数値を出さず、×1・×2の個数を残す。航空機は補給だけ。
- その他の質問は第1段の推奨案を採用。演習は上陸後に専用区画を追加する。

## 本営と配置

作戦の `groundHQ` に各陣営の既存拠点IDを指定する。本営を失うと供給停止、奪還で再開。他陣営の本営の転用や即敗北はない。本営が競合中なら本営自身・下流とも半速。開始前は既存の配置画面で時計を止め、本営の大円内で通れる陸上部隊を配置する。航空・海上・搭載済み部隊は固定位置。配置可能な空間がなければ出撃を拒否する。

試作演習はB「北橋」を味方本営、F「北東観測地」を敵本営に指定。A・C・Fの従来の占拠目標は維持し、Bは目標外。バイコヌール演習はAの訓練を維持し、区画10からB本営・C練習拠点・F敵本営を有効にする。案内をとばした場合は従来どおりA占拠で終了。

## 道路占領の決め方（案C）

拠点の大円を優先し、円外の道路帯は道路中心線を地形セル境界・折れ点・交差点・拠点投影点・従来の帰属境界で分けた小区間を所有単位にする。帯幅は既存の1.25 km。初期所有は現在の `groundRoadSections` と同じ拠点への帰属を使い、帰属なしは中立。拠点大円内の道路はその拠点に従う。

円外の各区間は地上の全兵科で5秒（仮）で占領する。拠点の占領兵科と30秒は変更しない。両軍がいれば競合し進捗停止。途中の進捗は保持し、占領完了で両軍の進捗を消す。敗走・再集結・搭乗中・航空・艦船は道路を占領しない。占領した所有者は部隊が離れても保持し、取り戻すには再占領が必要。拠点の所有変更だけで円外の道路まで一括で取り戻せない。描画も判定も同じ小区間を使う。

道路のグラフは全道路の実交点と共有端点を接続する。近いだけの線は接続しない。拠点は道路への投影点を経由して接続。道路から離れた拠点間は直接結ばない。川を横断する道は固定橋または完成・生存する仮設橋が必要で、浅瀬を補給路にしない。仮設橋が道路から離れていても新しい道路は生えない。

各本営から味方区間を探索し、通る競合地点があれば到達量を0.5にする。何箇所通っても0.25にはしない。敵・中立の非競合地点、橋のない渡河では切れる。円・帯の外では補充なし。同じ点で複数の候補があれば最大値を選び、加算しない。敵の所有者・位置を視界外で明かさず、表示は自軍の接続状態を基本とする。

## 対象と行動

地上だけを動く中隊（機械化突撃兵・補給部隊を含む）に士気と補給を持たせる。W.A.S. とドローンハイブは前段の推奨案どおり今回は対象外。航空3兵科には補給だけを持たせ、地上での自動補充や補給部隊からの分配は受けない。船は両方対象外。搭乗中は消費・回復を止める。既存の機械部消耗・輸送車破壊時の搭載者損失・沈没は従来どおり耐久へ通す。

発射前の残量で威力を確定し、発射後に消費。地点攻撃は着弾時に再計算しない。補給ゼロでも低性能で移動・射撃・架橋できる。基礎耐久や修理を変えない。

補給部隊は「補給」で味方地上中隊を指定し、停止して1対1で渡す。川・建物を越さない短い通行可能経路が必要。受ける側は移動・敗走中でも距離内なら受給可。補給部隊同士は不可。網の補充と分配は大きい方だけを使い、分配による実増加量を供給側から引く。複数の供給者でも一つだけ。命令取消で停止する。

士気ゼロで作業・射撃・追跡・予約を解除し、通行可能な経路長が最短の非敗走・非搭乗の味方地上中隊へ向かう。なければ味方拠点、本営へ。退路がなければその場で再集結。到着後は移動・搭乗だけ操作を返し、自軍の色へ運べる。士気30で戦闘復帰し、古い攻撃命令は戻さない。敗走中の被弾も士気から超過分を耐久へ通し、命令や速度を変えない。

士気回復は自軍色の非競合円・帯で、停止5秒かつ被弾なし5秒が条件。本営への接続は不要。補給部隊は士気を回復しない。地形は実移動を細分して計上。敵も同じ回復・消費・敗走規則を使い、低残量なら接続範囲へ自主撤退し、回復後は元の持ち場へ戻る。

航空は必要量を下回ると現在位置から本営上空（喪失時は初期位置）へ帰投し、基地補給中は盤上の射撃・索敵・選択対象から外れる。基地滞在後、出発地点へ戻って新しい指示を受ける。離脱中も中隊は生存し全滅扱いにしない。帰投中は攻撃しないが被弾し得る。基地帰投は本営占領による地上補給網とは別の航空用の処理。
