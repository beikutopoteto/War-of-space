- 本体の作業フォルダ（`~/dev/War-of-space`）の `docs/PROJECT_STATUS.md` と、2026-11-11 の引き継ぎの資料（docs フォルダの CLAUDE_HANDOFF）には、ユーザーの手元だけの版がある。コミットしない。main を取り込むときは `git merge --ff-only origin/main`（`reset --hard` は手元の版を消すので使わない）。取り込む変更がこのファイルに触れて止まったら、手元の版を別の場所へ写してから取り込み、戻す。手元の版は古いことがあるので、main の版（`git show origin/main:docs/PROJECT_STATUS.md`）も読む。
- 写真を持つ Codex の作業フォルダ（`~/dev/wos-codex-ground-integration` など）は消さない。
- リポジトリは公開。ほかの人の絵や写真は入れない（モデルの参考の絵も、見るだけにする）。
