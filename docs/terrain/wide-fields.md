# 広い戦場の地形設計図（段階8）

2026-11-10。通常150×100km、広域300×200kmは仮の検証寸法。既存カスピ海沿岸演習場48×36kmを変更しない。第二章の新作戦ではなく、射程・移動・補給・性能を確認する非公開デバッグ用フィールドを作る。以下の順に地形→オブジェクトの局在・密度→道路を定め、データへ反映する。

## 1. 実地形の選定

ウラル川下流の氾濫原とカスピ海北岸の河口デルタを地形の型にする。分流、自然堤防、河口低地、後背の乾いた平地を主な要素とする。NASAの2005年の説明は、樹枝状デルタと自然堤防からの分流、人工的に改変された河道を示す（[原資料](https://science.nasa.gov/earth/earth-observatory/ural-river-delta-kazakhstan-5551/)）。現在の海岸線・道路・市街地を測量再現するものではない。未来の軍事演習用に配置を創作する。

地理資料のwetlandを全てゲームの沼地にしない。移動に大きく響く沼地は河口の低窪地・旧河道に限定し、乾いた氾濫原・畑は平地。水田は今回は配置しない。山岳をデルタへ散らして作らず、起伏は自然堤防と低い段丘・砂地による。砂漠色は黄色い土色。地表のモザイク・地形グリッド・占領色は既存方式を使う。

両方とも自然な滑らかな外周を持つ盤型。海は岸に沿って南側へ連続させる。太い本流は0.3〜0.9km程度（仮）で、狭い渡河箇所と恒久橋を設計する。河口の広い分流は工兵で自由に架橋できると扱わず、既存0.3kmの仮上限を守る。

## 2. オブジェクトの密度・局在（仮）

- 河畔林は本流・分流に沿う局在帯。北の河道沿いに厚く、南の葦原へ近づくほど疎らにする。森林を平地全域へ乱数で散らさない。
- 森林の代表モデルは150版で約770本、300版で約1375本を上限の目安とする。実木の本数の再現ではない。密度と道路離隔は配置帯から決める。
- 低木は150版1300群、300版2400群を目安。乾いた平地の指定区画と河畔林外縁、砂地の縁へ局在。海・沼地中心・道路・市街を避ける。演習場の実描画650群は維持。
- 葦は河口低地に150版300、300版600の代表モデル。低窪地以外へ置かない。
- 市街地は道路結節と渡河点・港に限定。150版6拠点、300版8拠点。1集落40〜100棟程度の代表モデルで、占領時の既存の陣営色を維持。建物の色と地形の効果を混同しない。
- 畑は河川沿いの高めの耕作地に数区画。全て平地。沼地は河口・旧河道の個別の領域で定義し、分類セルを乱数で全域へ散らさない。

## 3. 道路・橋・補給

150版は西の本営(20,78)→中央渡河点(75,72)→東の本営(130,80)を主連絡道とする。西の港(25,25)と南の分岐点(62,42)、東の集落(112,42)を支線で結ぶ。恒久橋は本流の設計済み交差点に置き、車両は橋・浅瀬を選ぶ。幅の短い支流に工兵の実架橋を試せる場所を置く。

300版は西本営(35,150)→西中継(105,130)→中央渡河点(177,120)→東本営(260,160)が長い補給線。南方の港(52,48)・河口基地(157,58)・東側集落(244,84)、北の中継(180,177)へ支線を出す。河口側の東西道路は分流の合流点を避けて本流(172,84)の恒久橋へ通し、分流を無橋で横断しない。各交差点を拠点で受け、意味のない碁盤道路で面積を埋めない。

道路占領・競合による半速・切断、本営からの連結、味方領域での回復は既存の実システムを使う。広域寸法を理由に補給・士気の確定ルールや兵科の共通速度を変えない。

## 4. 性能と確認

データは必要なフィールドを初めて開くときに生成する。広域の地表テクスチャ・描画メッシュ・視界格子の上限を設け、物理の地表補間は実際の描画三角形と一致させる。選択射程の可射マスクはフレームへ処理を分散する。森・低木・建物は既存のInstancedMeshを使い、密度を無制限に増やさない。

確認は実寸、km表示、50kmロケット・30km自走砲・艦砲、移動・経路・補給切断、視界・遮蔽、選択の初回負荷と定常負荷。実測値は実行後に追記し、未実行の性能を目標達成と報告しない。新しい第二章のステージや報酬・物語は追加しない。
