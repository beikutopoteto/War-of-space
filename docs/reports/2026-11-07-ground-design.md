# 地上戦の設計案（2026-11-07）

## 1. 結論

今の戦闘に地形を足す案Aで作る。宇宙戦の座標・命令・索敵・表示を土台にし、地上作戦だけに地形と3段の規則を加える。数値と未決定の規則はすべて試遊前の仮案。

最初の試作はバイコヌールの小さな陸地、強化歩兵・戦車・重強化歩兵・攻撃機、1拠点、3段の切り替えと占拠まで。既存宇宙戦と並べて動かす。海・輸送・工兵・地点攻撃は後の作業票で足す。画面の形は [見本](../mockups/ground-a.html)。見本の地形とマークは提案であり採用決定ではない。

## 2. マップ

高さは地表の格子点から補間する。地上部隊の高さはその地点の地表に追従する。急斜面は車両が通れず、歩兵は減速する案。都市は建物群と占拠円を別に持つ。海は水面の高さを固定し、海岸線は地形と海面の交線で決める。艦は海だけを通り、歩兵や車両は海に入れない。川は通行不能、橋だけで渡る案。森・都市は歩兵の被発見距離と被弾を減らし、車両は遅くする。高台は視界を広げる。効果の重複は最大1種だけにする案。

視線と地形・建物の交差で発見と直接射撃を遮る。森は遮蔽バフ、山と建物は完全遮蔽の案。地点攻撃は発射点から地表への直線遮蔽を使わず、観測と射程を別に判定する。早期警戒機も山の裏を透視しない。地球の大気全体に宇宙のプラズマ雲を仮定しない。宇宙では排気プラズマがレーダーと誘導を阻害し、光学で探す。大気中では精密誘導が効く（story 3.3）。地上でのセンサーの方式は未決定。

データ案（座標・値は仮）:

```js
ground: {
  origin: [-100, -100], cell: 20, heights: [[0, 2], [1, 4]],
  seaLevel: 0, terrain: [{type:'forest', polygon:[[0,0],[20,0],[20,20]]}],
  rivers: [{path:[[0,0],[10,20]], width:4}],
  bridges: [{id:'b1', pos:[5,10], intact:true}],
  sites: [{id:'town', pos:[20,20], radius:8, owner:1, captureSec:30}]
}
```

格子は実際には長方形の行列とし、境界外は進入禁止。描画・通行・視線は同じ高さデータを参照する。建物の遮蔽体と地形ポリゴン、橋の接続は作戦データで指定する。

## 3. 3段の高度

地上部隊は地上のみ。艦は別枠の海面のみ。航空機は低・高、陸戦型 W.A.S. は地上・低・高を使う案。ドローンハイブは低高度を仮置きする。航空機は低・高のみを使い、地上に着陸しない（ユーザー決定 2026-11-07）。選択部隊の板に「地上・低・高」を並べ、使えない段を無効表示する。切り替え中は現在の段に留まる扱いとし、到着時に段を変える案。複数選択では共通して使える段だけ指定する。

## 5. 地上の仕組み

- 占拠: 生存する強化歩兵か地上の W.A.S. が円内に入り、敵の占拠可能部隊がいない間だけゲージを進める。仮30秒。敵がいれば停止し、離れれば進捗維持の案。他の歩兵の占拠は未決定。航空・艦・車両は占拠しない。
  勢力圏の色は拠点の占領で決まり、占領した軍の色が拠点ごとの影響範囲に付く。同じ範囲に両軍の部隊がいて争っている間は斜めのハッチ線を重ね、色は変えない（ユーザー決定 2026-11-07）。
  データ案: 拠点ごとに影響半径・持ち主・争い中のフラグを持つ。
- 輸送: 輸送車1中隊に歩兵1中隊を搭載する仮案。隣接して乗車命令、停止後に搭載。降車は通行可能な隣接地を指定。搭載中は独立移動・占拠・射撃不可。車両破壊時の損害は要決定。
- 地点攻撃: 自走砲・将来の砲兵・艦砲・爆撃は地点を指定し、予告円と着弾時刻を表示。仮に砲兵6秒・半径8、自走砲5秒・半径7、艦砲8秒・半径10、爆撃7秒・半径9。範囲内の味方にも当たる案。発射後は移動目標を追わない。砲兵は独立兵科として追加する決定ではない。海の艦の陸上砲撃は海戦の直接射撃と別処理。
- 索敵: 斥候は地上で隠蔽と視界に優れ、早期警戒機は高空から広域を観測する。両者とも遮蔽・視界距離を判定し、発見を味方で共有。仮に斥候60、早期警戒機100。攻撃範囲とは別。
- 工兵: 橋の修復・仮設、陣地構築、発見済み地雷の除去を停止して行う。仮に各20秒。橋の両端が通行可能で、建設位置に敵がいないことを条件にする。地雷の設置や発見条件は別途決定する。
- 機械化突撃兵とドローンハイブ: それぞれ地上突破と低空偵察・攻撃。小隊長の人間が目標ごとに射撃を許可する。自律して別の目標へ射撃しない。消耗品でも機械化突撃兵の人間の小隊長を含む損害表現は別途決める。
- 強化コマンド歩兵: 森・都市の通常歩兵バフを仮に1.5倍。たとえば被弾倍率0.8なら0.7。開けた場所では強化歩兵と同程度。

## 6. 部隊の単位と編成画面

中隊が最小の操作単位、大隊は複数中隊、旅団は複数大隊の案。数の上限は試作後に決める。戦闘の一覧は旅団→大隊→中隊を開閉し、選んだ中隊に命令する。大隊・旅団を選べば所属中隊に一括命令する。占拠などは中隊ごとに判定する。

`prep.js` の `screen='org'` の艦隊編集見出し付近に宇宙軍／地上軍の切り替えを足し、既存の支隊・打撃群・戦区軍と別の中隊・大隊・旅団の編集を表示する。出撃画面でも作戦に合う軍を選ぶ。技術ツリーには既に地上軍の予定があるが、海の艦に研究・編成ボーナスを適用しない。保存は既存宇宙編成を残し、地上編成の追加時に `migrate()` で旧データを補う。

## 7. コードの変え方

- `data/operations.js`: 作戦単位の ground 地形、拠点、初期部隊と勝敗条件を追加。未指定なら宇宙戦。
- `data/ships.js`: 宇宙艦の既存性能を変更しない。海の艦は既存モデルと固定の元性能を参照。地上兵科の仮値は別データに分離。
- `battle/state.js`: 地上作戦だけ地形・部隊・占拠・輸送・段の状態を初期化。艦隊の既存初期化を維持。
- `battle/scene.js`・`battle/units.js`: 同じ高さデータから地形・海・建物を描画。地表追従の足線と兵科名札を追加。
- `battle/hud.js`・`battle/battle.css`: 地上のみ3段ボタン、地点命令、階層一覧を表示。宇宙の連続バーを残す。
- `battle/sim.js`: 地上専用の移動・視線・段別射撃・占拠・地点着弾を分岐し、既存の宇宙の索敵・射撃・AIを維持。既存揚陸艇は宇宙の基地戦用であり、地上の乗降と混同しない。
- `prep.js`・保存処理: 地上軍の編成・出撃・移行を追加。読み込み順と普通の script 形式を維持。

テストは地形境界と遮蔽、段の遷移中と射撃先、占拠の競合、乗降・破壊、地点着弾、橋、海岸での通行禁止、旧保存の移行を固定場面で確認。宇宙の既存テストと代表作戦も通す。画面は名札・3段・一覧をブラウザで確認する。

作業票は小さく順番に分ける: ①地形・通行・地表追従（中）②3段と表示・射撃（中）③歩兵・戦車・占拠と演習の核（中）④編成・保存（中）⑤索敵と遮蔽（中）⑥地点攻撃（中）⑦輸送・工兵（中）⑧残り兵科と人の射撃許可（大なら兵科ごとに分割）⑨海・上陸（大、海岸と艦砲・輸送に分割）⑩章ごとの作戦と調整。各票で宇宙回帰を確認する。

## 8. 演習で教える順の案

バイコヌールの訓練場で、①選択と地上移動 ②地形と視界 ③強化歩兵で占拠 ④戦車と重強化歩兵の相性 ⑤斥候 ⑥航空の低・高と対空 ⑦地点攻撃 ⑧輸送と工兵 ⑨海岸の訓練区画で海の艦・艦砲・上陸。各段は一つずつ操作させる。演習で W.A.S. を自軍に配備しない案。第二章§2は中東の防衛、広州の防衛で敵の降下を初めて画面に見せ、§5終わりに自軍 W.A.S. を入手、§6の海からの上陸で初投入する。

## 9. ユーザーの決定（2026-11-07）

1. 航空機の段は低・高のみ。地上に着陸しない（A）。
2. 索敵は光学と地形の遮蔽を使う（A）。レーダーも事実上この視界の仕組みに含め、別の仕組みにしない。
3. 地点攻撃は予告円を出し、味方にも当たる（A）。
4. 陸戦型 W.A.S. は高高度で低・高の航空機を撃つ（A）。

次の4つは反対がなかったため、おすすめの A で仮に決定する。

- 他の歩兵の占拠: まず強化歩兵と地上 W.A.S. のみ。
- 乗車中の輸送車の破壊: 搭載歩兵に損害を与え、周囲へ降ろす。
- 工兵の橋: 所定の橋の位置だけ修復・仮設する。
- 段の切り替え中の射撃: 到着まで元の段で判定する。

早期警戒機・爆撃機の演習は未決定（訓練用の機体を使う案／作戦で初めて教える案）。
