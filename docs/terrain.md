# 地形作成方針書（地上戦のマップ）

地上戦のマップを作るときの決まり。作成: 2026-11-07（ユーザーの指示で Claude が書いた）。数値はすべて仮。

## 0. なぜこの順で作るか

前の見本では、地形・森・町を乱数でまき散らしたため、散らかって見え、どこで戦うかも読み取れなかった。実在の地形は、川・海・風・人の暮らしという原因から形が決まり、森も町も道路もその結果として決まった場所にある。だから、原因から順に決める。

**分担（ユーザー決定 2026-11-07）:** 地形を決める仕事（下の 1〜4 と設計図）は Codex。Claude は方針書を持ち、設計図をもとに試作（ゲームへの実装）をする。

## 0.5 地形・オブジェクト・地表の3つに分ける（ユーザー決定 2026-11-07）

マップの一点は、次の3つの層でできている。効果（攻め・守り・速さなどの増減）を持つのは地形とオブジェクトだけで、地表は見た目だけ。

| 層 | 中身 | 効果 | 種類 |
|---|---|---|---|
| **地形** | 土地そのもの | 攻防の増減（デバフ）を持つ。一点に1つ | 平地・沼地・山岳・砂漠の4つ（決まった数） |
| **オブジェクト** | 地形の上に載るもの | 地形の効果に上乗せする。重なってよい | 森林・低木（ユーザー 2026-11-07）・市街地・道路・積雪など（決まった数）。積雪は「地形」に見えるが、上乗せするので実質オブジェクト |
| **地表** | 見た目の味付け（フレーバー） | 自分の効果はなく、どれかの地形として扱う | 畑・葦原・塩性平地・草原など。どの地形として扱うかは、マップごとにその時に決める（例: 畑は平地、水田は沼地。ユーザー 2026-11-07） |

- **沼地**（ユーザー 2026-11-07。前は「湿地」と書いていた）: 水がたまり、足や車輪が沈む土地（葦の沼、湿原、三日月湖のまわり）。車両はほとんど通れず、歩兵は遅いが隠れやすい。湿った草地や、ふだん乾いている氾濫原は効果が小さいので平地として扱う。
- 地形とオブジェクトの種類は決まった数（有限）にして、増やすときはユーザーに聞く。
- 地表（サブ地形）は自由に足してよいが、必ず「どの地形として扱うか」を設計図に書く。
- 効果の数値はまだ決めていない（仮の案は設計の報告で出す）。
- **川の渡り方（ユーザー決定 2026-11-08）**: 川は橋のほかでも渡れるが、兵科で違う（数値は仮）。
  | 渡り方 | 兵科 |
  |---|---|
  | 渡れない（橋か浅瀬を使う） | 主力戦車、自走砲、自走対空砲、精密誘導ロケット兵 |
  | 少し遅くなる（仮 0.5 倍） | 装甲兵員輸送車、斥候部隊、工兵、陸戦型 W.A.S. |
  | かなり遅くなるが渡れる（仮 0.2 倍） | 強化歩兵、重強化歩兵、強化コマンド歩兵、機械化突撃兵 |
  | 影響なし | 航空機、ドローンハイブ |
  - **浅瀬**: 戦車などの重い車両も渡れる場所を、川ごとに何か所か作る（浅瀬だけでよい。川幅の狭い所に置くと自然）。設計図の `objects.fords` に置く。
  - **工兵の橋**: 工兵は、ある川幅まで（仮 0.3 km）なら橋を架けられる。広い本流には架けられない。
  - 経路は、橋・浅瀬まで回り道するか、遅くても川を渡るかを、着くまでの時間で比べて速いほうを選ぶ。
- **地形はモザイクで作る（ユーザーの案 2026-11-07）**: 地形は一色の大きな面ではなく、小さなマス（仮に一辺 250〜500 m）の寄せ集め。マス1つに地形は1つで、効果はマスごとに決まる。地域ごとに「地形の割合」と「区画の大きさ（固まり具合）」を決め、決まった種でモザイクを作る（例: 氾濫原は平地90%・沼地10%で細長い区画、河口の葦原は沼地80%で細かい区画）。景観の見方の「土台（いちばん広い地形）・区画（その中の別の地形の斑）・帯（川・道路・河畔林）」に合わせる。地表（見た目）はマスの上に重ね、オブジェクトの帯と塊はモザイクを横切る。

## 1. 手順（この順を守る）

1. **土台の地形を選ぶ**: 実在する地形の型から選ぶ（デルタ、リアス海岸、氾濫原、段丘、扇状地、砂丘、塩性湿地、断崖の台地など）。作戦の舞台の実際の場所に、その型が本当にあることを確かめる。型を 1〜2 個に絞り、混ぜすぎない。
2. **高さと水を決める**: 型に合う高さの形（海面との差、斜面、崖）と、川・水路・湖・海岸線の形。川は高いほうから低いほうへ流れ、合流はしても分かれるのはデルタの中だけ。
3. **地形と地表を決める**: まず効果のある地形（平地・沼地・山岳・砂漠）を、高さと水から置く（低くて水はけの悪い所は沼地、乾いた高台は平地や砂漠）。次に見た目の地表（畑・葦原・塩性平地など）を重ね、どの地形として扱うかを決める。境目は地形に沿わせる。
4. **建物と森のオブジェクトの密度と偏りを決める**: 被覆の種類ごとに密度を決め、さらに「どこに寄るか」を決める（町は川の渡り場・港・道路の交わりに、村は自然堤防の上に、森は川沿いの帯と谷に、など）。一様にまかない。
5. **道路を作る**: 町と町、港、橋（渡り場）をつなぐ。幹線は高くて乾いた所（堤防・段丘の上）を通り、沼地は避け、川は橋で一か所に集める。道は地形の等高線に沿って曲がる。
6. **拠点と戦いの形を置く**: 拠点（占拠できる所）は町・橋・高台・港に置く。下の「4. 戦いの形」を満たすか確かめる。

## 2. 設計図（Codex が作る）

1つの作戦の地形は、1つの設計図のファイルにまとめる。画面はこの設計図だけから作る（設計図にないものを画面で足さない）。

- 置き場所: `docs/terrain/<作戦のid>.md`（説明と略図）と、データ `data/terrain/<作戦のid>.js`（ゲームと見本が読む）。
- 中身（データの層。座標は km、原点はマップの南西）:
  - `meta`: 場所（実在の地名と緯度経度）、選んだ地形の型と理由、マップの大きさ、高さの誇張（下）。
  - `height`: 高さの作り方。制御点・線（堤防、段丘の縁、崖）と、それを滑らかにつなぐ規則。乱数の起伏は小さな揺らぎだけ（決まった種で、毎回同じ形）。
  - `water`: 海岸線（多角形）、川（中心線と幅。下流ほど広い）、水路、湖、浅瀬。
  - `terrain`: 地形のモザイク。地域の多角形ごとに、地形の割合・区画の大きさ・種（例: `{region:[...], mix:{平地:0.9, 沼地:0.1}, patch:1.2, seed:7}`）。マスの大きさは `meta` に書く。
  - `surface`: 地表の多角形（畑・葦原など。見た目だけ）と、それぞれをどの地形として扱うか（`as: '沼地'` など）。
  - `objects`: オブジェクト（森林・市街地・道路・積雪など）。森林と市街地は多角形と密度（1 km² あたりの数）と寄る場所の規則（「川から 0.5 km 以内に 70%」など）。配置は決まった種で作り、毎回同じ。
  - `roads`: 道路の線（幹線・脇道）と橋。
  - `sites`: 拠点（位置、影響の範囲、最初の持ち主）。
- 略図: `docs/terrain/<作戦のid>.md` に、上から見た図（SVG か文字の図）を1枚。どこが高く、どこが通りにくく、どこで戦うかが一目でわかるもの。

## 3. 見た目の決まり

- **盤の形（見本B、ユーザー決定 2026-11-07）**: 地形は盤に載せ、輪郭は四角でなく自然な形（海岸線や地形の切れ目）で終わる。盤のまわりにホログラムの枠と英字のコードを控えめに。
- **広さ**: 部隊の数と間隔に対して戦場が広いこと（ユーザー: 最初の見本の一辺の約9倍。部隊は画面の一部に集まって見える）。
- **高さの誇張**: 平らな土地（カスピ海沿岸など）は、立体に見えるよう高さを 3〜8 倍に誇張してよい。誇張の倍率は `meta` に書く。
- **地面の色**: 被覆の種類ごとのベースの色（草原・畑のパッチワーク・森・砂漠・沼地・岩地・雪）。写実寄りで、衛星写真らしく。
- **勢力圏**: 拠点のまわりの円と、自軍の拠点から出る道路に沿った帯に、持ち主の色を敷く（見本の案C「円＋道路」、ユーザー 2026-11-07）。円と帯が重なる所も色は濃くならない（同じ軍の色は1枚の面として塗る）。全体の画面でどこが誰の陣地か一目でわかる濃さにする（ユーザー 2026-11-07「もう少し濃く」。地表の質感は透けて残す）。争っている範囲は罫線。市街地の建物は持ち主の色（地球連合は青、惑星共和国は橙、中立はグレー）。罫線は地面の模様と紛らわしくない色と向きにする。
- **等高線**: 表示を切り替えられる。高さの等しい細い曲線だけ。海の上には出さない。
- **地形の表示（ユーザー決定 2026-11-07）**: 「地形」のボタンで ON/OFF。ON のとき、地形の種類ごとの色の半透明な膜を地面にかぶせ、どのマスがどの地形かを一目でわかるようにする。膜はマスの四角のまま（グリッド状でよい。マスの境目の線も入れる）で、色は濃く。沼地は紫、山岳はくすんだ緑、砂漠は黄色い土色（惑星共和国の橙とまぎれないように。青系は海と見分けにくいのでやめる。ユーザー 2026-11-07）（平地・沼地・山岳・砂漠で別の色。オブジェクトの森林・市街地・積雪は輪郭か模様で重ねる）。OFF のときは地表の見た目だけ。
- **名札**: 部隊のそばに出し、重なるときだけ少しずらして細い線でつなぐ。長い列にしない。

## 4. 戦いの形（地形が作戦に効くこと）

- 進む道が 2〜3 本あり、どれにも長所と短所がある（速いが開けている、遅いが隠れられる、など）。
- 渡れる所（橋・浅瀬）が限られた川か水路があり、そこが取り合いになる。
- 戦車が走れる開けた所と、歩兵が強い所（町・森・沼地）が両方ある。
- 見下ろせる高い所が少しある（斥候と砲兵の観測に効く）。
- 海の艦が近づける海岸と、近づけない浅い海の両方がある（艦砲射撃と上陸の場所が限られる）。
- 拠点は 6〜10 個。最初の持ち主が偏りすぎない。

## 5. 確かめること（Codex が設計図を作ったとき）

- 手順の 1〜6 の順に決めたか。各層に「なぜここか」の一言があるか。
- 実在の場所の地形の型と食い違っていないか（例: カスピ海の北岸は海面より低い平らな土地で、高い山はない）。
- 4. の戦いの形を満たすか。
- 画面は Claude がヘッドレス Chromium で撮って確かめる（Codex の作業場所ではブラウザが起動できない）。

### 道路占領の表示（2026-11-09）

道路だけは地上の全兵科が5秒（仮）で占領する。搭乗中・敗走中・再集結中・航空・艦船は除外。拠点の強化歩兵／地上W.A.S.限定と30秒は維持。現地の札で残り秒、競合による停止、中断を表示。視界外は最終確認の情報として示す。重なる道路札は選択部隊に近い区間を優先して間引く。
