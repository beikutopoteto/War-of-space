# カスピ海沿岸演習場（広域）の設計図

2026-11-11。仮のid `baikonur2`、96×72km。座標は南西原点km、北がy増加。[データ](../../data/terrain/baikonur2.js)と対応する。名前・配置・高さ・密度・寸法は演習用の仮値。既存の48×36km演習場を拡大コピーせず、同じ土地の広い範囲を独立に構成する。チュートリアル2は変更しない。

## 1. 土台の実地形

アティラウ南方のウラル川デルタとその背後の氾濫原（参考点46.85°N、51.85°E）。[NASAの原資料](https://science.nasa.gov/earth/earth-observatory/ural-river-delta-kazakhstan-5551/)にある、北カスピ海へ注ぐ樹枝状デルタ・自然堤防・人工改変された河道を型にする。広い乾燥平地の南に河口低地が続く構成とし、山岳は置かない。GISや実際の道路の測量再現ではない。

作業票2では乾燥した北側に砂の高まりと溝を追加する。[北カスピ平原のベール丘の研究（Badyukova, 2018）](https://www.sciencedirect.com/science/article/abs/pii/S1040618216301562)が扱う細長い低い丘列を形の参考にする。ナリン砂地を含む北カスピ低地の型を演習盤に取り入れるもので、アティラウ南方のこの座標に同じ丘列が存在するという測量再現ではない。方向・長さ・位置・高さは作業票に沿った仮値。

## 2. 高さと水

本流は(51,72)→北橋(49,60)→中央橋(47,39)→河口橋(46,25)→(47,16)。分流は河口橋の南(46,23)から西(34,17)と東(60,16)へ出す。北の浅瀬は(50,66)。川幅は上流0.28kmから河口0.9kmへ増す。海岸はy=14〜18kmで、海は南へ連続する。

北の微高地と自然堤防、低い河口・旧河道を制御点で滑らかにつなぐ。表示の誇張は18倍を維持（以下すべて仮）。

- 砂の高まりは北西(12,65)/(22,66)/(32,64)/(38,67)、北東(62,66)/(72,67)/(81,66)/(88,64)の8本。東西方向、裾を含む長さ約4.8〜8km、高まりの加算7〜13m。南北幅はガウス尺度0.4〜0.5kmで、列の間を低く残す。実装は固定制御点の細長いガウス形で、乱数で山を散らさない。
- 段丘の縁y=61は加算2.8→5m、遷移幅1.2→0.65km。北幹線と浅瀬の迂回路は元の位置を保持する。
- 旧河道の低窪地(35,31)/(60,31)を保ち、(40,35)/(56,35)に旧河道、(18,63)/(79,64)に塩性の溝を追加。窪地は計6か所。水系は変えない。
- 旧E寄りの観測丘1か所を、(18,58)/(40,53)/(58,48)/(81,42)の4か所へ置換。加算6〜7m。B/Eから各5km以上離し、両岸に分ける。港G・I付近を除く岸沿い2.5kmは浅海。GからIへ沿岸をたどる演習用の浚渫水路を置く（創作、水深の実測値ではない）。

## 3. 地形と地表の3層

セル一辺0.4km。固定種の滑らかなモザイクを地域ごとに順位付けして割合を決める。土台は平地。沼地は川沿いの旧河道と河口低地だけに寄せ、乾いた氾濫原を沼地にしない。河口西・東は沼地75%／平地25%、旧河道は沼地80%／平地20%（区画0.8〜1.2km）。東南の塩性地は砂漠70%／平地30%（区画1.6km）。地域外は平地100%。海は地形セルなし。追加旧河道2区画は沼地70%、北の塩性の溝2区画は砂漠80%、砂の高まりの地域2区画は砂漠65%（残りは平地、仮）。北経路の道路帯へ沼地を追加しない。

地表は草原=平地、畑=平地、葦原=沼地、塩性平地=砂漠。地表は見た目だけで、セルの地形と一致する箇所だけに適用する。地形・地表・上乗せの森林／市街地を分け、地形種・効果・共通戦闘値は増やさない。

## 4. オブジェクトの密度と局在

数はすべて仮。配置枠と実際に描く代表モデルを区別する。

|低木の枠／代表群|900／900|3000／2600|演習場の4倍の面積に、旧チュートリアルの代表650群の4倍を置く|

- 森は本流・分流の河畔帯を保ち、B/E周辺の畑の縁と村の外側に防風林の列、氾濫原の6区画に島状の林を足す。代表モデルの比率を55%／25%／20%に固定し、棄却率の差で河畔林が減らないようにする。北の乾いた段丘には森を置かない。
- 木の中心は道路から0.32km離す（以前0.18km）。最大樹冠半径約0.208kmと道路半幅0.095kmを足しても道路を覆わない。森・建物は海・河道・湖へ置かない。
- 低木の地域は元の草原区画、林縁、塩性地の縁を維持。一群の葉の塊を従来3〜7から3〜4へ、形の分割を1から0へ下げる。群を増やしても三角形数が膨らまないようにし、InstancedMeshを維持。チュートリアル2にはこの描画設定を適用しない。
- 村は(19,53)/(30,47)/(36,43)/(58,42)/(77,48)/(26,35)/(60,24)/(75,32)。村の市街地オブジェクトの範囲は各中心の周囲2×2km。既存の市街地規則を使い、占領拠点は追加しない。

## 5. 道路と渡り場

集落を自然堤防・乾いた微高地で結び、低沼地を避ける。3本の東西経路をBで分け、Eでまとめる。北の幹線は長めだが乾燥平地を通り、中央は最短だが河畔林と中央橋が要所、海沿いは長く港と艦砲支援を使える。

- 西の共通幹線 A(10,56)→(19,53)→B(27,49)。Bの西で補給路が1本に絞られる。
- 北 B→(31,59)→C北橋(49,60)→(61,60)→(68,53)→E(69,44)。
- 中央 B→(36,43)→D中央橋(47,39)→(58,42)→E。
- 海沿い B→(26,35)→(25,25)→G西港(23,19)→(33,23)→(39,25)→H河口橋(46,25)→(60,24)→(68,22)→I東港(76,20)→(75,32)→E。
- 東の共通幹線 E→(77,48)→F(86,55)。Eの東で補給路が1本に絞られる。
- 北橋西側(45,59.78)→(49,66)→北の浅瀬(50,66)→(51,66)→(54,60)は北橋への迂回路。重車両も通れるが遠回り。

恒久橋はC/D/Hの3か所。浅瀬は北の1か所。分流は海沿い道路より南に流し、道路を無橋で川へ通さない。浅瀬と橋の通行規則・工兵の架橋上限0.3kmは既存値を使う。

## 配備・確認・性能

バイコヌール演習だけ本営A/F、支援拠点B/E/G/I。自軍の既定編成は従来10隊に補給1隊、海の砲撃艦・揚陸艦と搭載歩兵を維持する（画面に出るのは開始時13隊、搭載を含め14隊）。敵10隊は歩兵4・戦車2・自走砲1・対空1・斥候1・戦闘機1をF/E/I付近に置く。開始時に表示される両軍は23隊。

寸法API・描画格子は既存の広域と同じ仕組み。384×288 world、mesh384×288分割、step1、texture2048×1536。地形データは初回参照で生成する。視界の描画格子fogStepは2（既存値）を維持し、視界と経路の処理は変更しない。1 step平均12ms以下を目安とし、超過時は関数別の実測を報告する。未実行の性能値を達成と扱わない。
