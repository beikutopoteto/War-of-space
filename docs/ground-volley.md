# 一斉射とロケット連射

段階4（2026-11-10）。命令欄の1〜30は部隊ごとの一斉射回数。個々の砲撃点は1発の砲弾／ロケットに対応する。

## 発射と装填

- 自走砲・戦車・艦・地上W.A.S.等は、残存車両／艦ごとに1発ずつ撃って1斉射とする。自走砲は従来の自動装填間隔で次の斉射を継続する。
- ロケット車両は1台ごとに6発、各車両の同じ発射順をまとめて0.25秒間隔で撃つ仮設定。1台なら計6発、2台なら計12発で1斉射。
- ロケットの再装填は連射終了後30秒（仮）。初回の装填待ちは連射1.25秒＋30秒。自走砲の従来8秒等は維持する。全てゲーム用の仮秒で、現実の兵器の公表性能ではない。
- 通常の敵部隊への間接攻撃・敵の密集砲撃・地点攻撃コマンドも同じ斉射へ接続する。単発primitiveは1発を作る内部APIとして残す。
- 射程・距離依存散布・弾道衝突は各弾の発射時に確認。連射中に失われた車両の未発射枠は飛ばす。

## 補給・取消・戻す

- 一斉射全体の補給消費を発射予定の弾数へ分割する。車両数・6発連射を理由に部隊の割合式補給消費を重複させない。中断時は実際に撃った分だけ消費する。
- 移動・停止・搭乗等の新しい命令は未発射分を取り消し、発射済みの弾は着弾する。
- 「戻す」は共有台帳に残る発射済み・失われた車両の枠を再発射しない。補給を巻き戻さず、取消前に未発射だった分だけを再開する。
- 長時間停止して装填待ちが0になった後に戻した場合でも、再開分の最後の実射後に最低限の再装填を確保する。古い連射トークンで装填・補給の処理を省くことはできない。
- 連射残り発数・次の斉射回数・装填中を既存の操作欄へ表示する。連射中の範囲ラベルを「最終弾着弾待ち」と誤表示しない。

## 確認

専用24、範囲27、兵科91、砲撃46、射程・実発射26、操作51、補給70、共有計画14を通過。
