# 準備画面とメニュー構成

## 画面の流れ

```
タイトル / メインメニュー
├─ 出撃 ─ 作戦を選ぶ → 出撃する軍集団を選ぶ → 戦闘
├─ 編成
│   ├─ 軍集団  最大5個の軍を 5×5×5 の立方体に配置して保存。速度同期の有無
│   ├─ 軍      最大5個の戦闘団を編入。能力の合計と編成ボーナスを表示
│   └─ 戦闘団  艦種と隻数を決める（1つの戦闘団は1艦種）
├─ 艦艇データ   8艦種の能力表と編成ボーナス一覧
└─ クイック戦闘 用意された艦隊ですぐ戦う
戦闘終了 → もう一度 / メニューへ
```

## ユニットの階層

| 単位 | 中身 | 戦闘中にできること |
|---|---|---|
| 軍集団 | 軍 最大5個。5×5×5 の配置と速度同期の設定を持つ | 全軍まとめて移動・攻撃。軍をドラッグで出し入れ |
| 軍 | 戦闘団 最大5個 | 1つの艦隊として操作 |
| 戦闘団 | 同じ艦種の艦（艦種ごとに最大隻数あり） | 編成は変えられない |

## 仮の決めごと（未確定）

- 戦闘団は1艦種でまとめる。混成にするかは未定。
- 艦種の能力値（攻撃・防御・回避・射程・視界・隠蔽性・速度、1〜10）と最大隻数はすべて仮。
- 編成ボーナス7種（打撃艦隊、護衛艦隊、機動部隊、前衛偵察、隠密艦隊、強襲揚陸、単一艦種）も仮。
- 戦闘への反映: 攻撃・防御・回避・射程・速度・視界・隠蔽性のすべてを戦闘の計算に使う（索敵は下記）。
- 軍集団の立方体は1マス = 横16・高さ10の間隔で戦場に展開する。前方（敵側）は格子の上側。

## データファイル

- 艦種と小型機は `data/ships.js`、編成ボーナスは `data/bonuses.js`、作戦は `data/operations.js` にある。下の仮の値はここで直す。
- 作戦の増援は作戦の時計で何分後かを書く（時計は1秒で30秒進む）。カリュブディス攻略戦は開戦30分後に第5戦隊（14隻）が北から来る。
- 作戦を足すと出撃画面に並ぶ。勝利条件は今は要塞の撃破だけで、要塞は戦場の中央に置く。

## 索敵（仮の値）

- 見つけていない敵は表示されず、攻撃もできない。味方の視界は陣営全体で共有する。
- 発見距離 = (60 + 視界×8) × (1 − 隠蔽性×0.04)。視界6の艦隊は隠蔽性5の敵を約86、隠蔽性7の敵を約78の距離で見つける。武器の射程（12〜22）よりずっと広い。
- 発砲した艦隊は3秒間、距離に関係なく相手に見える。
- 見失った敵は最終確認位置に薄い印を30秒残す。攻撃中の敵を見失うと、その位置へ移動に切り替わる。
- 要塞は常に見える。要塞自身も視界8で連合艦隊を見張る。
- 敵は見つけた連合艦隊にしか反応しない。増援の第5戦隊は何も見えないとき要塞の北で待機する。
- 選択中の艦隊のまわりの薄い緑の輪が、隠蔽性5の敵を見つけられる範囲。

## 艦載機とW.A.S.（仮の値）

- M.A.S.はW.A.S.（Weaponed Armored Shell、武装装甲化外骨格）に改名。艦名は「突撃揚陸艦」（W.A.S.を運ぶ）と「強襲母艦」（W.A.S.が主力、艦載機も出せる）。戦闘母艦は艦載機（W.A.S.ではない）を積む。
- 1隻あたりの搭載: 戦闘母艦 艦載機40、突撃揚陸艦 W.A.S.10、強襲母艦 W.A.S.30・艦載機10。軍の搭載数は戦闘団の合計。
- 発進: 見えている敵が発進距離（艦載機52、W.A.S.30）に入ると自動で出撃する。1隊は艦載機30機・W.A.S.20機。同時に出られるのは3隊まで、次の隊を出すまでのクールタイムは艦載機3秒・W.A.S.4秒。3隊に入りきらない分は予備として艦内に残る。
- 燃料: 艦載機24秒、W.A.S.16秒。尽きるか周りに敵がいなくなると母艦へ戻る。帰還後は整備（艦載機8秒・W.A.S.10秒）を終えるまで再出撃しない。
- 帰還時の回復: その出撃で失った数の半分を予備から補充する。予備がなければ補充されない。例: 収容120（3隊×30＋予備30）で3隊が10機ずつで戻ると、20機ずつに戻って予備は0。以後の帰還では増えない。
- 艦載機はW.A.S.より射程が長く速いが打たれ弱い。W.A.S.は射程が短いが装甲と火力が高い。艦砲は小型機を狙いにくく、小型機への艦砲の損害は半分。
- 母艦が沈むと、出撃中の隊は戻る場所を失い、燃料が尽きたところで失われる。
- 母艦自身の攻撃と射程は下げた（戦闘母艦は攻撃7→4・射程9→4、強襲母艦は攻撃5→4・射程7→3、突撃揚陸艦は攻撃6→5）。遠くへの攻撃は艦載機が担う。
- 選択中の母艦の青い輪は、砲の射程ではなく発進距離を示す。
