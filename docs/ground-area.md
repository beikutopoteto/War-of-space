# 地上戦の範囲砲撃

地上作戦だけに適用。宇宙の攻撃・砲撃は変更しない。

## 操作と挙動

- 単独の自走砲・戦車などは中心をクリックし、マウスまでの距離を半径として2クリック目で確定。
- 複数部隊と艦（単艦も対象）は始点・終点・幅の順。Shiftクリックで中間点を足し、曲線の帯を作る。
- 砲撃ボタン横の1〜30は各参加部隊の一斉射回数。確定後は再装填間隔で自動継続する。途中の選択変更では予約を消さない。
- 停止・移動などの新しい命令は未発射分を取り消す。発射済みの弾は着弾する。「戻す」も発射済みの回数を復活させない。
- 全参加部隊が指定範囲のどこかを撃てる場合だけ確定できる。射撃可能な地点がなくなった隊は残りを中止し理由を表示。
- 戦車は射程に加えて射手自身の視界・地形と建物の射線を確認する。友軍の観測だけで間接照準はできない。自走砲・艦の間接照準は維持。
- 指定範囲は着弾中心をランダムに選ぶ範囲。各弾の爆風半径とは別で、爆風は範囲外の味方にも及ぶ。従来の単発API・敵AIの散布規則は維持。
- 最大水平射程を基に地面へ投影する。段階2では直接／間接射程に地形・建物を反映した表示用マスクを追加した（32方向×12距離の近似）。範囲砲撃の指定輪自体は切り欠かず、実際の発射は共有の射線・弾道判定を満たす地点へ限定する。

## 仮の数値

値の正本は `data/terrain/exercise2.js` の `strike`。1kmは4ワールド単位。

|兵科|着弾まで秒|爆風半径（ワールド単位）|従来単発の散布半径|再装填秒|
|---|---:|---:|---:|---:|
|戦車（今回追加）|2|2|1|4|
|自走砲（既存）|5|7|2|8|
|艦（既存）|8|10|2|10|
|広域戦略支援航空機（既存）|7|9|2|10|

指定可能な最大散布半径は `areaRadius`、未指定時は爆風半径の数値を仮に使用。意味は別で、選んだ半径で爆風自体は変わらない。混成時の幅上限は参加兵科の最小値。中心線の長さ上限は各隊の「残存台数×その兵科の最大散布直径」の合計（ユーザー承認）。既存の戦車の通常攻撃性能・全体の性能倍率は変更しない。

## 確認

- `tests/ground-area.cjs`: 円・曲線・回数・装填・上限・取消・戻す・戦車の建物／尾根遮蔽・宇宙対象外22/22。
- `tests/ground-plan.cjs`: 既存共有命令14/14。
- 既存のブラウザ砲撃と演習の関連確認103件を通過。全作戦の手元での再実行は行わず、既存PRのCIを使用。
- `tools/ground-area-check.cjs`: 実マップのクリック、Shift中間点、停止・戻す、艦の線状指定、ページ例外なしを確認。写真は1600×900で `.shots/` に保存。

段階1ではロケットと地上W.A.S.にも間接射撃の地点指定を接続。着弾まで5秒・爆風半径7・従来散布2・再装填8秒は自走砲と共用する仮設定で、連射・爆風・装填の専用化は後段階。射程の正本は `data/terrain/exercise2.js` の `fireRangesKm`／`navalFireRangesKm`、旧 `range` は互換用で地上の射撃可否には使用しない。

段階2では飛翔時間を弾道から計算し、上表の自走砲5秒・艦8秒・戦車2秒は旧値となった。再装填秒・爆風半径は据え置き。支援機の7秒は段階7まで暫定維持。詳細は `docs/ground-ballistics.md`。

最小散布円の詳細と円／曲線帯への適用は `docs/ground-scatter.md`。自走砲・ロケットは距離別の物理精度を使い、従来の未観測倍率を掛けない。他の兵科の旧散布規則は維持。

斉射・連射・補給分割・取消と戻すの台帳は `docs/ground-volley.md`。単発primitiveと部隊の斉射回数を区別する。
