# 惑星共和国の宇宙の艦の考察（Codex、2026-11-13）

Codex（gpt-6.1-sol、推論 high、読み取り専用）に頼んだ考察をそのまま置く。頼んだ内容と、それを元にした設計は `docs/models.md` 15.11・15.12。

## 1. 両陣営の宇宙艦の設計思想の違い

**共和国艦は「少人数の乗員を密閉された船体で守り、W.A.S. を中心とした立体戦を支える艦」にするのが自然です。** 地球連合の艦を赤くした姿ではなく、火星の宇宙産業から生まれた、低い一体構造の艦を勧めます。

以下、資料にある設定からの考察と、未承認のデザイン案を区別します。**新しく示す形・武装数・寸法はすべて仮案**です。

| 観点 | 地球連合 | 惑星共和国 | 艦形に反映する違い |
|---|---|---|---|
| 歴史 | 核の誤射後に成立した連合軍。長く警備・救難・航路保護を担当 | 自治軍として軍備を制限され、輸送船の中でも戦力を育てた | 地球は艦橋・砲塔・装備が外から分かる。共和国は装備を殻の中へ収める |
| 産業 | 多地域の軍と産業を引き継ぎ、長期戦の生産力が大きい | アストラルX を中心に、精錬・大型艦建造・艤装・W.A.S. 生産を宇宙の拠点で分担 | 共和国は共通の断面、機関区画、砲塔外装を使う設計が似合う |
| 人の数 | 人口が多く、大型艦の長期哨戒を支えられる | 人口は地球の7〜8分の1。熟練乗員の損耗が弱点 | 共和国は小さな乗員区画を船体内部で守り、外側の砲室を小さくする |
| 技術 | D-RAMS 導入前の遠距離砲戦思想が残る | D-RAMS と W.A.S. の開発に深く関与。排気の雲の中で近接戦を磨いた | 地球は高い指揮・観測構造。共和国は船体各面に光学装置を分散 |
| 戦い方 | 戦艦が決め手。他艦が守り、敵をその射界へ導く | W.A.S. が攻撃の要。護衛、接近、対空艦の排除、離脱を組み合わせる | 地球は主砲と艦橋が目立つ。共和国は艦ごとの仕事が船体の輪郭に表れる |

根拠：[世界設定・年表](../../docs/story.md)、[火星の産業・勢力](../../docs/story.md)、[両軍のドクトリン](../../docs/story.md)。

ここで、形を考える際に注意したい点が四つあります。

- **共和国は宇宙工業では強い。** 燃料と軌道への輸送条件に恵まれているため、貧弱な小型艦や粗末な改造船ばかりにする理由はありません。少人数で扱える、高品質な艦が合います。
- **低い艦でも、装甲が薄いとは限りません。** 守るべき乗員区画を小さくまとめ、その周囲を厚く守る考え方です。
- **無人砲塔と無人艦は別です。** 地上車両と同じく、人が安全な場所から武装を扱う構成を提案します。共和国艦全体を自律兵器とする設定は足しません。
- **扁平な形の理由は空力やレーダー対策ではありません。** 乗員・機関・格納庫のまとめ方、共通部品、突出物の少なさとして説明します。宇宙艦に回転居住区も付けません。

両軍は D-RAMS を共有する技術圏です。異なる文明ほど形を離すより、**同じ技術を違う目的で組み立てた差**にすると説得力が出ます。根拠：[D-RAMS・光学索敵・居住区](../../docs/story.md)。

また、**開戦時の共和国には独自の戦艦・戦闘母艦がありません。** 戦艦は鹵獲艦で、後にマイクで戦艦を起工する記述があります。依頼の7種はすべて案を出しますが、共和国独自の戦艦・戦闘母艦は「新造艦の案」とし、第一章の鹵獲艦は地球型を残すのがおすすめです。名前の表に共和国の戦艦・母艦の役割があることだけでは、開戦時の保有を意味しません。根拠：[艦種性能と鹵獲艦の扱い](../../data/ships.js)。

## 2. 共和国の宇宙艦の共通の形の言葉

**「平らな背、側面を通る折り目、短く切った艦首、船体に埋まった装備」**を共通にします。

| 部位 | 共和国の案 | 地球連合との見分け方 |
|---|---|---|
| 船体の断面 | `CREASE` 系の六角断面。上面と下面に幅があり、側面の途中で面が折れる | 地球の上下へとがる断面・竜骨に対し、共和国は平たい密閉容器に見える |
| 上からの輪郭 | 艦首を小さな面で切り、肩から船尾へ大きな直線でつなぐ | 地球の針状艦首・外付けの翼に対し、共和国は船体そのものが輪郭を作る |
| 艦橋 | 背の一部が低く盛り上がる指揮区画。窓列なし | 地球の段のある艦橋・窓の帯と区別 |
| センサー | 艦首の肩、背、腹に暗い光学観測部。前面は短い帯、上下は小さな面 | 帯は窓ではなく光学装置。皿や長い観測塔は付けない |
| 推進器 | 船尾の共通機関ブロック。角ばった外装の奥に6〜8角の噴射口 | 地球の外から見える筒や翼に対し、機関も船体に組み込む |
| 主砲 | 低い無人砲室、細長い角形のレーザー砲身、先端に暗い光学開口 | 地球の大きな台座・砲室・輪のある砲身と区別 |
| 近接防御 | 小さな平たい箱に短いレーザー開口2本 | 地球の半球状の近接防御と区別 |
| ガトリング | 小さな角形の防盾から、短い砲身束だけを出す | 大きな外付け銃座にせず、殻の一部に見せる |
| 濃淡 | 本体は陣営色。折り目より下を一段暗くし、噴射口・光学部・射出口を最も暗くする | 色数や細線を増やさず、少数の大きな面で形を読ませる |

地上車両から引き継ぐのは、**低い姿、密閉された殻、小さな無人砲塔、センサーの帯、共通部品**です。履帯や戦車の長砲身をそのまま宇宙へ持ち込むのではなく、設計上の優先順位を共有させます。根拠：[兵器のスタイルの考察](../../docs/models.md)、[`CREASE` 断面](../../battle/ground-shapes.js)、[共和国車両の実装](../../battle/ground-shapes.js)。

武装の置き方は、次を全艦共通にします。

- **上面以外の砲は、船の前後の中心に置く。** 今回は近接防御・ガトリングにも例外を設けません。
- 側面砲は横の壁に直接取り付け、砲塔の上が外側を向く構造にする。横へ出した台の上には置かない。
- 中心に置くのは砲塔の台座・旋回軸。砲身はそこから前へ伸ばす。
- 主砲・副砲はレーザー。共和国用の誘導ミサイル発射機や魚雷ポッドは提案しない。
- 放熱部を加えるなら、船体とつながった少数の暗い面とし、大きな翼状装置にはしない。

16〜64ピクセルでは細いセンサー帯や砲身だけに頼れません。**真上では肩と艦首、横では背の低さと突出物の少なさ**で分ける設計です。16ピクセルでの成立は未確認なので、Claude の見本では色を消した艦影でも確認する必要があります。

共和国だけの揚陸艇 `lc` は変更しません。丸みのある箱・小型推進器・脚は、降下と着陸のための別系統として共存できます。根拠：[承認済みの揚陸艇](../../battle/shapes.js)。

## 3. 艦ごとの案（7隻）

以下の武装数は、外見を組むための仮案です。性能・射程・搭載数の変更を意味しません。部品の濃淡と低い砲室を共通化し、艦ごとに輪郭を変えます。

役割は現在の共和国の規範を優先しています。以前の艦種考察にある「共和国もフリゲートを短射程化」「強襲母艦を4隻分で数える」などの案は採用しません。根拠：[現在の艦種仕様](../../docs/spec.md)、[共和国の艦種別運用](../../docs/spec.md)、[艦種役割の検討履歴](../../docs/reports/2026-11-06-ship-roles.md)。

### コルベット

**役割：W.A.S. の進路を先に見て、接近先と退路を探す「目」。**

- **上から：** 細い艦首、中央より後ろに幅のある肩。そこから短い船尾へ絞る。独立した翼は付けない。
- **横から：** 薄い船体の背に、ごく低い観測区画。長い機首の棒や背びれは付けない。
- **武装：** 上面前寄りに単装レーザー1基、上面後寄りに近接防御1基。下面中央にガトリング1基。
- **特徴：** 艦首の左右へ分かれた光学観測面。船尾中央の主推進器と、その両肩に小さな姿勢制御口。
- **地球型との差：** 地球は針と翼、共和国は翼のない薄い肩。主砲も地球の腹側に対して上面に置く。

部品は「折り目の船体／観測区画／機関ブロック／小型砲」の四群で足ります。

### フリゲート

**役割：突撃揚陸艦と一緒に進む囮と盾。小型機を払い、W.A.S. の母体を守る。**

- **上から：** 前半に幅のある肩を持つ、短く切った盾形。船尾は細くする。
- **横から：** 前半の装甲殻がやや厚く、後半は低い。高い艦橋はない。
- **武装：** 上面前寄りに単装レーザー1基、下面中央に単装1基。上面の四隅寄りに近接防御4基。左右側面中央にガトリング各1基。
- **特徴：** 前半の大きな斜面と、左右に分かれた暗い観測面。中央の乗員区画を外装の内側へ収める。
- **地球型との差：** 地球の細い矢・背びれ・発射機の張り出しに対し、共和国は前半の広い一体船体。

盾役でも、戦艦のように厚い艦へはしません。現在の共和国フリゲートの機動性を残す姿です。

### 駆逐艦

**役割：上下・側方へ回り、敵の対空艦を崩し、W.A.S. が取り付いた相手へとどめを刺す。**

- **上から：** 細長い中央船体に、船体と密着した左右の装甲面。フリゲートより細く、艦首を長く取る。
- **横から：** ほぼ一定の低さ。中央の折り目だけを強く見せる。
- **武装：** 上面前寄りに2連装レーザー1基、下面中央に2連装1基。上面に近接防御2基。左右側面中央にガトリング各1基。
- **特徴：** 下面の砲室まで含めた中央の武装区画と、船尾左右の機関ブロック。外付けの長い筒は使わない。
- **地球型との差：** 地球型の装甲帯・魚雷ポッドに対し、共和国は連続した殻と上下の低い砲室。

地球の駆逐艦を「盾」に寄せた変更を、共和国へ移さないことが大切です。共和国では機動打撃の役を見せます。

### 巡洋艦

**役割：自治軍時代の最大級の正規戦闘艦。射程の端から敵の対空艦を削る「鎚」。**

- **上から：** 中央から後ろに幅のある、細長い六角形。艦首へ長い斜面を通す。
- **横から：** 背の低い長い船体。中央の指揮区画も背面から少し盛り上がる程度。
- **武装：** 上面前半の左右に2連装レーザー各1基。同じ高さで並べ、背負い式にしない。下面中央に単装副砲1基、左右側面中央に2連装副砲各1基。上面に近接防御4基、下面中央の左右にガトリング各1基。
- **特徴：** 前半へまとまった主砲、後半の大きな機関・放熱区画。前を向いたまま下がって撃つ役割に合う。
- **地球型との差：** 地球は艦橋を挟む前後の主砲と船尾の翼。共和国は低い一体船体と、前半に並ぶ主砲。

条約の上限まで造った艦なので、共和国の正規艦らしさを最も強く出す基準艦に向いています。

### 戦艦

**役割：共和国が開戦後に造る場合の、要塞・重艦への砲撃支援艦。W.A.S. 中心の編成を支える大型艦という仮案。**

第一章の鹵獲戦艦は、この姿に交換しないことを勧めます。

- **上から：** 中央が広く、艦首と船尾を絞った長い多角形。巡洋艦より重い肩と、短く幅の残る艦首。
- **横から：** 厚い低層船体。塔を積み上げず、背と腹に大きな砲室を密着させる。竜骨の大きなひれは付けない。
- **武装：** 上面前後に大型2連装レーザー各1基。下面中央に大型2連装1基。左右側面中央に単装副砲各1基。上面に近接防御4基、下面中央に左右2基ずつ、計4基のガトリング。
- **特徴：** 少数の大きな砲室、幅のある機関区画、厚い中央船体。大きさと主砲で戦艦と分かる形。
- **地球型との差：** 地球は高い段状艦橋、上面3基の主砲、下面の長いレールガン。共和国は低い船体と上下に分かれたレーザー主砲。

**共和国新造艦にレールガンは付けない案を推します。** 地球の例外装備を陣営識別に使え、共和国は巡洋艦のレーザー砲技術を大型化した系統としてまとまります。鹵獲艦なら、地球型のレールガンをそのまま持っていて自然です。

### 戦闘母艦

**役割：共和国が新造する場合の、艦載機による警戒・航空支援艦。W.A.S. の母艦とは分ける仮案。**

- **上から：** 前後の角を大きく落とした長い箱。全面を覆う大きな飛行甲板ではなく、閉じた格納庫の殻が輪郭になる。
- **横から：** 中央が低く盛り上がり、両肩が斜面になる。片舷の高い艦橋はない。
- **武装：** 上面後半の左右に単装レーザー各1基。下面中央に単装1基。上面に近接防御4基。下面中央に左右2基ずつ、計4基のガトリング。
- **特徴：** 艦首寄りの左右に暗い発進口2つ。上面には短い発進の窪みを付け、長い滑走路は描かない。
- **地球型との差：** 地球は平らな甲板と片側の艦橋。共和国は閉じた格納庫と中央の低い背。

共和国が航空支援を重視するようになっても、攻撃の中心まで艦載機へ置き換えたとは扱いません。独自艦の登場時期と性能は未決です。

### 突撃揚陸艦

**役割：W.A.S. を接近先まで運び、放出後は護衛の後ろへ退く母体。**

- **上から：** 前後を短く切った、幅のある密閉船体。巡洋艦のような長い艦首を作らない。
- **横から：** 低い本体の腹に、薄い射出区画が一段付く。艦橋は後半の背に埋め込む。
- **武装：** 上面前寄りに単装レーザー1基。左右側面中央に平たい2連装副砲各1基。上面後半に近接防御2基。腹側には砲を足さず、射出部を空ける。
- **特徴：** 下面に左右2列×4個、計8個の射出ポッド。筒の側面射出口ではなく、下向きの暗いふたを持つ短い箱として見せる。
- **地球型との差：** 地球は上下に稜線のある船体と10機分の射出部。共和国は平たい殻と8機分の射出部。左右の外付け推進筒は付けない。

8機は現在の共和国の基本搭載数です。地球型の見本の10個をそのまま複製しません。根拠：[陣営別の搭載数](../../data/ships.js)、[下向き射出と側面砲の決定](../../docs/models.md)。

### 低ポリで作る際の断面の目安

表は**全長2に正規化した仮の形状比**です。前が `+Z`、船体中央が `z=0`、各組は `(z, 半幅, 半高さ)`。実装では現在の各艦種の外接寸法に合わせて換算し、`data/ships.js` の `scale` を維持する想定です。砲・噴射口・射出区画は別部品です。

| 艦種／scale | 主な船体断面：船尾 → 艦首 |
|---|---|
| コルベット／.55 | `(-1,.12,.06) → (-.5,.24,.09) → (0,.22,.08) → (.65,.13,.055) → (1,.04,.02)` |
| フリゲート／.7 | `(-1,.17,.08) → (-.5,.25,.10) → (0,.34,.12) → (.4,.36,.12) → (1,.12,.055)` |
| 駆逐艦／.85 | `(-1,.16,.08) → (-.5,.26,.11) → (0,.27,.11) → (.55,.20,.08) → (1,.035,.025)` |
| 巡洋艦／1.2 | `(-1,.22,.10) → (-.45,.43,.15) → (0,.40,.15) → (.55,.23,.10) → (1,.06,.035)` |
| 戦艦／1.7 | `(-1,.27,.13) → (-.5,.44,.18) → (0,.46,.19) → (.55,.34,.15) → (1,.12,.065)` |
| 戦闘母艦／1.6 | `(-1,.30,.12) → (-.55,.39,.16) → (0,.39,.17) → (.65,.34,.15) → (1,.18,.09)` |
| 突撃揚陸艦／.9 | `(-1,.22,.11) → (-.55,.30,.15) → (0,.32,.15) → (.6,.30,.14) → (1,.18,.08)` |

各断面を `CREASE` 系の6頂点でつなぎ、艦橋は別の低い殻、砲室は角を落とした箱、砲身・噴射口は6〜8角で作れます。突撃揚陸艦の射出区画だけは、平底の台形断面が適します。

比較元は、現在の共通形ではなく、地球連合用になった [`sp*` の見本](../../battle/ground-shapes.js)です。

## 4. 強襲母艦を陣営で分けるべきかの意見と理由

**最終的には分けることを勧めます。ただし、許可済みの共通形は、新しい見本が承認されるまで維持します。**

強襲母艦は W.A.S.30機・艦載機10機を扱う、この時代の戦い方を代表する艦です。共和国の設計思想を強く示せる艦だけが共通形だと、ほかの7種とのつながりが弱くなります。

分ける場合の案は次です。

| 地球連合 | 惑星共和国 |
|---|---|
| 承認済みの双胴・広い甲板・片側の艦橋を維持 | 双胴と広さは残し、上を低い格納庫の殻で覆う |
| 発着甲板と昇降機が外から分かる | 中央の窪んだ発進路と、甲板より低い格納区画が目印 |
| 外から読める基地としての姿 | W.A.S. の整備・収容を内側へまとめた姿 |

共和国側も双胴を残すのは、承認済みの方向と海上運用を尊重するためです。形を分けても、**各陣営の中では宇宙と海で同じ形**という決定を守るのがよいと考えます。

共通形を維持する案も成立しますが、「共通設計になった由来」は資料で未確定です。由来を今回勝手に足して説明することは避けます。根拠：[強襲母艦の設計と承認](../../docs/models.md)、[搭載数・登場時期](../../docs/spec.md)。

## 5. ユーザーに決めてほしいこと

| 決めること | 選択肢 | おすすめ |
|---|---|---|
| 共和国の共通外観 | **A：低い密閉船体・折り目・埋込装備**／B：骨組みと外付け機器が目立つ工業船 | **A。** 地上車両とつながり、地球型とも分けやすい |
