# 地上基本操作の統合と性能確認（2026-11-09）

PR #376はCI成功・マージ済み。本作業は保存中の旧ブランチから性能・予約・選択円だけを統合したもの。旧見本アイコン、道路占領時間・兵科、士気回復上限の変更は取り込まない。第二章作成は保留。

## 変更

- 経路探索で川・海・沼地の重複判定を削減し、領域の外接矩形で対象を絞る。通行・橋・浅瀬・速度の規則は維持。
- 占領色は近隣の拠点・道路だけを調べ、画素の所属先を保存する。所有者・競合・未探知情報は生きた参照から読む。色の変更時に全道路を再探索しない。再初期化時はキャッシュを破棄。
- 到達不能な敵の追跡でも既存の0.5秒の再探索間隔を守り、毎ステップ探索を繰り返さない。新しい攻撃命令はすぐ探索する。
- Shift予約の経由地と地形迂回点を区別し、矢印・実移動に同じ経路を使う。高度変更、橋の版の変更、戻すでも残りの経由地を保持。
- 地上の選択円を白くし、占領色の後に描く。地形に沿わせ、表示尺度がない場合は既存の地上尺度0.3を補い、途中追加の部隊にも円を作る。
- PR #376のモード解除に加え、通常命令・高度変更・戻すでも入力待ちを消す。
