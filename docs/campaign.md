# キャンペーン

地球連合側のキャンペーン（全5章）の作戦の表と、各節の実装（編成、数値、仕組み）。物語は章ごとのファイル（`docs/chapter1.md` など）、世界設定は `docs/story.md`。
中継ステーションは、会話では略称（信濃、ナイル）で呼び、作戦名には正式名を使う（ユーザー決定 2026-10-02: 「ネオ信濃奇襲」）。ここにある作戦の中身は Claude の叩き台で、ユーザーが直す（ユーザー決定 2026-10-01）。数値やバランスは、作戦を実際に遊んでから決める（ユーザー決定 2026-10-02）。

## 第一章 撤退（叩き台）

章全体のストーリーの叩き台は `docs/chapter1.md`。

A.E. 45（2099年）。惑星共和国が独立を宣言し、人類史上初の惑星間戦争が始まる。
主人公は中継ステーション **ネオ信濃**（略称: 信濃）に配属された地球連合の新人士官。開戦の奇襲で上官が戦死し、臨時に指揮を執る。
章を通して描くのは、撤退戦と惑星共和国の快進撃。後半で、惑星共和国が大量の民間人を巻き込む作戦を行う。

#### プラズマ雲の決まり（数値は仮）

- 雲の中にいる艦隊は、自分の発見距離が半分になる。外からその艦隊を見つける距離も半分になる。両方が雲の中なら、掛け合わせて4分の1。
- 雲の外から雲の中の相手を見張れるのは6秒まで。それを過ぎると見失い、15秒は雲の中のものを見つけられない（Claude が足した決まり。これがないと、一度見つかると雲に入っても振り切れなかった）。両軍に同じく効く。
- 発砲した艦隊は、今と同じく3秒間、距離に関係なく相手に見える。雲の中で撃つと隠れている意味がなくなる。
- 雲の中では、D-RAMS のラム補助が効いて速度が1割上がる（ユーザーはどちらでもよいとした）。
- 雲は動かない。濃さは1種類（濃淡を付けるのは第5節で考える）。
- 見た目: 淡い紫の半透明の塊（1つの雲を5つの球で描く）。カメラが雲の中に入ると薄くなる。

#### 偵察と発見（ユーザー決定 2026-10-03、数値は仮）

- 共和国が自軍の部隊（艦隊か輸送船団）を見つけると、本隊はその部隊へ向かう（`ai:'pursue'`）。見えているあいだは追い続ける。

#### 起きそうな問題と防ぎ方（`wos-strategy`）

1. 戦艦は「いちばん重い艦」を撃つので、推進器を撃たずに砲撃線が止まりかねない。友軍に、並べた目標を順に撃つ `ai:'shell'`（targets の並び。1つ壊すたびに次へ）を足す。
2. 型の切り替えが今のデータでは書けない。`start` に「戦艦が鉱山へ向かった」（`descend`）「着底した」（`land`）を書けるようにし、起爆で槍と鎚を岩の盾へ移す（events で型を替える）。`ward` も並びで書けるようにする。
3. 北の岩の盾は点火まで動かない。「最後の砦」として作戦概要で見せる。槍がそろわないまま待ち続けるのは、そろう待ちを15分で打ち切る。
4. 「推進器を全部壊せば勝ち」と読み違えやすい。作戦概要に「核がなければずれない。押せる距離は鉱山に着いた戦艦の数で決まる」と書く。
5. 戦艦を砲撃線に使うと槍に削られて核を失う。友軍の戦艦が前へ出すぎないよう、出番までの持ち場は南の後ろ（推進器を射程の端から撃てる所）に固定する。
6. 防衛線の予備が棒立ちになる: 岩の盾の陰（shadow）と上下に回る動き（over）は、天体のある作戦では天体を基準にするので、予備がデナリの裏（約230先）に隠れて出てこない。陰を拠点の後ろにする `shade:'ward'` を足す（新）。
7. 防衛線の予備が出撃しない: 点で書いた ward は撃たれた判定が起きない。点のまわり（holdR）の隊が撃たれたら「撃たれた」にする（新）。
8. 段階が時刻でしか切り替わらない: `phases` は時刻（`at`）でしか始まらない。拠点が崩れたら始まる `when:'breach'` を足す（新）。
9. 友軍と敵が置き去りになる（動く作戦フィールド）: 友軍の持ち場は滑らせるときに `ai` の `shift` でずらす。崩れなかった拠点は events の `ai` で推進器の守りへ移す。槍1の `backTo` はデナリの北にし、取り付いたあと北の守りに入れる。槍1の `from` を第29・第30の脇に合わせ、取り付いたら2隊を今の持ち場へ戻す。
10. 何もしないと線の前で膠着する: 14:30 のウォン中将の押し出しで解く。
