# 準備画面とメニュー構成

## 画面の流れ

```
タイトル / メインメニュー（資金と進行を表示）
├─ 出撃 ─ 作戦を選ぶ（キャンペーン / 演習）→ 演習なら出撃する軍集団を選ぶ → 戦闘
├─ 艦隊編集（第一章第2節クリアで解放。前の「編成」）
│   ├─ 軍集団  最大5個の軍を 5×5×5 の立方体に配置して保存。速度同期の有無
│   ├─ 軍      最大5個の戦闘団を編入。能力の合計と編成ボーナスを表示
│   └─ 戦闘団  艦種と隻数を決める（1つの戦闘団は1艦種）
├─ 技術ツリー（第一章第2節クリアで解放）資金で兵科ごとの出撃上限を上げる
├─ 艦艇データ   8艦種の能力表と編成ボーナス一覧
├─ クイック戦闘 用意された艦隊ですぐ戦う（進行と報酬には数えない）
└─ DEBUG（右下、たたんである）
戦闘終了 → もう一度 / メニューへ
```

## 進行・解放・技術ツリー（2026-10-03、ユーザー決定と仮の値）

- 第一章第2節「後退」をクリアすると「艦隊編集」と「技術ツリー」が解放される（ユーザー決定）。それまでメニューには鍵付きで並び、解放の条件が出る（ユーザー決定）。
- キャンペーンの作戦は前の節をクリアすると選べる。演習（要塞カリュブディス攻略戦を自分の軍集団で）は艦隊編集と同時に解放（仮）。
- 進行は保存データの `prog`（クリアした作戦、資金、技術の段階、物語の旗）。前からの保存データは最初の状態から始まる。
- 報酬（仮）: 作戦に勝つと資金が入る。ネオ信濃奇襲 300、後退 400、演習 200。2回目からは半分。敗北と中止は0。クイック戦闘は数えない。数値は `data/operations.js` の `reward` と `data/tech.js`。
- 技術ツリーの形（ユーザー決定 2026-10-03）:
  - 上のタブで「宇宙軍」「地上軍」を切り替える。地上軍は地上戦（第二章〜）で導入する予定で、今は「準備中」。
  - 左の細い縦の欄で兵科を選ぶ。未解放の兵科は出さない。今は巡洋艦まで解放済み（護衛艦艇・駆逐艦・巡洋艦）。戦艦・母艦・W.A.S. 部隊は物語で解放する（時期は未定、W.A.S. は第二章後半〜第三章）。未解放の艦種は艦隊編集でも新しく選べない。
  - 右は、どの研究も〇（アイコン付き）で、相互につながり合う樹形図。左の列の4つ（動員計画、主兵装、装甲、光学探査儀）は最初から研究できる。ほかの研究は、線でつながる元をすべて研究すると始められる。横スクロール（ホイールでも）で左右に動く。研究を押すと下の欄に効果と資金が出て、そこで研究する。
  - 能力は数で出す（今の値 / 最大）。百分率は使わない。
  - 名前は「開発年（A.E.）式＋名前」のフレーバー（例: 38式 誘導魚雷、42式改 荷電粒子砲、試製47式 偏向力場装甲、D-RAMS 第3世代推進器）。主兵装は兵科ごとに名前が変わる（速射レーザー砲・誘導魚雷・荷電粒子砲・大口径主砲など）。名前と形は仮で、`data/tech.js` の `techTree`。
  - 能力（ユーザー決定 2026-10-03）: `data/ships.js` の能力値は研究をすべて終えた最終形態（最大）。自分で編成した艦隊は最初その3割から始まり、研究で上がる（同じ能力の研究を全部終えると10割）。自分で編成した艦隊でないもの（ストーリーの決まった艦隊、友軍、クイック戦闘、敵）には効かない。敵も最初は弱く、章が進むと強くなる（作戦ごとの敵の強さで表す）。
  - 資金（仮）: 左の列から 60・90・130・180・240・320・420（列ごと）。動員計画は出撃上限の段階の資金。兵科ごとの倍率は護衛艦艇・駆逐艦 1、巡洋艦 1.5、戦艦・母艦・W.A.S. 部隊 2。
  - 保存: `prog.tech[兵科] = [研究した節点の id]`。前の形（数や枝ごとの段）は、出撃上限の段だけ引き継ぐ（`migrate()`）。
- 出撃上限（仮）: 兵科ごとの出撃上限（隻数）を上限解放の4段階で上げる。数値は `data/tech.js` の `branches`。

  | 兵科 | 艦種 | 段階1〜4の上限 | 研究の資金（段階2〜4） |
  |---|---|---|---|
  | 護衛艦艇 | コルベット・フリゲート | 24・36・48・64 | 200・400・800 |
  | 駆逐艦 | 駆逐艦 | 16・24・32・48 | 200・400・800 |
  | 巡洋艦 | 巡洋艦 | 6・10・14・20 | 300・600・1000 |
  | 戦艦 | 戦艦 | 4・6・8・12 | 400・800・1200 |
  | 母艦 | 戦闘母艦 | 2・3・4・6 | 400・800・1200 |
  | W.A.S. 部隊 | 突撃揚陸艦・強襲母艦 | 8・12・16・24 | 500・1000・1500 |

  W.A.S. 部隊は物語で解放されるまで上限0で研究もできない（第二章後半〜第三章で解放、ユーザー決定 2026-10-01）。
- 出撃上限は軍集団で出撃するときだけ見る。超える兵科があると出撃できず、出撃画面に兵科ごとの「使う隻数 / 上限」が出る。艦隊編集では上限を超えて組んでもよい（仮）。
- まだないもの: 作戦ごとの補給の上限と、失った艦の天引き（roadmap のフェーズ1「出撃枠と補給の仕組み」）。

- クイック戦闘の自軍: 突撃艇隊、巡洋艦の2戦隊、戦闘母艦の機動部隊、戦艦主軸の第1主力艦隊（2026-10-03 にユーザーの指示で追加。戦艦6・巡洋艦4・駆逐艦4、装甲46・火力4.6・射程26・速度4 は仮）。

## ユニットの階層

| 単位 | 中身 | 戦闘中にできること |
|---|---|---|
| 軍集団 | 軍 最大5個。5×5×5 の配置と速度同期の設定を持つ | 全軍まとめて移動・攻撃。軍をドラッグで出し入れ |
| 軍 | 戦闘団 最大5個 | 1つの艦隊として操作 |
| 戦闘団 | 同じ艦種の艦（艦種ごとに最大隻数あり） | 編成は変えられない |

## 仮の決めごと（未確定）

- 戦闘団は1艦種でまとめる。混成にするかは未定。
- 艦種の能力値（攻撃・防御・回避・射程・視界・隠蔽性・速度、1〜10）と最大隻数はすべて仮。
- 編成ボーナス7種（打撃艦隊、護衛艦隊、機動部隊、前衛偵察、隠密艦隊、強襲揚陸、単一艦種）も仮。
- 戦闘への反映: 攻撃・防御・回避・射程・速度・視界・隠蔽性のすべてを戦闘の計算に使う（索敵は下記）。
- 軍集団の立方体は1マス = 横16・高さ10の間隔で戦場に展開する。前方（敵側）は格子の上側。

## 操作（PC が前提・仮の既定）

- 左クリック（タップ）で自軍の艦隊を選び、宙域をクリックで移動、敵や要塞をクリックで攻撃（ユーザー決定の「タップで選ぶ → タップで移動」のまま）。
- 右クリックでも移動・攻撃を命令できる。右クリックでは選択は変わらない。右ドラッグは視点の平行移動。
- キー: 1〜9 で艦隊を選ぶ（右下の一覧の順）、G で軍集団の全軍（押すたびに次の軍集団、最後に解除）、Shift+クリックで艦隊をまとめて選ぶ、Space で一時停止と再開、Q/E で高度（5ずつ、自由。▲▼ は15ずつの段へ）、WASD で平行移動、十字キーか下のスティックで視点の回転、V で視点の切り替え、F で選択中の艦隊へ寄る、H でパネル、L で名札。
- クリックできるもの（自軍の艦隊、選択中なら敵と要塞）の上ではカーソルが指の形になる。
- 敵や要塞をクリック（右クリックも）すると、その場に小さな選択「攻撃：（敵の名前）」「ここへ移動」が出る。「ここへ移動」はクリックした地点へ、高度バーの高さで移動する。ほかの場所のクリックか Esc で閉じる（閉じるだけのクリックでは命令は出ない）。
- 追撃中の矢印は敵の位置を追い続け、射程に入ると消える。
- 予約指示: Shift+クリックで経由地や攻撃を足す。敵を Shift+クリックすると「攻撃を予約」「ここを経由地に予約」を選べる。攻撃の予約は、今の命令が終わる（移動が着く、または目標を倒すか見失う）と順に始まり、すでに倒した目標は飛ばす。一覧のボタンに「予約N」と出る。経由地は最大8点。艦隊は今の位置から全経由地を通る曲線（Catmull-Rom）で進み、矢印も同じ曲線。Shift なしのクリックは予約を消して直進。高度バーは最後の地点の高さを変える。複数の軍に出すと、各軍の最後の地点を保ったまま陣形ごとずらす。
- 艦隊一覧（右下）の切り替え（ユーザー決定 2026-10-02）: 各隊の行の右に自動/命令（自動交戦/命令優先）のボタン。軍集団の欄には「速度同期/速度個別」「全軍自動/全軍命令/全軍混在」（配下の全軍をまとめて切り替える）と「陣形ON/陣形OFF」、「解散」。速度同期と陣形は戦闘中だけの変更で、編成の保存は変えない（仮）。
- 艦砲の目標: 攻撃を命じた敵が射程内にいれば優先して撃ち、いなければ射程内で一番近い敵を撃つ（ユーザー決定 2026-10-02）。
- 戦闘中のメニュー: Esc か左上の「メニュー」で開く。「続ける」「やり直す」「やめる（敗北）」「操作の一覧」。開いている間は戦闘が止まり、閉じると元の速さに戻る。やめると、終わりの会話なしで敗北の結果を出す（ユーザー決定 2026-10-02）。Esc は前の「選択の解除・会話の早送り・攻撃か移動かの選択を閉じる」には使わない（選択の解除は同じ艦隊をもう一度クリック、会話はクリックか Enter、選択肢は宙域のクリックで閉じる）。
- 戻す: 右上の「戻す」か Ctrl+Z / Backspace で、一つ前の指示（移動・攻撃・予約）を取り消し、その前の命令と予約に戻す。最大30回（仮）さかのぼれる。
- 自動交戦/命令優先（2026-10-02 に交戦/回避から変更、ユーザー決定）: 高度バーの下のボタンか R キー。自動交戦は射程内の敵を撃ち、母艦は近い敵に小型機を出す。命令優先は射程内の敵にも自分からは撃たず、攻撃を命じた相手だけを撃ち、母艦も命じた相手にだけ小型機を出す。その下に「戻す」。一覧のボタンに「自動」「命令」と出る。敵は常に自動交戦。空母系の動き（下がりながら戦う、止まる位置、要塞の内外）はどちらでも同じ。
- 視点のボタン（斜め 24°・真上 88°・真横 3°、仮）は縦の角度だけを変え、横の角度は保つ。
- タッチ操作はそのまま使える。Steam Deck とコントローラーは仕上げで検討する。

## 軍集団の陣形と旗艦（2026-10-02）

- 編成画面の軍集団で、各軍の「☆」を押すとその軍が旗艦になる（★ 旗艦）。決めていなければ最初の軍。立体表示では旗艦の箱が少し大きく明るい。
- 出撃すると、旗艦が展開位置の中心に来て、ほかの軍は立方体の配置どおりに旗艦の周りに並ぶ（1マス = 横16・高さ10）。
- 戦闘中に全軍（G キーか「全軍」）で移動すると、旗艦がクリックした地点へ向かい、ほかの軍は陣形の位置へ向かう。陣形は進む向き（旗艦の今の位置から目的地へ。予約なら最後の地点から）を正面にして回る（ユーザー決定 2026-10-03。前は北向きのまま平行移動だった）。各軍は目的地の周りの自分の持ち場へ直接向かい、旗艦を追いかけない（ユーザー決定 2026-10-03。旗艦の通った道をたどる案は取りやめ）。攻撃を命じると、陣形ON でも全軍がそれぞれ目標へ寄って撃つ（縦陣で後ろの軍が届かなかったのを直した）。
- 軍集団ごとに「陣形ON/陣形OFF」を切り替える（ユーザー決定 2026-10-03。前の「陣形を組み直す」ボタンの代わり）。ON は上のとおり陣形を保って動き、OFF は全軍がクリックした一点へ向かう（隊どうしが重なる）。出撃時の軍集団も、戦闘中に作った軍集団も OFF から始まる（ユーザー決定 2026-10-03）。
- 陣形ON のとき、軍集団の欄の選択で陣形を選べる（ユーザー決定 2026-10-03）: 「出撃時の陣形」（戦闘中に作った軍集団は「編成時の並び」）と、用意した3つの型「横陣」・「縦陣」・「輪形陣」。選ぶとすぐ、旗艦はその場に止まり、ほかの軍が新しい位置（旗艦の向きに合わせて回す）へ動く。そのあとの移動もその陣形を保つ。型では、旗艦も含めて艦種で場所を決める（ユーザー決定 2026-10-03）: 艦艇データの表の上の方（コルベット・フリゲート・駆逐艦）が前衛、下の方（巡洋艦・戦艦・空母系）が後衛。突撃揚陸艦は駆逐艦と同じ。軍の重さは各艦の表の順位の平均。縦陣は軽い軍が先頭で重い軍が最後尾。横陣は一番重い軍が中央、軽い軍ほど外側で少し前。輪形陣は一番重い軍が中央（少し後ろ）、ほかは輪の上で軽い軍ほど前。出撃時の陣形は編成画面のとおりで並べ替えない。軍どうしの間隔は20（仮）、高さは旗艦と同じ（仮）。軍が沈んだり出入りしたりすると、残った軍で詰め直す。「戻す」で組み直しを取り消せる。
- 旗艦が沈むか軍集団から外れると、残っている最初の軍が旗艦の代わりになる。一覧では旗艦に ★ が付く。
- 決まった艦隊で戦う作戦（ネオ信濃奇襲など）は、開始時の並びを陣形とし、最初の隊を旗艦にする。

## 戦闘中の軍集団づくり（2026-10-03）

- 艦隊を Shift+クリック（宙域でも右下の一覧でも）でまとめて選ぶ。もう一度 Shift+クリックで外す。まとめて選んだ艦隊への移動は、各隊の今の並びを保ったまま動く。
- 一覧の一番上の「＋ 軍集団を作る」で、選んでいる艦隊から新しい軍集団を作る（ユーザー決定 2026-10-03）。いくつでも作れるが、1つの軍集団は5個の軍まで。1つの軍は1つの軍集団にだけ入る（ほかの軍集団から移る）。
- 名前は「第N軍集団」（空いている一番小さい N）、最初に選んだ艦隊が旗艦、作った時の並びが陣形、速度同期あり（仮）。
- 各軍集団の欄に「解散」。軍がいなくなった軍集団は消える。一覧のドラッグで軍集団どうし・独立行動の間を移せる（入った軍は、そのときの旗艦との位置が陣形になる）。

## 任務欄（2026-10-02）

- 左上の時計（日時と段階）と「メニュー」の下に、いまやることとゲージを出す（ユーザーの要望: 任務の内容がわかりにくい。2026-10-03 に右上から移す）。その下に、艦隊を選んでいる間だけ高度バーが出る（ユーザーの指示で縦を短くした 2026-10-03）。H でほかのパネルと一緒に消え、クリックで1行にたためる。
- 護衛の作戦: 乗船中は「乗船○%　出港時刻」（金色のゲージ）、出港後は「離脱点まで○%」（青いゲージ）。輸送船の残りと、何隻失うと失敗かを添える。輸送船団は動かせないので、右下の艦隊一覧には入れない（ユーザーの指示）。指示の文は作戦のデータ（`boardText`・`escortText`）で決める。
- 要塞の作戦: 要塞の装甲の残り（赤いゲージ）。

## データファイル

- 艦種と小型機は `data/ships.js`、編成ボーナスは `data/bonuses.js`、作戦は `data/operations.js` にある。下の仮の値はここで直す。
- 作戦の増援は作戦の時計で何分後かを書く（時計は戦闘の1秒で15分進む。ユーザー決定 2026-10-02 で前の10倍、2026-10-03 にさらに3倍にし、そのたびに作戦データの時刻も同じ倍率にして実際のタイミングは変えていない。日をまたぐと日付も進む）。カリュブディス攻略戦は開戦900分後（戦闘の60秒後）に第5戦隊（14隻）が北から来る。
- 作戦を足すと出撃画面に並ぶ。勝利条件は今は要塞の撃破だけで、要塞は戦場の中央に置く。

## 索敵（仮の値）

- 見つけていない敵は表示されず、攻撃もできない。味方の視界は陣営全体で共有する。
- 発見距離 = (60 + 視界×8) × (1 − 隠蔽性×0.04)。視界6の艦隊は隠蔽性5の敵を約86、隠蔽性7の敵を約78の距離で見つける。武器の射程（12〜22）よりずっと広い。
- 発砲した艦隊は3秒間、距離に関係なく相手に見える。
- 見失った敵は最終確認位置に薄い印を30秒残す。攻撃中の敵を見失うと、その位置へ移動に切り替わる。
- 要塞は常に見える。要塞自身も視界8で連合艦隊を見張る。
- 敵は見つけた連合艦隊にしか反応しない。増援の第5戦隊は何も見えないとき要塞の北で待機する。
- 選択中の艦隊のまわりの薄い緑の輪が、隠蔽性5の敵を見つけられる範囲。

## 艦載機とW.A.S.（仮の値）

- W.A.S.（Weaponed Armored Shell、武装装甲化外骨格）。艦名は「突撃揚陸艦」（W.A.S.を運ぶ）と「強襲母艦」（W.A.S.が主力、艦載機も出せる）。戦闘母艦は艦載機（W.A.S.ではない）を積む。
- 1隻あたりの搭載: 戦闘母艦 艦載機40、突撃揚陸艦 W.A.S.10、強襲母艦 W.A.S.30・艦載機10。軍の搭載数は戦闘団の合計。
- 発進: 見えている敵が発進距離（艦載機52、W.A.S.30）に入ると自動で出撃する。1隊は艦載機30機・W.A.S.20機。同時に出られるのは3隊まで、次の隊を出すまでのクールタイムは艦載機3秒・W.A.S.4秒。3隊に入りきらない分は予備として艦内に残る。
- 燃料: 艦載機24秒、W.A.S.16秒。尽きるか周りに敵がいなくなると母艦へ戻る。帰還後は整備（艦載機8秒・W.A.S.10秒）を終えるまで再出撃しない。
- 帰還時の回復: その出撃で失った数の半分を予備から補充する。予備がなければ補充されない。例: 収容120（3隊×30＋予備30）で3隊が10機ずつで戻ると、20機ずつに戻って予備は0。以後の帰還では増えない。
- 艦載機はW.A.S.より射程が長く速いが打たれ弱い。W.A.S.は射程が短いが装甲と火力が高い。艦砲は小型機を狙いにくく、小型機への艦砲の損害は半分。
- 母艦が沈むと、出撃中の隊は戻る場所を失い、燃料が尽きたところで失われる。
- 母艦自身の攻撃と射程は下げた（戦闘母艦は攻撃7→4・射程9→4、強襲母艦は攻撃5→4・射程7→3、突撃揚陸艦は攻撃6→5）。遠くへの攻撃は艦載機が担う。
- 選択中の母艦の青い輪は、砲の射程ではなく発進距離を示す。
- 要塞の内と外: 小型機は、相手側の要塞そのものは自分からは狙わない。母艦が要塞の射程（＋余裕6、仮）の外にいれば外の敵だけ、内にいれば内の敵だけを自分から狙う。射程の外にほかの敵がいなければ母艦へ戻り、母艦もそれだけを理由には発進しない。母艦に攻撃を命じた相手は、内外に関係なく優先して狙い、相手を替えるとすぐ替える。そのあと母艦に移動を命じても（射程内での位置の調整など）、その相手が倒れるか別の相手に攻撃を命じるまで狙い続ける。敵の小型機も同じ（ユーザー決定 2026-10-02）。
- 空母の止まる位置: 空母系だけの軍は、攻撃のとき、敵が小型機の発進距離（積んでいる中で短いほう）の0.8倍（射程の端と艦隊を1:4に内分する点）に入ったら止まる。空母系とほかの艦が混ざった軍は、今まで通り軍の射程の0.75倍で止まり、空母系は隊形の最後尾（進む向きの反対側）に並ぶ（ユーザー決定 2026-10-02）。
- 下がりながら戦う: 空母系だけの軍は、移動の命令中でなければ、見えている敵艦隊がその敵の射程＋余裕6（仮）まで近づくと、敵から離れる向きへ下がる（向きは変えない）。マップの外（中心から215）へは出ない。
- 足止め: 艦載機に攻撃されている艦隊は、0.5秒のあいだ速度が半分になる（仮）。W.A.S. にはない。
- 空中戦（ユーザー決定 2026-10-02）: 小型機の狙いは、母艦に攻撃を命じた相手 → 敵の小型機（届く範囲で、自分の母艦に一番近いもの）→ 近い敵、の順。敵の小型機が母艦へ迫るとそちらへ向き直る（今の相手より母艦に10以上近いとき、仮）。
- 要塞の迎撃（カリュブディス、ユーザー決定 2026-10-02）: 要塞は艦載機120機（30機×3隊＋予備30）を積み、発進距離70（仮）で迎撃に出す。装甲が75%を切ると近衛艦隊、50%を切ると防空隊が自軍に近い隊から20秒ごと（仮）に1隊ずつ、持ち場を離れて追ってくる。
- 狙い: 艦載機だけの戦闘母艦が、巡洋艦以下を相手の射程に入らずに一方的に攻撃できるようにする（ユーザー決定 2026-10-02）。開けた宙域での試し（Claude）: 戦闘母艦3隻（艦載機120）は、追ってくる巡洋艦10・駆逐艦8・コルベット12のどれにも被弾なしで勝つ。要塞の近くや、ほかの敵の射程を横切ると撃たれる。
- 戦闘中の動き（見た目だけ）: 目標の近くでは、原子核の周りの電子のように目標を囲んで飛ぶ。W.A.S. は傾いた輪の上を回り、輪の向きがゆっくり変わるので立体的に群がる。艦載機は前にしか進めないので、目標の片側から反対側へ直線で横切り、端で折り返す（ユーザー決定 2026-10-02）。輪の大きさは目標の大きさ＋射程の0.7〜1.3倍（W.A.S.）・0.9〜1.4倍（艦載機）、回る速さは W.A.S. が速度の0.6倍、艦載機が0.8倍（仮）。戦闘の計算は今まで通り隊の位置で行う。
- 小型機の軌跡（見た目だけ）: 艦載機と W.A.S. の後ろに、陣営色の薄い線を約0.6秒分（0.075秒ごとに8点、仮）引き、後ろほど消える。W.A.S. の線は艦載機より少し濃い色。W.A.S. はときどき（1機あたり毎秒0.5回、仮）背中からごく小さい火花を出す（ユーザー決定 2026-10-02）。
- 艦載機の見た目: ステルス戦闘機と全翼機を合わせた形。後ろ縁がギザギザの後退翼、角ばった胴体と風防、左右の空気取り入れ口、外へ傾いた2枚の尾翼、平たい噴射口（ユーザー決定 2026-10-02。実在の機体名はゲームに出さない）。大きさは W.A.S. より少し大きい程度（長さ約0.9、幅約0.9。W.A.S. は武装まで含めて長さ約0.8、仮）。
- W.A.S. の見た目: 人より一回り大きな強化外骨格。曲線で描き、体は小さく、武装は大きい。肘と膝は適度に曲げる。右手に大きな銃、左肩の上の少し前に砲、背中にバックパックと飛行推進ユニット2基と小さな安定翼、腰にも推進ユニット2基（ユーザー決定 2026-10-02。近接武器は描かない）。画面上の大きさは、体が艦載機の約3分の1、武装まで含めて約7割（仮）。
