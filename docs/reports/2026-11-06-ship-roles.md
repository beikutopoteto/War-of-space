## 3. 要る仕組み

| 役割 | 必要な変更と目安 | 危険・判断 |
|---|---|---|
| 戦艦の重い一撃 | [battle/sim.js](../../battle/sim.js) などで艦種別の再装填と打撃を管理し、[battle/effects.js](../../battle/effects.js) の `beam` を利用。混成対応を含め概算80〜180行 | 今ある砲台用 `every` は隊全体に効き、通常砲撃と向き補正なども異なる。そのまま流用すると混成隊や実効DPSが変わる。光の柱は見本の確認が必要 |
| フリゲートのミサイル | 短射程・DPS自体はデータ変更。飛翔する見た目は効果と射撃処理に概算40〜100行 | 見た目だけなら着弾・迎撃の新ルールは不要。実体のある誘導弾にすると遅延や命中条件で釣り合いが変わる。見本の確認が必要 |

| コルベットの偵察 | 現在も高い視界・隠蔽・速さと、偵察向け行動がある。まず数値変更なしで試す | 混成隊では隠蔽が最低値になり、独立した先行偵察はできない。必要なら分隊や自動先行が別途必要 |

データの例は、強襲母艦だけに `sortieCost: 4` を置き、省略時は1です。

```js
{id:'masc', /* 現在の値 */, sortieCost:4, hangar:{was:30, ftr:10}}
```

- [prep.js](../../prep.js:161) の `groupLoad` は兵科ごとに**実隻数**と**上限消費**を別々に返す。上限消費は `隻数 × sortieCost`。
- 同ファイルの出撃画面・艦隊編集画面では、例えば「W.A.S. 部隊：上限消費 8 / 8、実数2隻」と表示する。強襲母艦1隻が4枠であることも読めるようにする。
- **戦闘規模の上限は実隻数で数える。** 現在は兵科の `used` を合計しているため、重み付きの値をそのまま流用すると戦闘規模まで4倍に数えてしまう。
- 戦闘側には通常どおり実隻数・実搭載数を渡す。4倍の処理は出撃可否の計算だけに置く。既存の保存編成は削除せず、上限超過なら表示して出撃を止める。

目安は `data/ships.js` が約2行、`prep.js` が約30〜60行、確認用テストが約40〜80行です。デバッグの上限無視、複数戦区軍、混成、既存保存データを確認します。

### 混成隊でも艦種ごとに撃つ

データは艦の性能と分けて、例えば戦艦に以下を追加します。**6秒は今回置いた仮の値**です。

```js
weapon: { mode:'salvo', every:6, effect:'beam' }
```

フリゲートは通常砲撃のまま艦種別のDPS・射程を使います。ミサイルの見た目は今回の設計に含めません。

1. [prep.js](../../prep.js:192) の `armyToFleet` と [battle/state.js](../../battle/state.js:57) の `techFleet` で、研究と編成ボーナスを反映した**艦種別DPS・射程**を戦闘用に保持する。隊全体の平均値も移動や既存表示の互換用に残す。
2. [battle/sim.js](../../battle/sim.js:2426) で、現在生きている艦を `ships[].type` で数え、艦種ごとに射程判定・攻撃する。沈没した艦種の火力は次の計算から減らす。戦艦の再装填中も、フリゲートなどは撃ち続ける。
3. 戦艦は例えば6秒ごとに、**その艦種のDPS×6秒**を一度に与える。最大研究の1隻なら `4.45×6＝26.7`。通常射撃と同じ向き・再装填・回避などの補正を適用し、長時間の理論DPSをそろえる。発射時には [battle/effects.js](../../battle/effects.js:71) の `beam` を使う。
4. 命令された目標を優先し、各艦種の射程内なら撃つ。射程外の艦種は撃たない。目標選択も隊平均射程だけに縛られないよう変更する。

混成隊は位置と移動命令を共有するため、艦種別射撃だけでは短射程艦だけが前に出ることはできません。攻撃命令では短射程艦も撃てる距離へ隊ごと近づき、プレイヤーが別の位置を命じた場合はその位置を優先する設計を推します。射程外のフリゲートが撃てないのは距離による結果です。

概算は `prep.js`・`battle/state.js` が計80〜140行、`battle/sim.js` が120〜220行、表示・テストが80〜150行です。既存の砲台、固定値を持つ特別な艦隊、隊の射程を使うAI、再装填中の目標変更、同時発射時の性能への影響が主な危険です。一撃は平均DPSをそろえても、撃ち過ぎや射程外にいる時間によって実戦の損害は変わります。

なお現在の混成隊の耐久は隊全体のプールと平均値で処理され、沈没艦の艦種もその仕組みに従います。駆逐艦の耐久値を上げても、混成隊内で**駆逐艦だけが個別に硬い**挙動にはなりません。今回の戦区軍あたりの耐久条件は満たしますが、個艦ごとの被弾・盾まで求めるなら別の設計が必要です。

### 盾と偵察

駆逐艦を盾として自動的に前へ置くには、地球側の `WOS_DATA.roles` と位置取りを見直します。硬さだけでは敵に狙われる保証がないため、まず前に置く動きで試し、それでも守れなければ狙い・割り込みの変更を検討します。地球側の現行「挟み手」という決定に触れます。

コルベットは現状の高い視界・隠蔽・速さを維持します。単独隊では偵察役を試せますが、混成隊では隠蔽が隊内の最低値になるため、独立した隠密偵察はできません。

## 4. 釣り合いへの影響

共和国の艦種表は変更しません。地球の表を参照する自軍・友軍のうち、作戦データに耐久が明記されていない隊にはフリゲート・駆逐艦の変更が効きます。耐久などを明記した特別な隊は、その指定が優先されます。

共和国の鹵獲戦艦は現在地球の表を使いますが、「共和国は変えない」に合わせ、**新しい戦艦射撃は地球側の自軍・友軍に適用し、敵の鹵獲戦艦には適用しない**設計です。これは現行の「鹵獲戦艦は地球の戦艦と同じ」という扱いに差を作るため、実装時に資料へ反映が必要です。

## 5. ユーザーに決めてもらうこと

今回の決定を反映したうえで、実装前に残る選択です。

1. **駆逐艦の仮数値**
   - 推し：防御4・攻撃4.5を出発点に試す。戦区軍の耐久は戦艦を約2%上回る。
   - 盾の余裕を大きくし、防御をさらに上げる。駆逐艦の耐久増加も大きくなる。

2. **混成隊の移動**
   - 推し：攻撃命令では短射程艦が撃てる距離まで隊ごと近づく。別の位置命令は優先する。
   - 現在の平均射程に基づく移動を維持する。長射程艦が先に撃てる一方、短射程艦が届かない場面が増える。

3. **鹵獲戦艦**
   - 推し：共和国の戦い方を変えないため、敵の鹵獲戦艦には新しい一撃を適用しない。
   - 地球の戦艦と同じ射撃にする。共和国側にも戦闘上の変化が入る。

ユーザーの指示として、駆逐艦の耐久変更、強襲母艦の上限重み、共和国据え置き、混成隊の艦種別射撃を受けました。今回の防御4・攻撃4.5・再装填6秒・上限の重み4は仮の数値です。検討用スクリプトのみ `test-results/` に置き、リポジトリの追跡対象ファイル、コミット、push、PR、`npm test` は扱っていません。
