# 準備画面とメニュー構成

## 画面の流れ

```
タイトル / メインメニュー（資金と進行を表示）
├─ 出撃 ─ 作戦を選ぶ（キャンペーン / 演習）→ 演習なら出撃する戦区軍を選んで「出撃する」、または「クイック出撃」→ 戦闘
├─ 艦隊編集（第一章第2節クリアで解放。前の「編成」）
│   ├─ 戦区軍  最大5個の打撃群を 5×5×5 の立方体に配置して保存。速度同期の有無
│   ├─ 打撃群      最大5個の支隊を編入。能力の合計と編成ボーナスを表示
│   └─ 支隊  艦種と隻数を決める（1つの支隊は1艦種）
├─ 技術ツリー（第一章第2節クリアで解放）資金で兵科ごとの出撃上限を上げる
├─ 艦艇データ   8艦種の能力表と編成ボーナス一覧
├─ オプション   設定画面（ストーリーのオン／オフ）
└─ DEBUG（右下、たたんである）
戦闘終了 → もう一度 / メニューへ
```

## 進行・解放・技術ツリー（2026-10-03、ユーザー決定と仮の値）

- 出撃画面の「出撃する」ボタンは、上の見出し（← メニュー　出撃）の行の右端に置く（ユーザー決定 2026-10-04）。
- 出撃画面の戦区軍は押すたびに選ぶ・外すを切り替え、いくつでも選べる（ユーザー決定 2026-10-04）。出撃上限の表は選んだ戦区軍の合計。出撃すると戦区軍は展開位置に横に並ぶ（間隔56、仮）。
- 配置の段階（ユーザー決定 2026-10-04）: 戦闘画面の上の真ん中に小さな「配置」の欄と「作戦開始」のボタン。展開範囲は作戦の `deployZone`（{pos, r}）、書かなければ展開位置（`deploy`）から半径60（仮）の円で、平面に淡い青で光る。艦隊を押すとその戦区軍を選び、範囲の中を押すと旗艦がそこへ移り、ほかの打撃群は並びを保ってついてくる（範囲の外を押すと、旗艦は範囲の内側の縁に収まる）。
- 艦隊編集の上（説明の下）に、兵科ごとの「持っているすべての支隊の隻数の合計／出撃上限」を出す（ユーザー決定 2026-10-04）。上限を超えた兵科は赤。未解放の兵科は、艦を持っているときだけ「（未解放）」と出す。
- 支隊の画面の艦種は、兵科が開いているものだけ出す（鍵のマークも出さない。ユーザー決定 2026-10-04）。今の艦種が未解放なら、それだけは出す。
- 艦隊編集で新しく作った部隊の名前（ユーザー決定 2026-10-04。決まりは `docs/spec.md`「部隊の名前」、表は `data/ships.js` の `unitNames`）: 支隊は艦種、打撃群と戦区軍は主力の艦種（中で一番上位の艦種。順は `docs/spec.md`「部隊の名前」。2026-10-04 に「隻数が一番多い艦種」から変更）の番号と役割で「第N 役割 規模」。番号は表の番号から始め、同じ階層で使われていれば次の空き番号。打撃群と戦区軍は、空のうちは「第N 打撃群」のように役割なしで、艦が入ると付け直す。名前を自分で書き換えるまでは、艦種や中身が変わると名前も付け直す。支隊が1つだけの打撃群は、その支隊と同じ名前（支隊の名前を変えると付いてくる）。支隊が2つ以上になると「第N 役割 打撃群」に自動で変わり、1つに戻ると支隊の名前に戻る（ユーザー決定 2026-10-04）。最初から持っている打撃群もこの決まりで、物語の第1・2節と同じ名前で出る。
- 第一章第2節「後退」をクリアすると「艦隊編集」と「技術ツリー」が解放される（ユーザー決定）。それまでメニューには鍵付きで並び、解放の条件が出る（ユーザー決定）。
- キャンペーンの作戦は前の節をクリアすると選べる。演習（要塞カリュブディス攻略戦を自分の戦区軍で）は艦隊編集と同時に解放（仮）。
- 進行は保存データの `prog`（クリアした作戦、資金、技術の段階、物語の旗）。前からの保存データは最初の状態から始まる。
- 報酬（仮）: 作戦に勝つと資金が入る。ネオ信濃奇襲 300、後退 400、ナイル防衛線 500、演習 200。2回目からは半分。敗北と中止は0。後退を初めてクリアしたときだけ、司令部からの緊急援助 +1000（ユーザー決定 2026-10-03。`aid`）。クイック出撃は数えない。数値は `data/operations.js` の `reward` と `data/tech.js`。
- 技術ツリーの形（ユーザー決定 2026-10-03）:
  - 上のタブで「宇宙軍」「地上軍」を切り替える。地上軍は地上戦（第二章〜）で導入する予定で、今は「準備中」。
  - 左の細い縦の欄で兵科を選ぶ。未解放の兵科は出さない。今は巡洋艦まで解放済み（護衛艦艇・駆逐艦・巡洋艦）。戦艦・母艦・W.A.S. 部隊は物語で解放する（時期は未定、W.A.S. は第二章後半〜第三章）。未解放の艦種は艦隊編集でも新しく選べない。
  - 右は、どの研究も〇（アイコン付き）で、相互につながり合う樹形図。左の列の4つ（動員計画、主兵装、装甲、光学探査儀）は最初から研究できる。ほかの研究は、線でつながる元をすべて研究すると始められる。横スクロール（ホイールでも）で左右に動く。研究を押すと下の欄に効果と資金が出て、そこで研究する。
  - 能力は今の値を数で出す。百分率も、強化の上限（最大の値）も見せない（ユーザー決定 2026-10-03。艦艇データの表だけは最終形態を載せる）。
  - 樹形図は、左ボタンのドラッグで上下左右に動かし、ホイールで拡大・縮小する。兵科を選ぶと、樹形図が枠に収まる大きさで出る。技術ツリーの画面は縦にスクロールしない（ユーザー決定 2026-10-04）。
  - Enter キー: 技術ツリーでは選んだ研究を「研究する」、出撃画面では「出撃」（ユーザー決定 2026-10-04）。
  - 研究の効果と前提の見方: 〇を押すと下の欄に「防御 巡洋艦 2.4 → 3.3（+0.9）」のような上がり幅、前提の研究（✓済み／✗まだ）、「この先」に開く研究が出る。樹形図では、選んだ〇へ入る線が白く太くなり、前提の〇に白い輪が付く。この〇から先へ出る線は点線。〇にマウスを乗せると名前・資金・上がり幅が出る。同じ系統の研究は同じアイコン。
  - 名前は「開発年（A.E.）式＋名前」のフレーバー（例: 38式 誘導魚雷、42式改 荷電粒子砲、試製47式 偏向力場装甲、D-RAMS 第3世代推進器）。主兵装は兵科ごとに名前が変わる（速射レーザー砲・誘導魚雷・荷電粒子砲・大口径主砲など）。名前と形は仮で、`data/tech.js` の `techTree`。
  - 能力（ユーザー決定 2026-10-03）: `data/ships.js` の能力値は研究をすべて終えた最終形態（最大）。自分で編成した艦隊は最初その3割から始まり、研究で上がる（同じ能力の研究を全部終えると10割）。自分で編成した艦隊でないもの（ストーリーの決まった艦隊、友軍、クイック出撃、敵）には効かない。敵も最初は弱く、章が進むと強くなる（作戦ごとの敵の強さで表す）。
  - 資金（仮）: 左の列から 60・90・130・180・240・320・420（列ごと）。動員計画は出撃上限の段階の資金。兵科ごとの倍率は護衛艦艇・駆逐艦 1、巡洋艦 1.5、戦艦・母艦・W.A.S. 部隊 2。
  - 対空照準の研究（全兵科）: 40式 対空機銃 → 44式 対空誘導弾 → 46式 近接防御網（仮）。
  - 小型機の機体の研究（ユーザー決定 2026-10-03）: 母艦に艦載機（F-38 アクィラ → F-42 ファルコ → F-46 ハルピュイア）、W.A.S. 部隊に W.A.S.（W-21 ルクス → W-24 ノクス → W-27 ウンブラ）。強襲母艦の艦載機にも母艦の研究が効く（機体の研究は、その小型機の兵科 `crafts[].branch` で決まる）。名前は「型番＋名前」（仮）。小型機の火力・耐久・回避が上がる。`data/ships.js` の小型機の値も最終形態で、自分で編成した艦隊の小型機は最初その3割。
  - 母艦の運用の研究（母艦と W.A.S. 部隊、ユーザー指示 2026-10-03）: 出撃部隊数（第2飛行甲板増設 → 多層格納甲板。同時に出撃できる隊が1つずつ増える。`data/ships.js` の maxOut 3 が最終形態で、研究前は1隊）と補給（40式 自動補給機構 → 44式 高速整備ライン → 46式 無人整備システム。帰還後の整備と次の隊の発進間隔が速くなる。速さは3割から始まり、時間は data の値 ÷ 速さ。艦載機の整備は研究前 26.7秒 → 最終 8秒）。小型機を積む艦のすべての小型機に効く。
  - アイコン: 系統ごとに同じ絵（ユーザー決定 2026-10-03）。W.A.S. の機体は設定どおりの姿で、案 C を使う（ユーザー決定 2026-10-03）: 人より一回り大きい外骨格。小さな頭、段差のある胸と細いお腹、肩より上へとがってハの字に開く腕（細い線で胴とつなぐ）、胴と平行に背中から上へ伸びる主砲、腕の機関砲、^ の膝の細い脚と脇のスラスター（細い線で腰とつなぐ）。案 C と予備の案 D（腕が細長い六角形）は `docs/icons/was-c.svg`・`was-d.svg` に残す。
  - 保存: `prog.tech[兵科] = [研究した節点の id]`。前の形（数や枝ごとの段）は、出撃上限の段だけ引き継ぐ（`migrate()`）。
- 出撃上限（仮）: 兵科ごとの出撃上限（隻数）を上限解放の4段階で上げる。数値は `data/tech.js` の `branches`。

  |---|---|---|---|
  | 護衛艦艇 | コルベット・フリゲート | 24・36・48・64 | 200・400・800 |
  | 駆逐艦 | 駆逐艦 | 16・24・32・48 | 200・400・800 |
  | 巡洋艦 | 巡洋艦 | 6・10・14・20 | 300・600・1000 |
  | 戦艦 | 戦艦 | 4・6・8・12 | 400・800・1200 |
  | 母艦 | 戦闘母艦 | 2・3・4・6 | 400・800・1200 |
  | W.A.S. 部隊 | 突撃揚陸艦・強襲母艦 | 8・12・16・24 | 500・1000・1500 |

- 出撃上限は戦区軍で出撃するときだけ見る。超える兵科があると出撃できず、出撃画面に兵科ごとの「使う隻数 / 上限」が出る。艦隊編集では上限を超えて組んでもよい（仮）。

## デバッグ（2026-10-03、ユーザーの指示）

- タイトルの右下の「DEBUG」で開く小さな欄。「作戦と画面を自由に選ぶ（鍵と出撃上限を無視）」「戦闘中のメニューに即勝利・即敗北」の切り替えと、「一節だけクリア」（まだクリアしていない最初の節を、報酬と緊急援助つきで勝ったことにする。2026-10-03）「全作戦クリア」「資金 +1000」「全兵科解放」（研究はせず、物語で開く兵科（戦艦・母艦・W.A.S. 部隊）を開く。2026-10-04）「全研究（全兵科を解放）」「進行を最初に戻す」（進行と、艦隊の支隊・打撃群・戦区軍も最初の状態に戻す。2026-10-04。2回押す）。全作戦クリアでは兵科は巡洋艦までのまま。戦艦・母艦・W.A.S. 部隊が技術ツリーに出るのは、全研究を押したとき（ユーザー決定 2026-10-03）。
- 切り替えは保存データとは別（localStorage の `wos.debug`）なので、進行を戻しても残る。販売版では隠す（仮）。

- クイック出撃（ユーザー決定 2026-10-04。前はタイトルの「クイック戦闘」）: 出撃画面で演習（要塞カリュブディス攻略戦）を選ぶと、「出撃する」の横に「クイック出撃」が出る。用意された艦隊（作戦データの `quick`）で戦い、進行と報酬には数えない。演習は最初から選べ、クイック出撃はいつでもできる。クイック出撃が出るのは演習だけで、キャンペーンの作戦（戦区軍で出撃するナイル防衛線も）には出さない（ユーザー決定 2026-10-05）。自分の戦区軍での「出撃する」は第一章第2節のクリアから（報酬200）。
- クイック出撃の自軍: 第3 突撃艇 打撃群、巡洋艦の第2・第5 巡洋 打撃群、戦闘母艦の第4 空母航空 打撃群、戦艦主軸の第1 主力戦艦 打撃群（2026-10-03 にユーザーの指示で追加。戦艦6・巡洋艦4・駆逐艦4、装甲46・火力4.6・射程26・速度4 は仮）。

## ユニットの階層

| 単位 | 中身 | 戦闘中にできること |
|---|---|---|
| 戦区軍 | 打撃群 最大5個。5×5×5 の配置と速度同期の設定を持つ | 全軍まとめて移動・攻撃。打撃群をドラッグで出し入れ |
| 打撃群 | 支隊 最大5個 | 1つの艦隊として操作 |
| 支隊 | 同じ艦種の艦（艦種ごとに最大隻数あり） | 編成は変えられない |

## 仮の決めごと（未確定）

- 支隊は1艦種でまとめる。混成にするかは未定。
- 艦種の能力値（攻撃・防御・回避・射程・視界・隠蔽性・速度、1〜10）と最大隻数はすべて仮。
- 編成ボーナス7種（打撃艦隊、護衛艦隊、機動部隊、前衛偵察、隠密艦隊、強襲揚陸、単一艦種）も仮。
- 戦闘への反映: 攻撃・防御・回避・射程・速度・視界・隠蔽性のすべてを戦闘の計算に使う（索敵は下記）。
- 戦区軍の立方体は1マス = 横16・高さ10の間隔で戦場に展開する。前方（敵側）は格子の上側。

## 操作（PC が前提・仮の既定）

- 左クリック（タップ）で自軍の艦隊を選び、宙域をクリックで移動、敵や要塞をクリックで攻撃（ユーザー決定の「タップで選ぶ → タップで移動」のまま）。
- 右クリックでも移動・攻撃を命令できる。右クリックでは選択は変わらない。右ドラッグは視点の平行移動。
- キー: 1〜9 で艦隊を選ぶ（右下の一覧の順）、G で戦区軍の全軍（押すたびに次の戦区軍、最後に解除）、Shift+クリックで艦隊をまとめて選ぶ、Space で一時停止と再開、Q/E で高度（5ずつ、自由。▲▼ は15ずつの段へ）、WASD で平行移動、十字キーか下のスティックで視点の回転、V で視点の切り替え、F で選択中の艦隊へ寄る、H でパネル、L で名札。
- クリックできるもの（自軍の艦隊、選択中なら敵と要塞）の上ではカーソルが指の形になる。
- 敵や要塞をクリック（右クリックも）すると、その場に小さな選択「攻撃：（敵の名前）」「ここへ移動」が出る。「ここへ移動」はクリックした地点へ、高度バーの高さで移動する。ほかの場所のクリックか Esc で閉じる（閉じるだけのクリックでは命令は出ない）。
- 追撃中の矢印は敵の位置を追い続け、射程に入ると消える。
- 予約指示: Shift+クリックで経由地や攻撃を足す。敵を Shift+クリックすると「攻撃を予約」「ここを経由地に予約」を選べる。攻撃の予約は、今の命令が終わる（移動が着く、または目標を倒すか見失う）と順に始まり、すでに倒した目標は飛ばす。一覧のボタンに「予約N」と出る。経由地は最大8点。艦隊は今の位置から全経由地を通る曲線（Catmull-Rom）で進み、矢印も同じ曲線。Shift なしのクリックは予約を消して直進。高度バーは最後の地点の高さを変える。複数の打撃群に出すと、各打撃群の最後の地点を保ったまま陣形ごとずらす。
- 艦隊一覧（右下）の切り替え（ユーザー決定 2026-10-02）: 各隊の行の右に自動/命令（自動交戦/命令優先）のボタン。戦区軍の欄には「速度同期/速度個別」「全軍自動/全軍命令/全軍混在」（配下の全軍をまとめて切り替える）と「陣形ON/陣形OFF」、「解散」。速度同期と陣形は戦闘中だけの変更で、編成の保存は変えない（仮）。
- 艦砲の目標: 攻撃を命じた敵が射程内にいれば優先して撃ち、いなければ射程内で一番近い敵を撃つ（ユーザー決定 2026-10-02）。
- 会話の送り方: クリック・Enter で1行進む。Ctrl を押している間は 0.1 秒（仮）ごとに1行進む早送り（ユーザー決定 2026-10-08）。「とばす」で会話を最後までとばす。
- 戦闘中のメニュー: Esc か左上の「メニュー」で開く。「続ける」「やり直す」「やめる（敗北）」「操作の一覧」。開いている間は戦闘が止まり、閉じると元の速さに戻る。やめると、終わりの会話なしで敗北の結果を出す（ユーザー決定 2026-10-02）。Esc は前の「選択の解除・会話の早送り・攻撃か移動かの選択を閉じる」には使わない（選択の解除は同じ艦隊をもう一度クリック、会話はクリックか Enter、選択肢は宙域のクリックで閉じる）。
- 戻す: 右上の「戻す」か Ctrl+Z / Backspace で、一つ前の指示（移動・攻撃・予約）を取り消し、その前の命令と予約に戻す。最大30回（仮）さかのぼれる。
- 自動交戦/命令優先（2026-10-02 に交戦/回避から変更、ユーザー決定）: 高度バーの下のボタンか R キー。自動交戦は射程内の敵を撃ち、母艦は近い敵に小型機を出す。命令優先は射程内の敵にも自分からは撃たず、攻撃を命じた相手だけを撃ち、母艦も命じた相手にだけ小型機を出す。その下に「戻す」。一覧のボタンに「自動」「命令」と出る。敵は常に自動交戦。空母系の動き（止まる位置、要塞の内外）はどちらでも同じ。
- 視点のボタン（斜め 24°・真上 88°・真横 3°、仮）は縦の角度だけを変え、横の角度は保つ。
- タッチ操作はそのまま使える。Steam Deck とコントローラーは仕上げで検討する。

## 戦区軍の陣形と旗艦（2026-10-02）

- 編成画面の戦区軍で、各打撃群の「☆」を押すとその打撃群が旗艦になる（★ 旗艦）。決めていなければ最初の打撃群。立体表示では旗艦の箱が少し大きく明るい。
- 出撃すると、旗艦が展開位置の中心に来て、ほかの打撃群は立方体の配置どおりに旗艦の周りに並ぶ（1マス = 横16・高さ10）。
- 戦闘中に全軍（G キーか「全軍」）で移動すると、旗艦がクリックした地点へ向かい、ほかの打撃群は陣形の位置へ向かう。陣形は進む向き（旗艦の今の位置から目的地へ。予約なら最後の地点から）を正面にして回る（ユーザー決定 2026-10-03。前は北向きのまま平行移動だった）。各打撃群は目的地の周りの自分の持ち場へ直接向かい、旗艦を追いかけない（ユーザー決定 2026-10-03。旗艦の通った道をたどる案は取りやめ）。攻撃を命じると、陣形ON でも全軍がそれぞれ目標へ寄って撃つ（縦陣で後ろの打撃群が届かなかったのを直した）。
- 戦区軍ごとに「陣形ON/陣形OFF」を切り替える（ユーザー決定 2026-10-03。前の「陣形を組み直す」ボタンの代わり）。ON は上のとおり陣形を保って動き、OFF は全軍がクリックした一点へ向かう（隊どうしが重なる）。出撃時の戦区軍も、戦闘中に作った戦区軍も OFF から始まる（ユーザー決定 2026-10-03）。
- 陣形ON のとき、戦区軍の欄の選択で陣形を選べる（ユーザー決定 2026-10-03）: 「出撃時の陣形」（戦闘中に作った戦区軍は「編成時の並び」）と、用意した3つの型「横陣」・「縦陣」・「輪形陣」。選ぶとすぐ、旗艦はその場に止まり、ほかの打撃群が新しい位置（旗艦の向きに合わせて回す）へ動く。そのあとの移動もその陣形を保つ。型では、旗艦も含めて艦種で場所を決める（ユーザー決定 2026-10-03）: 艦艇データの表の上の方（コルベット・フリゲート・駆逐艦）が前衛、下の方（巡洋艦・戦艦・空母系）が後衛。突撃揚陸艦は駆逐艦と同じ。打撃群の重さは各艦の表の順位の平均。縦陣は軽い打撃群が先頭で重い打撃群が最後尾。横陣は一番重い打撃群が中央、軽い打撃群ほど外側で少し前。輪形陣は一番重い打撃群が中央（少し後ろ）、ほかは輪の上で軽い打撃群ほど前。出撃時の陣形は編成画面のとおりで並べ替えない。打撃群どうしの間隔は20（仮）、高さは旗艦と同じ（仮）。打撃群が沈んだり出入りしたりすると、残った打撃群で詰め直す。「戻す」で組み直しを取り消せる。
- 旗艦が沈むか戦区軍から外れると、残っている最初の打撃群が旗艦の代わりになる。一覧では旗艦に ★ が付く。
- 決まった艦隊で戦う作戦（ネオ信濃奇襲など）は、開始時の並びを陣形とし、最初の隊を旗艦にする。

## 戦闘中の戦区軍づくり（2026-10-03）

- 艦隊を Shift+クリック（宙域でも右下の一覧でも）でまとめて選ぶ。もう一度 Shift+クリックで外す。まとめて選んだ艦隊への移動は、各隊の今の並びを保ったまま動く。
- 一覧の一番上の「＋ 戦区軍を作る」で、選んでいる艦隊から新しい戦区軍を作る（ユーザー決定 2026-10-03）。いくつでも作れるが、1つの戦区軍は5個の打撃群まで。1つの打撃群は1つの戦区軍にだけ入る（ほかの戦区軍から移る）。
- 名前は「第N 役割 戦区軍」（中の一番上位の艦種で決める。`docs/spec.md`「部隊の名前」）、最初に選んだ艦隊が旗艦、作った時の並びが陣形、速度同期あり（仮）。
- 各戦区軍の欄に「解散」。打撃群がいなくなった戦区軍は消える。一覧のドラッグで戦区軍どうし・独立行動の間を移せる（入った打撃群は、そのときの旗艦との位置が陣形になる）。

## 索敵（仮の値）

- 見つけていない敵は表示されず、攻撃もできない。味方の視界は陣営全体で共有する。
- 発見距離 = (60 + 視界×8) × (1 − 隠蔽性×0.04)。視界6の艦隊は隠蔽性5の敵を約86、隠蔽性7の敵を約78の距離で見つける。武器の射程（12〜22）よりずっと広い。
- 発砲した艦隊は3秒間、距離に関係なく相手に見える。
- 見失った敵は最終確認位置に薄い印を30秒残す。攻撃中の敵を見失うと、その位置へ移動に切り替わる。
- 要塞は常に見える。要塞自身も視界8で連合艦隊を見張る。
- 敵は見つけた連合艦隊にしか反応しない。増援の第6 本国増援 エスカドラは何も見えないとき要塞の北で待機する。
- 選択中の艦隊のまわりの薄い緑の輪が、隠蔽性5の敵を見つけられる範囲。

- プラズマ雲（第2節）: 中の艦は見つける距離も見つかる距離も半分。外から中の相手を見張れるのは6秒までで、そのあと15秒は雲の中を見つけられない。詳しくは `docs/campaign.md` の第2節。

## 艦載機とW.A.S.（仮の値）

- 当たりやすさ（2026-10-03、ユーザー決定と仮の値）: 艦や要塞の砲が小型機に与える打撃 = 打撃 ×（1 − 小型機の回避）× 0.1 × 撃つ側の対空照準。小型機の回避は艦載機 0.25、W.A.S. 0.45 で、艦載機の方が当たりやすい（前は逆で 0.45 と 0.25、係数は一律 0.5）。対空照準 5 の艦で、艦載機 0.375、W.A.S. 0.275（前の W.A.S. と艦載機の値を入れ替えたもの）になり、これを最終形態とする。
- 対空照準（仮、1〜10）: コルベット5、フリゲート8、駆逐艦4、巡洋艦6、戦艦4、戦闘母艦6、突撃揚陸艦3、強襲母艦4。自分で編成した艦隊は研究前その3割なので、小型機にかなり当たらない。対空照準を書いていない艦隊（決まった艦隊、敵、要塞）は5。数値は `data/ships.js` の `aa` と `WOS_DATA.aa`。
- 小型機同士の戦いも回避が効くので、艦載機は W.A.S. より落ちやすい。

- W.A.S.（Weaponed Armored Shell、武装装甲化外骨格）。艦名は「突撃揚陸艦」（W.A.S.を運ぶ）と「強襲母艦」（W.A.S.が主力、艦載機も出せる）。戦闘母艦は艦載機（W.A.S.ではない）を積む。
- 1隻あたりの搭載: 戦闘母艦 艦載機40、突撃揚陸艦 W.A.S.10、強襲母艦 W.A.S.30・艦載機10。打撃群の搭載数は支隊の合計。
- 発進: 見えている敵が発進距離（艦載機52、W.A.S.30）に入ると自動で出撃する。1隊は艦載機30機・W.A.S.20機。同時に出られるのは3隊まで、次の隊を出すまでのクールタイムは艦載機3秒・W.A.S.4秒。3隊に入りきらない分は予備として艦内に残る。
- 燃料: 艦載機24秒、W.A.S.16秒。尽きるか周りに敵がいなくなると母艦へ戻る。帰還後は整備（艦載機8秒・W.A.S.10秒）を終えるまで再出撃しない。
- 帰還時の回復: その出撃で失った数の半分を予備から補充する。予備がなければ補充されない。例: 収容120（3隊×30＋予備30）で3隊が10機ずつで戻ると、20機ずつに戻って予備は0。以後の帰還では増えない。
- 艦載機はW.A.S.より射程が長く速いが打たれ弱い。W.A.S.は射程が短いが装甲と火力が高い。艦砲は小型機を狙いにくく、小型機への艦砲の損害は半分。
- 母艦が沈むと、出撃中の隊は戻る場所を失い、燃料が尽きたところで失われる。
- 母艦自身の攻撃と射程は下げた（戦闘母艦は攻撃7→4・射程9→4、強襲母艦は攻撃5→4・射程7→3、突撃揚陸艦は攻撃6→5）。遠くへの攻撃は艦載機が担う。
- 選択中の母艦の青い輪は、砲の射程ではなく発進距離を示す。
- 要塞の内と外: 小型機は、相手側の要塞そのものは自分からは狙わない。母艦が要塞の射程（＋余裕6、仮）の外にいれば外の敵だけ、内にいれば内の敵だけを自分から狙う。射程の外にほかの敵がいなければ母艦へ戻り、母艦もそれだけを理由には発進しない。母艦に攻撃を命じた相手は、内外に関係なく優先して狙い、相手を替えるとすぐ替える。そのあと母艦に移動を命じても（射程内での位置の調整など）、その相手が倒れるか別の相手に攻撃を命じるまで狙い続ける。敵の小型機も同じ（ユーザー決定 2026-10-02）。
- 空母の止まる位置: 空母系だけの打撃群は、攻撃のとき、敵が小型機の発進距離（積んでいる中で短いほう）の0.8倍（射程の端と艦隊を1:4に内分する点）に入ったら止まる。空母系とほかの艦が混ざった打撃群は、今まで通り打撃群の射程の0.75倍で止まり、空母系は隊形の最後尾（進む向きの反対側）に並ぶ（ユーザー決定 2026-10-02）。
- 足止め: 艦載機か W.A.S. に攻撃されている艦隊は、0.5秒のあいだ速度が4割になる（仮。2026-10-04 に半分から強め、W.A.S. にも付けた）。
- 空中戦（ユーザー決定 2026-10-02）: 小型機の狙いは、母艦に攻撃を命じた相手 → 敵の小型機（届く範囲で、自分の母艦に一番近いもの）→ 近い敵、の順。敵の小型機が母艦へ迫るとそちらへ向き直る（今の相手より母艦に10以上近いとき、仮）。
- 要塞の迎撃（カリュブディス、ユーザー決定 2026-10-02）: 要塞は艦載機120機（30機×3隊＋予備30）を積み、発進距離70（仮）で迎撃に出す。装甲が75%を切ると第5 要塞近衛 エスカドラ、50%を切ると防空隊が全隊一斉に持ち場を離れて追ってくる（ユーザー決定 2026-10-04）。
- 要塞の陥落後の追撃（ユーザー決定 2026-10-04。作戦データの `chase`）: 第5 要塞近衛 エスカドラは北の離脱点（10, -195、高度30。仮）へ逃げ、地図に輪が出る。段階は「追撃」。ほかの敵艦隊は自軍を追い、見えないときは近衛のそばにつく。近衛を沈めると「完全勝利」、離脱点の10以内に着かれると「勝利」。追撃中に自軍が全滅しても、要塞は落としたので勝利。要塞の前に近衛を沈めていれば、要塞の撃破で完全勝利。
- 狙い: 艦載機だけの戦闘母艦が、巡洋艦以下を相手の射程に入らずに一方的に攻撃できるようにする（ユーザー決定 2026-10-02）。開けた宙域での試し（Claude）: 戦闘母艦3隻（艦載機120）は、追ってくる巡洋艦10・駆逐艦8・コルベット12のどれにも勝つ。2026-10-03 に艦載機を当たりやすくしてからは、巡洋艦10には210のうち30前後被弾する（1隻も失わない。ユーザー決定で被弾してよい）。要塞の近くや、ほかの敵の射程を横切ると撃たれる。
- 戦闘中の動き（見た目だけ）: 目標の近くでは、原子核の周りの電子のように目標を囲んで飛ぶ。W.A.S. は傾いた輪の上を回り、輪の向きがゆっくり変わるので立体的に群がる。艦載機は前にしか進めないので、目標の片側から反対側へ直線で横切り、端で折り返す（ユーザー決定 2026-10-02）。輪の大きさは目標の大きさ＋射程の0.7〜1.3倍（W.A.S.）・0.9〜1.4倍（艦載機）、回る速さは W.A.S. が速度の0.6倍、艦載機が0.8倍（仮）。戦闘の計算は今まで通り隊の位置で行う。
- 小型機の軌跡（見た目だけ）: 艦載機と W.A.S. の後ろに、陣営色の薄い線を約0.6秒分（0.075秒ごとに8点、仮）引き、後ろほど消える。W.A.S. の線は艦載機より少し濃い色。W.A.S. はときどき（1機あたり毎秒0.5回、仮）背中からごく小さい火花を出す（ユーザー決定 2026-10-02）。
- 艦載機の見た目: ステルス戦闘機と全翼機を合わせた形。後ろ縁がギザギザの後退翼、角ばった胴体と風防、左右の空気取り入れ口、外へ傾いた2枚の尾翼、平たい噴射口（ユーザー決定 2026-10-02。実在の機体名はゲームに出さない）。大きさは W.A.S. より少し大きい程度（長さ約0.9、幅約0.9。W.A.S. は武装まで含めて長さ約0.8、仮）。
- W.A.S. の見た目: 人より一回り大きな強化外骨格。曲線で描き、体は小さく、武装は大きい。肘と膝は適度に曲げる。右手に大きな銃、左肩の上の少し前に砲、背中にバックパックと飛行推進ユニット2基と小さな安定翼、腰にも推進ユニット2基（ユーザー決定 2026-10-02。近接武器は描かない）。画面上の大きさは、体が艦載機の約3分の1、武装まで含めて約7割（仮）。
