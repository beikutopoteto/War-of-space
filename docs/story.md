# バックストーリー（叩き台・整理版）

ユーザーの叩き台（2026-10-01）を年表と設定に整理したものです。
表記の揺れや矛盾は **既定案** で仮にそろえ、末尾の「確認事項」に元の表記と一緒に残しています。確定したら確認事項から消して本文を直します。

## 1. 概要

核の誤射で地球が荒廃した後、人類は「地球連合」のもとで統一され、紀年を A.E.（Anthropocene Era／人新世紀）に改めた。
戦災を免れた火星は復興需要で急成長するが、戦争を知らない世代は地球との復興支援条約を「一方的な不平等条約」と見なすようになる。
新型推進器 D-RAMS が戦場からレーダーを奪い、火星の若手将校が密かに育てた W.A.S. が実戦配備されたとき、人類史上初の惑星間戦争が始まる。

## 3. 技術: D-RAMS（重水素推進器）

### 3.1 名称

- 制式名称: **D-RAMS**（ディー・ラムス）
  Deuterium-Radiation Acceleration Magnetic-ramjet System（重水素放射加速・磁気ラムジェット推進機構）
- 現場の通称: 「D・ドライブ（D-Drive）」「重水素ラム（Deut-Ram）」

### 3.2 しくみ（擬似大気吸気サイクル）

ジェットエンジンの「吸気 → 圧縮 → 燃焼 → 排気」を、自分でばらまいた重水素プラズマで成り立たせる。

1. **前方散布**: 船首のパルスノズルから、イオン化した重水素（D⁺）と自由電子を前方へ広角に散布する。
2. **空間電離**: 散布した粒子が進路の前方に、人工の高密度プラズマ空間（電離カーテン）をつくる。
3. **磁気吸気・圧縮**: 船首に展開した漏斗状の超伝導磁場（マグネティック・インテーク）が、自ら撒いたイオンと電子を船の速度を利用して吸い込み、中心軸へ電磁圧縮する。
4. **核融合加熱・噴射**: 圧縮コアでレーザー照射（またはピンチ効果）により D-D 核融合を起こし、高温・高速のヘリウムと陽子のプラズマを後方の磁気ノズルから噴射する。

重水素を選ぶ理由:

- トリチウムと違って放射性崩壊（半減期）がなく、長期備蓄や輸送が容易。
- 重陽子（陽子 1＋中性子 1）は軽水素イオンの 2 倍の質量があり、吸気・排気の運動量交換効率（推力）が高い。

### 3.3 戦場への影響（ゲームの索敵システムの根拠）

- 艦が撒き散らすイオンで電波が乱れ、反射波を受け取って探知する **レーダーは使えない**。戦闘は **有視界戦闘** になる。
- **通信はできる**。通信は送りっぱなしの一方向の信号で、返ってくる必要がないため。
- ゲームの「見つかっていない敵は見えない」「視界・隠蔽性」の設定は、この世界観から来ている。

### 3.4 重水素と火星

- 火星の極冠や地下氷床の水は、地球の約 5 倍の重水素濃度を持つ。
- 地球の重水素は海水から得るしかなく、D-RAMS に不可欠な重水素の多くを火星から運んでいる。これが A.E. 35 年以降の対立の火種になる。

## 6. 確認事項（既定案で仮置き中）

1. **企業名の揺れ**: 「アストロンX」（2041・2045・2052）と「アストラルX」（A.E. 24・35）。→ 既定案: **アストラルX** に統一。
2. **推進器の燃料**: 本文の「トリチウムを使った推進器」の直後に重水素版の設定が続いている。→ 既定案: **重水素（D-RAMS）** に統一し、トリチウムは「重水素を選ぶ理由」の比較にだけ残す。
3. **別の会話からの貼り付けらしい文**: 「科学的事実（…）と完璧に合致し、世界観の説得力が一段と引き締まりました。」「設定を再構築します。」は地の文ではないので削除し、中身（火星の重水素濃度）だけ 3.4 に残した。
4. **重水素はどこにあるか**: 叩き台は「火星大気に大量に有る重水素」だが、火星の大気は薄い二酸化炭素が主で、重水素が豊富なのは極冠や地下の氷。また地球の海水にも重水素は約 150 ppm あり、量としては多い。→ 既定案: 「火星の氷から安く大量に取れる（濃度が地球の約 5 倍）ので、地球は火星からの輸入に頼っている」とする。地球側で取れない理由を強めたいなら「核戦争で海洋の採取施設が壊れたまま」などを足す案もある。
5. **陣営名との対応**: 物語は「地球連合 vs 火星」。→ 既定案: 蒼環同盟＝地球連合、緋星帝国＝火星側。ただし火星は帝国ではなく自治政府なので、緋星側の呼び名（例: 緋星共和国、火星独立軍）か、ゲーム内の陣営名そのものを物語の名前に置き換えるかを決めたい。
6. **組織名の揺れ**: 「地球連合政府」「統一地球連合」「地球連合」。→ 既定案: 組織は **地球連合**、その政府機関を **地球連合政府** と呼ぶ。
7. **プレイヤーはどちら側か**: W.A.S. は火星の兵器だが、ゲームの自軍（蒼環同盟）の艦種に強襲母艦・突撃揚陸艦がある。→ 既定案: 両陣営で遊べる前提にしておき、W.A.S. は戦争の途中で地球側も模倣して配備する。
8. **小さな表記**: 「Armord」→ Armored、「米軍宇宙軍」→ 米宇宙軍、「個別活動」→ 独自行動、「ソ連領」→ 旧ソ連領、「推進機／推進器」→ 推進器、「お幅に」→ 大幅に、で直した。
