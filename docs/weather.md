# 天候（雲・雨・雷・雪）

地上戦と海戦の天候のまとめ。ユーザーの案（2026-11-07）を Claude が整理した。**実装は地上戦の土台（地形・3段の高度・占拠）が動いたあと**（ユーザー「後で実装しましょう」）。数値はすべて未定。

## 1. ねらい

- 3段の高度に意味を足す: 雲は低高度か高高度にあるので、どの段を飛ぶかで見えるものと当たりやすさが変わる。
- 空の優勢への対抗手段: 悪天候のあいだは航空が弱り、地上の側が動ける（史実のバルジの戦いのように）。
- 地形と結びつける: 雨で低い土地がぬかるみ、雪で積雪が積もる。

## 2. 雲の種類と効果（ユーザー案）

雲は低高度か高高度のどちらかの段にある塊。風でゆっくり流れ、行き先は予報として読める（運任せにしない）。

| 雲 | 効果（空・陸・海に共通） | 陸にだけ足すもの |
|---|---|---|
| 雨雲 | 視界不良 | 雨で土地が湿り、移動速度が下がる（4.） |
| 雷雲 | 視界とレーダーの不良（命中率が下がる） | 雨雲と同じ湿り |
| 雪雲 | 視界不良（大） | 積雪が積もり移動速度が下がる。寒さで耐久系のステータスも下がる |

- 空: 雲の中にいる部隊と、雲を通して見ようとする部隊（例: 高高度から低い雲の下の地上を見る）が効果を受ける。
- 陸と海: 雲の真下が雨・雷・雪の効果を受ける。海の艦にも気候のデバフがかかる（ユーザー）。
- レーダーはもとから視界の仕組みに入っている（`docs/reports/2026-11-07-ground-design.md` の決定 2）。雷雲はそれを落とす。

## 3. 陸のデバフの向き（ユーザー）

- 雨・雷（湿り）: **移動速度系**のデバフ。
- 雪: 移動速度系に加えて、**耐久系**（耐久・防御など）のデバフ。積雪はオブジェクトとして積もり、地形の効果に上乗せする（`docs/terrain.md` 0.5）。

## 4. 雨で土地が沼地に変わる（Claude の案に決定、ユーザー 2026-11-07）

- **案A 隠しステータス「湿地」**: マスごとに見えない「湿り気」の値を持つ。値は低い土地・川や海に近い土地ほど高く、雨が降ると上がり、晴れると下がる。しきい値を超えたマスは一時的に沼地として扱う。
- **案B 割合で沼地に変わる**: 雨のあいだ、低い土地や川に近い土地が、決まった割合で沼地に変わる。

**決定（Claude の案）:** 案A を土台にして、案B の「低い土地・川の近くから先に変わる」をその値の初期値で表す。決まった計算で変わるので、どこが沼地になりそうかを気候マップで前もって見せられる（乱数で変えると読めない）。前の「湿地」の考え（ふだんは効果が小さい湿った土地）は、ここで隠しステータスとして生かせる。

## 5. 気候マップ

- 「気候」ボタンで ON/OFF（地形のボタンと同じ、半透明の膜）。
- 雲の塊を段（低・高）ごとに、種類（雨・雷・雪）の色と模様で示し、流れる向きを矢印で出す。
- 雨で沼地になりかけのマス、積雪のマスも示す。
- 部隊の札に、今かかっている天候の効果を出す（命中が下がった理由が見えるように）。

## 6. 出す時期と物語（ユーザー 2026-11-07）

- 天候はキャンペーンの途中から出し、機能（気候マップなど）も途中で解放する。二つ目の演習は晴れだけ。
- 天候は作戦の途中で変わる（雲が流れてくる・晴れる）。
- 最初の天候は第二章の中東（砂漠）の雨。ふつう雨の降らない砂漠に雨が降ることで、デナリの落下（地中海とゴビ砂漠のあたり、`docs/story.md` 年表 A.E. 45.05.06）で気候が乱れていることを示す。

## 7. 決めること

- 効果の大きさ（ユーザーはまだ決めていない。段階で決める案。例: 雨雲は視界 −1 段）。
- 中東のどの節で雨を出すか、広州・海からの上陸で出す天候。
