# 地上・海上の弾道と遮蔽

段階2の実装記録（2026-11-10・対象確認済み）。第一章の宇宙戦には適用しない。距離依存の最小散布円は段階3、連射・一斉射は段階4、航空機の投下進入は段階7。

## 判定と飛翔

- 地点指定の射程・地上／海上の可否を満たしてから、同じ弾道解で発射可否、着弾予測、飛翔時間を求める。
- 間接砲撃は重力下の放物線。仰角と可変の初速から指定地点へ到達する解を求め、到達できない地点や途中で地形・建物に接触する地点への発射を拒否する。障害物の上を通る弾は発射可能。森林を新しい弾止めにはしない。
- 地形は描画と同じ三角形の面を参照し、格子・三角形境界ごとに交差を調べる。薄い建物も水平区間と二次式の高さで調べ、点サンプリングの隙間から通過させない。
- 発射時に散布先・弾道・最初の衝突点を確定する。狙点が通っていても実際の散布先の経路に障害物があれば、そこで着弾する。射手や敵が後から移動しても弾は追尾しない。
- 偵察が見つけた位置と、視界外の予測座標の両方を指定できる。追加の測量操作・観測方式選択は作らない。敵の未発見位置を予測表示のために参照しない。
- 戦車の範囲射撃は直接照準のまま。既存の直接射撃の視界・射線規則を維持し、飛翔時間と飛翔中表示を接続する。
- 広域戦略支援機の旧7秒の地点攻撃は段階7まで暫定維持。自由落下の位置評価は共通エンジンへ用意するが、砲弾用の到達解で爆弾を目標へ誘導しない。

## 単位と仮設定

水平は1km＝4戦闘単位、弾道内部はm・物理秒。描画地形は18倍に誇張されているため、地表の物理高度へ戻して計算する。航空高度は地形の18倍で割らない。seaLevelMを高低差へ重ねて加算しない。

|項目|実装用の仮値|
|---|---:|
|重力加速度|9.81m/s²|
|物理秒／ゲームの飛翔秒|10|
|砲口の地表からの高さ|2m|
|間接砲撃の基準仰角|45度|
|間接砲弾の初速上限|900m/s|
|ロケットの初速上限|1000m/s|
|戦車の直接照準の弾速|1500m/s|

初速は基準仰角で到達する値を距離・高低差から求め、上限を超えれば解なし。飛翔時間は物理計算の結果を10で割ったゲーム秒で、既存の再装填秒とは別。これらはユーザー確定値ではなくゲーム用の仮設定。空気抵抗、推進中のロケット、風の偏流はまだ扱わない。

描画は地表だけ既存の誇張を使い、砲弾の地表からのクリアランスは実寸比で表示する。誇張を砲弾の最高高度へ一律に掛けて航空層より極端に高くしない。敵の射手が未発見なら、飛翔線でその位置を明かさない。

## 表示と負荷

- 範囲指定中に最初の参加隊の予想軌道と着弾までの秒を表示する。複数隊の散布域全体が同じ弾道になるという意味ではない。
- 発射後は弾道線・飛翔中の砲弾・着弾までの秒を描く。選択や取消で発射済みの弾を消さない。
- 選択中の直接／間接射程は32方向×12距離の可射マスクの境界として描き、内部の遮蔽も残す。これは表示用の離散近似で、クリック地点・発射直前は厳密な同じ射線／弾道判定を使う。対空の輪は最大水平射程のまま。
- 静止中は射程マスクを再生成せず、移動中は更新を最大約0.75秒に1回へ制限。部隊の高度変更、建物配列の交換、作戦再初期化を反映する。同じ配列内の地形・建物変更時は明示的にキャッシュを初期化する。予想軌道の描画データも解が変わった時だけ更新。
- 弾道解は射手ごと最大64点を保持。作戦の初期化で消し、発射済みの解は射手から独立して保持する。

## 確認記録

専用弾道30件、対象ブラウザ204件、射程と実発射23件などを通過。射程境界の外側／内側へ散る弾は、狙点の射程判定を通した後に公称射程だけを省いて計算する。発射・補給・再装填を取り消さず、初速上限と衝突判定は維持。予想と実着弾の写真は `tools/ground-ballistics-check.cjs`。初回マスク生成約57.6msは環境依存の実測で、性能保証値ではない。
