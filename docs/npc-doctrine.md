# NPC の規範行動（指揮官の層）

宇宙と地上で共通の、敵と友軍の「指揮官」の設計。2026-11-11、ユーザーの依頼で Claude（Fable 5.2）が設計した。数値はすべて仮で、表は `data/npc-doctrines.js`。頭は `battle/npc-core.js`。

## 1. ねらいと決まったこと

今の AI は「隊ごとの動き」（狙いの分担、挟み撃ち、艦種別の動き、射程に入れば撃つ）だけで、**作戦全体の判断**がない。陽動や増援は作戦ごとのデータに手で書いている。ここで作るのは、その上に載る指揮官の層。

ユーザー決定（2026-11-11）:

- 宇宙と地上で同じ設計にする。今後の更新を見越した土台で、今ある作戦には入れない。作戦ごとに有効にする（`roleAI` と同じ考え方）。
- 例外はバイコヌール演習で、最初にこの AI で敵を動かす。チュートリアル2は有効にせず、敵は動かず撃たない。
- 敵だけでなく友軍も対象。友軍は脇役で、勝ちすぎない制限を付ける。
- 規範は一つ。強さの段階は、判断の速さと読みの深さだけで付ける。
- 連合と共和国は、地上でも戦い方を変える（案は 4.）。
- NPC はプレイヤーと同じ視界を使い、同じ命令を出す（ずるをしない）。
- バイコヌール演習の勝利条件は「敵基地の占領、または敵の全戦力の撃破」。
- 本番のマップはバイコヌール演習（48×36km）よりかなり大きくなりうる（150×100km、300×200km）。その大きさで動くこと。

## 2. 形

```
状況（sit）──▶ 頭 npc-core.js ──▶ 任務の一覧（plan）
   ▲                                   │
   └── 橋渡し npc-ground.js／npc-space.js ◀┘   任務を通常の命令に直す
```

- **頭**（`battle/npc-core.js`）: 状況だけを読み、任務だけを返す。three.js・画面・戦闘の内部に触らないので、Node だけで試せる。宇宙と地上で同じものを使う。
- **橋渡し**: モードごとに1つ。戦闘の状態から状況を作り、任務をプレイヤーと同じ命令（移動・攻撃など）に直す。戦闘の内部の値は書き換えない。
- **規範**（`data/npc-doctrines.js`）: 陣営ごとの性格と、強さの段階。頭はこの表だけで性格が変わる。
- 有効にする書き方: 作戦データに `npc:{1:{doctrine:'mars',level:'standard'}}`（キーは軍の番号。友軍は `side:'ally'` を足す）。書いていない作戦では何も動かない。

こうしておくと、あとでコードを宇宙と地上の2つのモードに分けても、頭はそのまま使える。

## 3. 頭の考え方

指揮官は、拠点（zone）とそのつながり（link）で戦場を見る。1隊ずつ地図を探索しないので、広いマップでも重くならない。考えるのは数秒に1回（強さの段階で決まる）。

1. **見積もる**: 自軍の力、知っている敵の力、その比。拠点ごとの脅威（近い敵ほど強く数える）。敵地をどれだけ最近見たか。見失った敵は時間とともに薄れ、見ていない敵地には守備がいると仮定する。
2. **姿勢を決める**: 攻める・守る・遅滞（下がりながら守る）・偵察。力の比で決める。行ったり来たりしないよう、境目に幅を持たせ、変えるまでに反応の遅れを置く。
3. **任務を立てる**:
   - 守り（hold）: 本営と、前線か脅威のある拠点。攻めているあいだは守りを節約する。
   - 主攻（seize）: 目標の拠点を点数で選ぶ（作戦の目標、近さ、守りの薄さ、補給線を切れるか、取られた拠点か、最近失敗した所は避ける）。そこへの経路の、最初の敵地を取りに行く。
   - 助攻（fix）: 主攻と別の拠点の敵を、突入せずに押さえつける。
   - 遮断（cut）: 敵の本営と前線のあいだの、守りの薄い拠点を取る。
   - 偵察（recon）: 長く見ていない敵地へ。
   - 予備（reserve）と再編（refit）。
4. **隊を割り当てる**: 大事な任務から順に、着くのが早く役の合う隊で埋める。今の任務を続ける隊を優先し、ころころ変えない。士気か補給が減った隊は下げて休ませる。耐久が減った隊（休んでも戻らない）は攻めの最後に回し、守りと予備に使う。火力・打撃・護衛・支援の隊は、主攻（なければ脅威のある守り）に付ける。
5. **段取りを進める**: 主攻は 集結 → 前進 → 突入。集まる前に攻めない。押し返されたら中止して下がり、しばらくその拠点を避けて別の所を狙う。

動きに理由があり、集結という前触れがあるので、プレイヤーは意図を読んで裏をかける。拠点の点数には隊ごとの小さなゆらぎを入れ、毎回少し変わる。指揮官は判断の理由を記録する（`log`）。

役は7つ: 線（line）、突破（shock）、火力（fires）、護衛（screen）、偵察（recon）、打撃（strike）、支援（support）。兵科・艦種との対応は `data/npc-doctrines.js` の `roles`。

## 4. 陣営の性格（仮）

| | 地球連合 | 惑星共和国 |
|---|---|---|
| 考え方 | 火力と線。集めてから一方向を押す | 機動と浸透。固い所を避けて回り込む |
| 攻め始める力の比 | 1.5 | 1.1 |
| 主攻に集める割合 / 予備 | 7割 / 25% | 5割 / 10% |
| 集結 | 8割集まるまで待つ | 6割で出る |
| 助攻・遮断 | 出さない | 出す（補給線を切りに行く） |
| 経路 | 最短を通る | 守りの固い拠点を避ける |
| 取ったあと | 30秒固めてから次へ | 10秒で次へ |

宇宙の性格（連合は大艦巨砲、共和国は W.A.S. が要。ユーザー決定 2026-10-22）と同じ向き。

強さの段階（規範は同じ）:

| | やさしい | 標準 | 難しい |
|---|---|---|---|
| 考える間隔 | 6秒 | 3秒 | 1.5秒 |
| 姿勢を変えるまでの遅れ | 12秒 | 5秒 | 2秒 |
| 見失った敵を覚えている時間 | 30秒 | 60秒 | 120秒 |
| 脅威として数える距離（マップの差し渡し比） | 0.25 | 0.5 | 0.8 |
| 同時の攻めの任務 | 主攻だけ | ＋助攻 | ＋遮断 |
| 敵の力の見積もりの誤差 | ±40% | ±20% | ±5% |

## 5. 友軍

- 作戦の最終目標（`final` の拠点）は取らない。
- プレイヤーの先頭の拠点より先へ出ない（`sit.lead.front`）。
- 取られた拠点の取り返しは自分からは始めない。守りと、プレイヤーが取った拠点の保持が主な役。

## 6. 地上の橋渡し（`battle/npc-ground.js`）

- **拠点**: 作戦の拠点（`groundSites`）。座標は地図の km。半径は拠点の影響円。持ち主は、その軍の視界で見えているときだけ伝える（自軍の拠点は常に分かる）。作戦の説明で分かる初期の持ち主は `known` で渡す。
- **つながり**: 補給の道路網（`groundSupplyNet`）から、拠点と拠点を道路でたどった距離。橋が落ちていれば閉じる。そのため NPC を有効にする作戦は本営（`groundHQ`）を持つこと。
- **隊**: 役、力（兵科の重み × 残りの耐久）、速さ、拠点を取れるか、士気、補給、命令できるか（敗走・搭乗中・基地へ帰投中は不可）、交戦中か。
- **敵**: その軍の接触の記録（`groundContacts`）だけ。見えていない敵の今の位置は使わない。
- **任務 → 命令**: 通常の `order()` と地点砲撃の命令だけを使う。目的地が大きく変わったときだけ出し直す。
  - 守り: 拠点を取れる隊は占拠円の中、ほかは脅威の向きに並ぶ。
  - 主攻: 集結は出発拠点の目標寄り、前進は突破の隊が先、突入で占拠できる隊が占拠円へ入り、ほかは見えている敵を攻撃。
  - 助攻: 目標の手前（射程の8割）で止まり、占拠円には入らない。
  - 偵察: 視界の8割の所で止まる。
  - 火力: 目標から射程の7割、味方の側。打撃・護衛: 主攻の上空と後ろ。支援: 主攻の後ろ。
- NPC が動かす軍では、既存の `groundSupplyAI`（敵の自動の補給帰り）は使わず、頭の再編に任せる。地点砲撃の自動（`groundStrikeAI`）と自動対空はそのまま使う。
- まだ使わないもの（後で足す）: 輸送車への乗車、上陸、架橋、布陣・進撃計画の線、道路の区間だけの占領。

## 7. 宇宙の橋渡し（次の段階）

指揮官は、今は作戦の作者が前もって書いている値（隊の `ai`・持ち場・`leash`・撤退、陽動の出る時刻）を、戦闘中に決める役になる。拠点は要塞・基地・ゲート・宙域・退避点から作る。隊ごとの動き（狙いの分担、挟み撃ち、艦種別の動き、小型機と母艦のつなぎ）は今のまま使う。地上で形が固まってから作る。

## 8. 確かめ方

- **頭だけ**: Node で仮の状況を渡して試す（`tests/npc-core.cjs`）。2026-11-11 の粗い模型では、拠点30・隊60・敵40で1回の判断が約0.5ms。
- **AI どうし**: 実際のゲームで両軍を NPC にして早送りする道具（`tools/npc-sim.cjs`）。演習場・150km・300kmで測る。
- 物差し: 棒立ちの割合（命令も敵もない時間）、主攻への集中（突入のときに主攻にいる力の割合）、最初の接触までの時間、主攻の目標を変えた回数、中止の回数、判断にかかった時間、勝敗と残存。
- **人が遊ぶ**: バイコヌール演習。

## 9. 進め方

1. 頭と規範の表（この PR）。
2. 地上の橋渡し、確かめる道具、バイコヌール演習の敵と勝利条件（Codex）。
3. 測って規範の数値を直す。
4. 宇宙の橋渡し。
5. 友軍、輸送・上陸・架橋の利用。
