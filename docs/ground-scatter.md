# 距離による最小散布円

段階3（2026-11-10）。確定値は自走砲が10kmで最小直径25m、ロケット砲が同30m、10km増すごとに直径2倍。半径や面積の倍増ではない。

|距離|自走砲の最小直径|ロケットの最小直径|
|---|---:|---:|
|10km|25m|30m|
|20km|50m|60m|
|30km|100m|120m|
|40km|200m（自走砲は射程外）|240m|
|50km|400m（自走砲は射程外）|480m|

10km未満は基準値を下限にし、中間は `D10 * 2^((max(10,距離km)-10)/10)` で補間する仮設定。爆風半径は変更しない。戦車・艦・W.A.S.等へ未指定の精度下限を追加しない。

## 指定と実弾

- 円・曲線帯とも、参加射手から中心線の最遠点までの距離と幅を考慮し、必要な最小半径を求める。混成時は一番大きい下限を共通の指定幅へ適用する。幅そのものが距離へ影響するため、下限を安定するまで反復する。
- 指定を細くしすぎると必要な幅へ補正する。上限内で実現できない指定は確定しない。小さい範囲はm単位の直径で表示する。
- 狙点は最小散布分を除いた内側の円／帯から選び、そこへ最小円盤のランダムな散布を加える。これにより意図した散布域に収まり、射程境界で散布円だけを切って精度を上げることを避ける。散布後の軌道は射程を再適用せず、地形との衝突は判定する。
- 発射前に射手の距離から再確認する。射手の移動等で幅が下限を満たさなくなれば残りを中止し、狭い指定を使い回さない。
- 通常の単発API・敵の自走砲／ロケットも距離別の散布を使う。この2兵科は未観測だからという理由で物理的な散布円を倍増しない。見えていない敵の位置を自動追尾するものではなく、指定座標へ撃つ。
- 1〜30の一斉射回数、ロケットの短い連射と長い再装填は段階4。現段階は従来の各隊の射撃回数を維持。

## 確認

専用32件、範囲砲撃27件、砲撃46件、兵科91件、射程と実発射23件、表示34件を通過。実ブラウザの対象141件と、10km付近で半径ゼロを指定しても最小直径約25mが維持される実弾・写真を確認。ページ例外なし。

`tools/ground-scatter-check.cjs` で `.shots/ground-scatter-minimum.png`（1600×900）を撮影。クリック位置は10km付近で、実測の下限表示は25.1m。10kmちょうど等の確定値は専用テストで確認する。
