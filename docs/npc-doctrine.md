# NPC の規範行動（指揮官の層）

宇宙と地上で共通の、敵と友軍の「指揮官」の設計。2026-11-11、ユーザーの依頼で Claude（Fable 5.2）が設計した。数値はすべて仮で、表は `data/npc-doctrines.js`。頭は `battle/npc-core.js`。

## 1. ねらいと決まったこと

今の AI は「隊ごとの動き」（狙いの分担、挟み撃ち、艦種別の動き、射程に入れば撃つ）だけで、**作戦全体の判断**がない。陽動や増援は作戦ごとのデータに手で書いている。ここで作るのは、その上に載る指揮官の層。

ユーザー決定（2026-11-11）:

- 宇宙と地上で同じ設計にする。今後の更新を見越した土台で、今ある作戦には入れない。作戦ごとに有効にする（`roleAI` と同じ考え方）。
- 例外はバイコヌール演習で、最初にこの AI で敵を動かす。2026-11-11の追加指示で、案内なしのカリュブディス演習も試験場にする。チュートリアル2は有効にせず、敵は動かず撃たない。
- 敵だけでなく友軍も対象。友軍は脇役で、勝ちすぎない制限を付ける。
- 規範は一つ。強さの段階は、判断の速さと読みの深さだけで付ける。
- 連合と共和国は、地上でも戦い方を変える（案は 4.）。
- NPC はプレイヤーと同じ視界を使い、同じ命令を出す（ずるをしない）。
- バイコヌール演習の勝利条件は「敵基地の占領、または敵の全戦力の撃破」。
- 守り方の型は4つ（固守・遅滞・機動防御・縦深）。既定は連合が固守、共和国が機動防御。本営はどの型でも捨てない。
- 本番のマップはバイコヌール演習（48×36km）よりかなり大きくなりうる（150×100km、300×200km）。その大きさで動くこと。

## 2. 形

```
状況（sit）──▶ 頭 npc-core.js ──▶ 任務の一覧（plan）
   ▲                                   │
   └── 橋渡し npc-ground.js／npc-space.js ◀┘   任務を通常の命令に直す
```

- **頭**（`battle/npc-core.js`）: 状況だけを読み、任務だけを返す。three.js・画面・戦闘の内部に触らないので、Node だけで試せる。宇宙と地上で同じものを使う。
- **橋渡し**: モードごとに1つ。戦闘の状態から状況を作り、任務をプレイヤーと同じ命令（移動・攻撃など）に直す。戦闘の内部の値は書き換えない。
- **規範**（`data/npc-doctrines.js`）: 陣営ごとの性格と、強さの段階。頭はこの表だけで性格が変わる。
- 有効にする書き方: 作戦データに `npc:{1:{doctrine:'mars',level:'standard'}}`（キーは軍の番号。友軍は `side:'ally'` を足す）。書いていない作戦では何も動かない。

こうしておくと、あとでコードを宇宙と地上の2つのモードに分けても、頭はそのまま使える。

## 3. 頭の考え方

指揮官は、拠点（zone）とそのつながり（link）で戦場を見る。1隊ずつ地図を探索しないので、広いマップでも重くならない。考えるのは数秒に1回（強さの段階で決まる）。

1. **見積もる**: 自軍の力、知っている敵の力、その比。拠点ごとの脅威（近い敵ほど強く数える）。敵地をどれだけ最近見たか。見失った敵は、位置だけが時間とともに薄れ、数は覚えている（力の比には数え続ける）。見ていない敵地には守備がいると仮定する。
2. **姿勢を決める**: 攻める・守る・遅滞（下がりながら守る）・偵察。力の比で決める。行ったり来たりしないよう、境目に幅を持たせ、変えるまでに反応の遅れを置く。
3. **任務を立てる**:
   - 守り（hold）: 本営と、前線か脅威のある拠点。攻めているあいだは守りを節約する。守りの姿勢でも、取られた拠点の取り返しと、隣の守りの薄い拠点（中立など）は余力で取りに行く。
   - 主攻（seize）: 目標の拠点を点数で選ぶ（作戦の目標、近さ、守りの薄さ、補給線を切れるか、取られた拠点か、最近失敗した所は避ける）。そこへの経路の、最初の敵地を取りに行く。
   - 助攻（fix）: 主攻と別の拠点の敵を、突入せずに押さえつける。
   - 遮断（cut）: 敵の本営と前線のあいだの、守りの薄い拠点を取る。
   - 偵察（recon）: 長く見ていない敵地へ。
   - 予備（reserve）と再編（refit）。
4. **隊を割り当てる**: 拠点を取れる隊は少ないので、先に攻めの任務へ1つずつ確保する。そのうえで大事な任務から順に、着くのが早く役の合う隊で埋める。今の任務を続ける隊を優先し、ころころ変えない。士気か補給が減った隊は下げて休ませる。耐久が減った隊（休んでも戻らない）は攻めの最後に回し、守りと予備に使う。火力・打撃・護衛・支援の隊は、主攻（なければ脅威のある守り）に付ける。
5. **段取りを進める**: 主攻は 集結 → 前進 → 突入。集まる前に攻めない。前進は目標の手前（攻撃の位置）までで、主攻がそろってから一斉に突入する。突入してしばらくたち、その場の敵に力で負けているか、隊を失ったら中止して下がり、しばらくその拠点を避ける（経路でも避け、ほかに道がなければその方向へは攻めない）。取りに出た拠点は、見積もりが少し揺れたくらいでは変えない。

動きに理由があり、集結という前触れがあるので、プレイヤーは意図を読んで裏をかける。拠点の点数には隊ごとの小さなゆらぎを入れ、毎回少し変わる。指揮官は判断の理由を記録する（`log`）。

役は7つ: 線（line）、突破（shock）、火力（fires）、護衛（screen）、偵察（recon）、打撃（strike）、支援（support）。兵科・艦種との対応は `data/npc-doctrines.js` の `roles`。

## 4. 陣営の性格（仮）

| | 地球連合 | 惑星共和国 |
|---|---|---|
| 考え方 | 火力と線。集めてから一方向を押す | 機動と浸透。固い所を避けて回り込む |
| 攻め始める力の比 | 1.5 | 1.1 |
| 主攻に集める割合 / 予備 | 7割 / 25% | 5割 / 10% |
| 集結 | 8割集まるまで待つ | 6割で出る |
| 助攻・遮断 | 出さない | 出す（補給線を切りに行く） |
| 経路 | 最短を通る | 守りの固い拠点を避ける |
| 取ったあと | 30秒固めてから次へ | 10秒で次へ |

宇宙の性格（連合は大艦巨砲、共和国は W.A.S. が要。ユーザー決定 2026-10-22）と同じ向き。

強さの段階（規範は同じ）:

| | やさしい | 標準 | 難しい |
|---|---|---|---|
| 考える間隔 | 6秒 | 3秒 | 1.5秒 |
| 姿勢を変えるまでの遅れ | 12秒 | 5秒 | 2秒 |
| 見失った敵を覚えている時間 | 30秒 | 60秒 | 120秒 |
| 脅威として数える距離（マップの差し渡し比） | 0.25 | 0.5 | 0.8 |
| 同時の攻めの任務 | 主攻だけ | ＋助攻 | ＋遮断 |
| 敵の力の見積もりの誤差 | ±40% | ±20% | ±5% |

## 5. 友軍

- 作戦の最終目標（`final` の拠点）は取らない。
- プレイヤーの先頭の拠点より先へ出ない（`sit.lead.front`）。
- 取られた拠点の取り返しは自分からは始めない。守りと、プレイヤーが取った拠点の保持が主な役。

## 6. 地上の橋渡し（`battle/npc-ground.js`）

- **拠点**: 作戦の拠点（`groundSites`）。座標は地図の km。半径は拠点の影響円。持ち主は、その軍の視界で見えているときだけ伝える（自軍の拠点は常に分かる）。作戦の説明で分かる初期の持ち主は `known` で渡す。
- **つながり**: 補給の道路網（`groundSupplyNet`）から、拠点と拠点を道路でたどった距離。橋が落ちていれば閉じる。そのため NPC を有効にする作戦は本営（`groundHQ`）を持つこと。
- **隊**: 役、力（兵科の重み × 残りの耐久）、速さ、拠点を取れるか、士気、補給、命令できるか（敗走・搭乗中・基地へ帰投中は不可）、交戦中か。
- **敵**: その軍の接触の記録（`groundContacts`）だけ。見えていない敵の今の位置は使わない。
- **任務 → 命令**: 通常の `order()` と地点砲撃の命令だけを使う。目的地が大きく変わったときだけ出し直す。
  - 守り: 拠点を取れる隊は占拠円の中、ほかは脅威の向きに並ぶ。
  - 主攻: 集結は出発拠点の目標寄り、前進は突破の隊が先、突入で占拠できる隊が占拠円へ入り、ほかは見えている敵を攻撃。
  - 助攻: 目標の手前（射程の8割）で止まり、占拠円には入らない。
  - 偵察: 視界の8割の所で止まる。
  - 火力: 目標から射程の7割、味方の側。打撃・護衛: 主攻の上空と後ろ。支援: 主攻の後ろ。
- NPC が動かす軍では、既存の `groundSupplyAI`（敵の自動の補給帰り）は使わず、頭の再編に任せる。地点砲撃の自動（`groundStrikeAI`）と自動対空はそのまま使う。
- 道路: 脅威のない守りか予備の1隊が、本営から自軍の拠点までの道路の区間を占領してつなぐ。主攻の最後尾の隊も、通りながら経路上の区間を取る。再編の隊は、補給が届いている一番近い地点で止まる。
- 火力: 間接火力は、任務の目標の中か主攻の近くの見えている敵へ砲撃する（味方が着弾の範囲にいる地点は撃たない）。
- まだ使わないもの（後で足す）: 輸送車への乗車、上陸、架橋、布陣・進撃計画の線、補給部隊による補給、海の艦の移動。

## 7. 宇宙の橋渡し（`battle/npc-space.js`、2026-11-11 実装）

ユーザー指示（2026-11-11）「宇宙のほうは、要塞攻略演習にその AI の動きを組み込み、試験場にしてよい」。案内なしのカリュブディス演習を対象にした。`npc` があり、地上でも案内中でもない作戦だけで動く。頭・規範値・隊の狙い分担・上下の挟み撃ち・艦種別の動き・艦載機の仕組みは変えない。

- **拠点**: 作戦の `npcZones`。円内（水平距離）に片軍の艦隊だけが連続で仮10秒いれば保有する。固定物・艦載機・退場隊は数えない。競合・無人は時計をリセットし、無人なら以前の持ち主を保つ。要塞を含む本営は要塞生存中その軍のもの。画面には出さない。
- **つながり**: `npcLinks` の無向辺。距離は水平直線距離。カリュブディスの拠点表と16辺、仮の距離は `docs/menu.md`「宇宙NPC」。
- **情報**: 自軍保有は常に分かり、ほかの拠点の現在の持ち主は艦隊の視界で見えた場合だけ。初期の持ち主は作戦で既知の `known`。敵艦隊は `updateFog()` の発見結果だけを記憶し、見失ったら最後の位置・力と時刻を保持する。視界外の死亡では消さない。役は最重量艦種、力は残存隻数×hp×dmgを巡洋10隻で割った値。固定・退避・未到着などは任務を与えない。
- **任務 → 隊の値**: `ai`・`post`・`leash`・`watchPos`を変化時だけ更新する。古い移動や、新しい持ち場の外への攻撃は解除し、通常の `enemyAI()` に任せる。
  - hold: 円の半径をleashとし、水平と高度にずらしてguard。
  - seize: 集結は出発拠点でguard、前進は目標のr＋射程の手前でguard、突入は目標にwatchPosを置いてhunt。
  - fix: 射程8割の手前でguard、小さいleash。cutはhunt、reconはscout（既存の巡回点と高度も渡す）。
  - reserve・refit・retire: 拠点でguard、小さいleash。
  - 支援: 任務の拠点の味方側でguard。母艦はlaunchR内に置く。
- **台本との境界**: NPC有効時は装甲75%・50%によるsortieを使わない。増援は到着してから指揮官の隊に入る。要塞陥落後の`startChase()`以降は判断・適用を止め、従来の追撃に任せる。案内中はsortieも含め従来どおり。勝敗・時計・報酬は変更しない。`npcDebug()`は地上・宇宙の有効な軍を返す。
- **確認**: `tests/npc-space.cjs`（Nodeとsmoke）、`tools/npc-sim.cjs charybdis mars earth standard 1 900`（`--no-npc`で台本比較）。自軍は既存のautoAI。`tools/npc-measure.cjs`へNPCあり／なし・seed1〜2を追加。実測結果と未実行は状態メモで区別する。

頭に足りない入力・現状の境界（頭は変更しない）:

- 頭の状況には要塞の残存装甲・被弾の緊急度が無い。現在は観測した敵の接近から本営の脅威を判断する。装甲低下そのものを見た緊急の守備変更はできない。
- 頭の前進→突入は拠点半径による距離で判定する。宇宙の射程・高度や、実際の前進持ち場への到着は入力にないため、射程が長い隊や高度差の大きい作戦では段取りの精度に限界がある。
- 既存`pickFoe()`は候補が空になると、現在の攻撃目標を保持する場合がある（両スコアがInfinity）。NPCの宇宙守備だけ、任務変更時と毎ステップでleash外の攻撃命令を解除して持ち場へ戻す。候補を選ぶ共通AIは変更しない。
- このブランチの設計書には、作業票が参照する9.7節がまだない。型は既存の頭と`styles`データ（共和国既定mobile）をそのまま使用する。

## 9.5 実ゲームで測った結果（2026-11-11、`tools/npc-measure.cjs`、数値は仮のまま）

- 演習場・AI どうし（青=連合12隊、赤=共和国8隊、600秒）: 2回のうち1回は青が288秒で全滅させて勝ち、1回は決着なし。
- バイコヌール演習・自軍は何もしない（300秒）: 敵は62秒で北橋（自軍の本営）、128秒で中央渡河地、271秒で西の葦原を取った。力の比が0.8なので姿勢は「守り」のまま、空いた拠点を余力で取る動き。
- 150km・AI どうし（各12隊、900秒）: 占領は1回だけ。補給が20%未満の隊が最大8隊。広いマップでは補給線の伸ばし方がまだ足りない。
- 判断1回は平均0.2ms。ゲーム本体のステップは150kmで平均22ms（視界の計算 groundUpdateSight が1回7.5msで2回、経路探索 groundPath が1回27ms）。重さはゲーム側の課題。
- 接触の記録は、視界の外で倒された敵もすぐ消える（敵が生きているかを見ている）。厳密には「倒したのを見た」かどうかの記録が要る。

## 9.7 作戦の意図と守り方の型（実装、数値は仮）

作戦データの `op.npc[軍].intent` を橋渡しが `sit.goal` へ渡す。省略時は `seize`。`type` は `seize`（取る）・`hold`（守る）・`delay`（時間を稼ぐ）・`withdraw`（逃がす）。`zones` は捨てない拠点のID、`until` は遅滞の期限（ゲーム秒）、`style` は守り方の型。

- `hold` と期限内の `delay` は力の比にかかわらず守りの姿勢。期限後は従来の力の比と反応遅れで姿勢を決める。期限省略の `delay` は守りを続ける。期限が近いほど拠点を手放しにくくする。
- 型は姿勢が `defend` / `delay` のときだけ適用。`withdraw` は遅滞型。それ以外は明示の `style` を優先し、未指定で姿勢が `delay` なら遅滞型、ほかは規範の既定（連合=固守、共和国=機動防御）。型の表を渡さない指揮官は従来の守りを使う。
- 捨てない拠点（must）は `zones` と本営。型の `abandon` による放棄の対象外。守備任務への割当は残る隊の力に制限される。

|型|守りと取り返し|
|---|---|
|固守 `firm`|指定拠点を厚く守り、失った必須拠点を取り返す。空いた拠点には出ない|
|遅滞 `delay`|前線だけを持ち、強い脅威で下がる。取り返しも空いた拠点の占領もしない|
|機動防御 `mobile`|守備を薄く予備を多く持つ。近い脅威に反応し、余力で取り返し・空いた拠点の占領を行う|
|縦深 `depth`|後ろの線にも守備を置く。二本以上の線が残る間に取り返し、必須拠点は線の数にかかわらず取り返す|

`withdraw` は姿勢 `delay` とし、前線ごとに殿を1隊残し、ほかを `retire` で `zones[0]`（未指定なら本営）へ退かせる設計。橋渡しは `retire` を通常の移動へ直し、到着後は待機させる。道路係には使わない。型が変わると `style:<型>` を log に残す。

確認は `tests/npc-core.cjs`（型・意図・切り替え）、`tests/npc-ground.cjs`（意図の入力と退避移動）、`tests/npc-sim.cjs`（引数と集計）。計測例:

```sh
node tools/npc-sim.cjs exercise2 earth mars standard 1 600 --intent0 seize --intent1 hold:firm:F,E --brief
node tools/npc-sim.cjs exercise2 earth mars standard 1 600 --intent0 seize --intent1 delay:delay:F:300 --brief
```
