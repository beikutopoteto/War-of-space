# war-of-space

宇宙空間での艦隊戦をテーマにした 3D リアルタイムストラテジーゲームの試作です。

- `index.html`: Three.js を使ったブラウザ版の試作。戦闘画面と、準備画面を読み込むシェル。ブラウザで開けば動きます。
- `data/`: 艦種、編成ボーナス、作戦（マップ）のデータ。コードを触らずに数値と作戦を足せます。
- `prep.js` / `prep.css`: メインメニュー、出撃、編成（軍集団・軍・戦闘団）、艦艇データの画面。編成はブラウザの localStorage に保存します。
- `tests/smoke.cjs`: 自動確認。`npm install` のあと `npm test` で、ヘッドレスのブラウザが主な画面と戦闘を一通り動かします。PR ごとに GitHub Actions でも走ります。
- `docs/`: 仕様（`spec.md`）、操作と仮の数値（`menu.md`）、ロードマップ、キャンペーン、ストーリー、設定。
- `CLAUDE.md`: 作業の進め方と資料の案内（Claude Code が毎回読む）。`.claude/` にサブエージェントとスキル（`/ship`、`/tidy-docs`）。
- 陣営: 自軍「地球連合」、敵「惑星共和国」（オリジナル設定）。
