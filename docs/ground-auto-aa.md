# 独立した自動対空

段階5（2026-11-10）。航空機以外の対空装備は独立した迎撃時計と目標を使う。地上・海上・空中W.A.S.が対象で、戦闘機・攻撃機・広域戦略支援航空機は通常の対空命令を維持する。

- 装備射程、対象高度、味方の共有視界と射線がそろう場合だけ迎撃する。150kmの武器射程でも未発見の航空機には撃たない。
- 移動、Shift予約、地上目標への攻撃、範囲砲撃、一斉射、再装填は迎撃で置き換えない。対空だけを理由に追跡移動しない。
- 沈黙、搭載、工事、不在、敗走、帰投中は撃たない。groundHoldFireとgroundAAEnabledは設定用フックで、新しいUIは追加しない。engage／evadeの通常目標選択とは独立する。
- 対空間隔は従来のfireEvery（1秒）の仮値を維持し、発射ごとに既存の補給消費を適用する。対空解決中の専用入口だけが打撃を許可する。
- 地上・海上部隊から航空機への手動攻撃は受け付けず、移動・予約・戻す履歴も消さない。混成選択では航空機だけに手動対空を渡す。既存の小メニューに自動迎撃と表示する。
- チュートリアル2は自走対空砲を選んで自動迎撃を確認する手順へ変更。案内前の訓練航空だけはその手順で有効にし、早期撃墜による行き詰まりを防ぐ。案内をとばした場合や通常演習はこの目標保護を適用しない。敵は従来どおり攻撃しない。

## 確認

専用30、兵科91、砲撃46、射程26、操作53、補給70、再集結3のNode確認。チュートリアル26手順を完走、敵の打撃・損害0。通常演習は敵の攻撃ありで占拠勝利。

対象ブラウザ確認204件成功。実演習でW.A.S.の範囲砲撃と重強化歩兵の移動・予約が迎撃で変化しないこと、航空機の手動対空、専用入口以外の打撃拒否、宇宙へ戻る際の表示解除を確認。ページ例外なし。

台本tools/ground-aa-check.cjs、写真.shots/ground-aa-moving.png（1600×900）。撮影は明示した試験配置を使い、対空確認機の耐久は複数の操作を確認できる値へ一時設定している。通常演習の性能を変更していない。

段階8の性能対応：装填中は全航空目標への射線探索を繰り返さない。保持する対象は生存・発見・範囲だけを軽く確認する内部状態で、射撃許可ではない。実射時は距離順に候補を試し、最初の有効な射線で選び直す。遮蔽の再確認を省略して撃つことはない。追加の対象確認結果は段階8で記録する。
