# 惑星共和国のコルベット・フリゲートの案（Codex、2026-11-13）

Codex（gpt-6.1-sol、推論 high、読み取り専用）に頼んだ案。ユーザーは有名な SF 映画の艦を参考に挙げたが、公開リポジトリのため作品名・艦名・外部の資料は書かず、考え方だけを残す（`CLAUDE.md`「いつも守ること」）。設計は `docs/models.md` 15.15。

## 1. 参考にした考え方（要約）

**おすすめは、コルベットが「A：片肩の観測艇」、フリゲートが「A：H形の双胴護衛艦」。** 小さく表示したときにも、非対称の一体船体と、前後に切れ込みのある双胴という違いが残る。案名・寸法・配置はすべて仮案で、性能の変更は提案しない。

- 小型のコルベットの、機関を船尾にまとめ、前後で仕事を分ける構成。共和国では前を観測・乗員区画、後ろを機関区画とする。
- 小型の貨物船の、左右で異なる機能を持たせて非対称を輪郭に出す方法。コルベット A では、片側に長い観測区画を組み込む（円盤や横へ突き出す操縦席ではなく、折り目のある密閉船体に置き換える）。
- 輸送・支援機の、運ぶ戦力とそれを守る火器を1つの機体にまとめる考え方。フリゲートでは、揚陸艦と進むための対小型機の火器を船体の四隅や側面へ分ける（可動翼は採らない）。

共和国へのつなげ方は、少人数の乗員区画を内側にまとめ、観測・火器・機関の配置から外形を作ること。細部は、大きな装甲面のあいだに短い配管の溝や暗い放熱面を置き、機械としての大きさを感じさせる。

寸法表記は `(z, 半幅, 半高さ)`。前は `+Z`、船体断面の中心は `y=0`、前後の中心は `z=.025`。左右の位置は `x`。全案で、折り目の上下2色、短く切った艦首、窓のない低い指揮区画、埋め込みの装備を保つ。

## 2. コルベットの案3つと、おすすめ

### A：片肩の観測艇――おすすめ

**一方の肩だけが前後に長く張った、非対称の小型艦。** 観測装置を横棒にせず、船体の片側へ収めます。

- **上から：** 左肩が長く、右舷はほぼ直線。艦首は中央より少し左に寄った短い切断面。前方だけに横長の頭を載せません。
- **横から：** 薄い船体に、低い観測区画がなだらかにつながる。独立した艦橋や背びれはありません。
- **正面：** 左へ長い、低い折れた六角形。左右非対称の幅が目印です。

**主な部品・寸法**

船体断面は次を目安にし、断面中心の左右位置もずらします。

| z | 半幅 | 半高さ | 断面中心x |
|---:|---:|---:|---:|
| −1.00 | .17 | .065 | 0 |
| −.55 | .23 | .075 | −.03 |
| .05 | .31 | .080 | −.11 |
| .55 | .24 | .065 | −.15 |
| 1.05 | .10 | .045 | −.15 |

指揮区画は `z=−.30〜−.05`、半幅 `.075`、船体上への高さ `.03`。左肩の前面と外側面に、離して置いた光学面を設けます。主機は船尾中央、小さな補助噴射口は船尾外装に埋め込みます。

**武装位置**

- 上面単装：`(x=−.08, z=.52)`。
- 上面近接防御：`(x=0, z=−.62)`。
- 下面ガトリング：`(x=0, z=.025)`。中央の平らな底へ直接取り付ける。

**見分けられる理由**

片肩の偏りが船体全長の半分以上に続きます。地球型の針と後退翼、共和国駆逐艦の前割れ、巡洋艦の左右対称のひし形と区別できます。戦闘母艦の非対称とは、**張り出しが前寄りで、甲板や島がない**ことで分けます。

### B：尾広のくさび

**船尾が最も広く、艦首へ素直に細くなる、機関の塊が目立つ艦。**

- **上から：** 後端の広い台形から、短い平面の艦首へ絞る。途中に翼や細い首を挟みません。
- **横から：** 船尾が少し厚く、前へ向かって薄くなる一枚のくさび。
- **正面：** 中央の小さな艦首の後ろに、幅のある低い船体が見える。

**主な部品・寸法**

船体：

`(−1,.32,.085) → (−.60,.32,.085) → (.20,.21,.065) → (.75,.13,.050) → (1.05,.09,.040)`

船尾の一体機関区画に、噴射口を横に3つ。指揮区画は `z=−.25〜.05`、半幅 `.07`、高さ `.03`。光学面は艦首の左右角へ埋め込みます。

**武装位置**

- 上面単装：`(x=0, z=.48)`。
- 上面近接防御：`(x=0, z=−.70)`。
- 下面ガトリング：`(x=0, z=.025)`。

**見分けられる理由**

最大幅が船尾まで続くため、中央の広い巡洋艦・戦艦とは重心が違います。地球型コルベットの翼の間を、こちらは厚みのある船体で埋めます。**先端の尖りではなく、幅のある船尾**を主な目印にする案です。

### C：前後二室の鼓形

**観測区画と機関区画の間に、短いくびれを持つ艦。** 前後の塊を両方残し、細い棒の先に頭を載せる形から離します。

- **上から：** 前後に長さのある二つの塊と、中央のくびれ。前室は横棒ではなく、縦長の観測室です。
- **横から：** 前後の区画は同程度の厚さ。中央も高さを保ち、細い連結棒にはしません。
- **正面：** 前室の低い六角形。その外側に、わずかに広い後室の肩が見える。

**主な部品・寸法**

船体：

`(−1,.19,.080) → (−.65,.30,.090) → (−.35,.27,.085) → (−.12,.12,.075) → (.25,.12,.075) → (.48,.25,.085) → (.85,.23,.075) → (1.05,.13,.050)`

後室に機関、前室に観測区画。指揮区画は前室後端の `z=.35〜.55` に低く組み込みます。中央の上下面は、切れずにつながる装甲面とします。

**武装位置**

- 上面単装：`(x=0, z=.70)`。
- 上面近接防御：`(x=0, z=−.65)`。
- 下面ガトリング：`(x=0, z=.025)`。くびれの底に付ける。

**見分けられる理由**

中央のくびれが、ひし形やエイ形と逆の輪郭を作ります。前室・後室とも十分に長いため、現在のT字やシャベル形とも違います。ただし、16ピクセルではくびれが消えやすく、Aより見本での調整が必要です。

**コルベットはAを推します。** 「先を見る目」を、センサーの小さな飾りではなく、片側に長い観測区画として表せます。Bは最も作りやすく、Cは区画の違いを強く出したい場合の候補です。

## 3. フリゲートの案3つと、おすすめ

### A：H形の双胴護衛艦――おすすめ

**左右の長い装甲船体を、中央の幅広い区画でつないだ艦。** 前後の中央に深い切れ込みを残します。

- **上から：** 太いH形。左右の船体は艦首から船尾まで続き、中央の接続区画が乗員・指揮区画になります。
- **横から：** 低く一定の厚さ。中央にだけ、ごく低い指揮区画が載る。
- **正面：** 左右の六角断面が高く、奥の接続区画が低い、浅い凹形。

**主な部品・寸法**

左右船体は `x=±.29` に配置。それぞれの局所断面：

`(−1,.11,.095) → (−.65,.13,.115) → (.65,.13,.115) → (1.05,.10,.080)`

中央接続区画：

`(−.28,.40,.090) → (.35,.40,.090)`

左右船体の間隔は約 `.32`。前後の切れ込みは、それぞれ長さ約 `.70` を確保します。指揮区画は接続区画後寄り、主機は左右船体の後端です。

**武装位置**

- 上面単装：中央接続区画の `(x=0, z=.18)`。
- 上面近接防御4：左右船体の `(x=±.29, z=±.62)`。
- 下面単装：中央接続区画の `(x=0, z=.025)`。
- 側面ガトリング各1：左右の最外側面、`z=.025`。

**見分けられる理由**

駆逐艦は前だけが割れますが、こちらは**前後両方が割れ、中央で太くつながるH形**です。地球型フリゲートの中央の矢先や誘導弾ポッドもありません。ひし形、エイ形、片側飛行甲板、貨物列とも輪郭が重なりにくい案です。

### B：三列機関の後割れ艦

**前半は一つの船体、後半は三つの短い機関区画に分かれる艦。**

- **上から：** 短い艦首から後方へ広がり、船尾に3本の太い歯が並ぶ。切れ込みは後ろだけです。
- **横から：** 前半は低い装甲殻。後半の機関区画も同程度の高さでつながる。
- **正面：** 切った艦首の背後に、左右へ広がる低い肩が見える。

**主な部品・寸法**

前方の一体船体：

`(−.30,.48,.120) → (.15,.39,.120) → (.65,.23,.095) → (1.05,.13,.065)`

後方の機関区画は `x=−.40／0／+.40` の3列。各区画は `z=−1〜−.25`、半幅 `.08`、半高さ `.085`。前端を一体船体へ十分に食い込ませます。

機関区画間の空きは約 `.24`。単なる噴射口の違いではなく、外形に二つの深い切れ込みを作ります。指揮区画は中央の `z=−.15〜.10`。

**武装位置**

- 上面単装：`(x=0, z=.65)`。
- 上面近接防御4：`(x=±.30, z=−.12)` と `(x=±.16, z=.43)`。
- 下面単装：`(x=0, z=.025)`。
- 側面ガトリング各1：一体船体の左右側面、`z=.025`。

**見分けられる理由**

3本の船尾が最大の特徴です。前割れの駆逐艦やH形とは、切れ込みの向き・数が違います。輸送船型揚陸艦の貨物列とも、長い一体の前半と、少数の太い機関区画で分けます。コルベットBより幅があり、船尾も分割されます。

### C：中央横胴の十字形

**中央の防御区画を左右へ厚く広げ、前後に短い船体をつないだ艦。**

- **上から：** 角を落とした太い十字形。最も広い場所は前方ではなく、船の中央です。
- **横から：** 中央区画が少し厚く、前後が一段低い。側方の張り出しにも船室の厚みがあります。
- **正面：** 幅広い低い六角形に、中央の主砲が小さく載る。

**主な部品・寸法**

船体：

`(−1,.16,.085) → (−.42,.18,.090) → (−.32,.46,.130) → (.38,.46,.130) → (.48,.18,.090) → (1.05,.13,.060)`

中央横胴の長さは約 `.70`。指揮区画は後方の `z=−.80〜−.50`、半幅 `.075`、高さ `.03`。船尾の狭い船体に噴射口を2つまとめます。

**武装位置**

- 上面単装：`(x=0, z=.65)`。
- 上面近接防御4：中央横胴の `(x=±.29, z=±.18)`。
- 下面単装：`(x=0, z=.025)`。
- 側面ガトリング各1：中央横胴の左右端、`z=.025`。

**見分けられる理由**

輪郭の四つのくぼみと、中央の直線的な横胴が目印です。戦艦のエイ形とは、薄く流れる肩ではなく、**厚い横胴と急な段差**で分けます。現在のシャベル形のように前半だけを広げません。

**フリゲートはAを推します。** 近接防御4基を左右船体の前後へ自然に分けられ、中央の下面砲と側面ガトリングも無理なく接続できます。「盾」は前の大きな板ではなく、火器を分散して揚陸艦を守る構成で表せます。

## 4. 作るときの注意

- **小さな識別点を、砲身や色に任せない。** 長さ16ピクセルなら、モデル上の幅 `.25` が約2ピクセルです。双胴の間隔、三列機関の隙間、鼓形のくびれは、この程度の差を残す目安にします。16・32・64ピクセルでの成立は未確認です。
- **片肩Aは、左右対称の断面幅だけでは作れない。** 断面中心をずらす形状か、基幹船体と十分に重なる片肩区画で作ります。既存の `mA` に断面中心xを渡すだけでは反映されません。
- **双胴・三列機関の接続を薄い板にしない。** 接続区画には高さを持たせ、側方船体へ食い込ませます。境界をぴったり合わせるだけだと、視点によって隙間が見えます。
- **十字形の横胴を翼にしない。** 中央船体と同じ折り目・上下色・厚さを持たせます。薄くすると戦艦のエイ形へ近づきます。
- **武装は台座の位置で「真ん中」を守る。** 下面砲と側面ガトリングの旋回軸を `z=.025` に置きます。側面砲は外側へ向くよう回転し、折り目の壁へ直接接続します。
- **砲塔の接地面は、装甲の実際の高さから取る。** 複数船体の案では、中央船体の高さを左右船体へ使い回すと浮きます。底面砲は反転後の台座、側面砲は回転後の台座まで確認が必要です。
- **砲身と機関外装を含めて全長を収める。** `mGun` は砲身が前へ伸び、`mEng` は指定zより後ろへ出ます。船体断面だけを `−1〜1.05` に合わせて終わらせないようにします。
- **細部は少数の大きな面にする。** 光学面・放熱面・配管溝を区画ごとにまとめ、細線の全面貼りは避けます。ガトリングもレーザーの発射口束として扱い、弾薬箱や排莢口は加えません。
