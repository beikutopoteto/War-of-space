# ユーザーが決めた仕様

ユーザーが決めた仕様の一覧。勝手に変えない。変わったら日付つきでここを直す。
戦闘や画面の動きを変える前に、このファイルを読む。細かい操作と仮の数値は `docs/menu.md`。

- **見た目:** 戦況図風。中央に要塞小惑星、同心円のグリッド、陣営アイコン、太い進軍矢印、時刻と解説パネルを置く。版権の名前は使わない。
  - 自軍は「地球連合」（青）、敵は「惑星共和国（アストラルリパブリック）」（赤）。要塞は「カリュブディス」。設定は `docs/story.md`。
- **3D の意味:** モデルではなく戦闘空間が 3D で、上下にも自由に動ける。
  - 操作は「タップで選ぶ → タップで移動」のまま、高度は左の高度バーか Q/E で指定する。高度バーの ▲▼ は 0 から上下に15ずつの段へ動く。バーのドラッグと Q/E は自由に動かせる（ユーザー決定 2026-10-03）。
  - 射程と距離は 3D で測る。
  - 艦隊ごとに「自動交戦」か「命令優先」を選べる（2026-10-02 に「交戦/回避」から変更）。自動交戦は射程内の敵を撃ち、母艦は近い敵に小型機を出す。命令優先は攻撃を命じた敵だけを撃ち、母艦も命じた敵にだけ小型機を出す。どちらでも攻撃を命じた敵を優先する。高度バーの下で切り替え、その横に「戻す」（一つ前の指示の取り消し）を置く。右下の艦隊一覧でも、各隊ごとと戦区軍の全軍まとめて切り替えられる。戦区軍の速度同期もそこで切り替える（ユーザー決定 2026-10-02）。
  - 移動の矢印は勝手に曲げない。矢印は実際の航路と同じ。予約指示（経由地）を足すと、A→B→C を自然な曲線でつないで進む。敵への攻撃も予約できる（ユーザー決定 2026-10-02）。
  - 敵部隊をクリックしたら「その地点へ移動」か「その敵を攻撃」かを選べる（敵の真上や真下へも移動できる）。敵を追っている間の矢印は敵を追尾する。
- **対象:** PC 向けだけで売る。スマホの画面は考えない（ユーザー決定 2026-10-03）。
- **画面:** 戦場を隠すポップアップや説明パネルを嫌う。UI は小さく半透明で、たためるようにする。
  - パネルは H、名札は L で消せる。
  - 戦闘中は Esc か左上の「メニュー」でいつでもメニューを開く（続ける・やり直す・やめる・操作の一覧）。開いている間は止まり、やめると敗北になる。「戻す」（Ctrl+Z / Backspace）で一つ前の指示を取り消す（ユーザー決定 2026-10-02。左上へ移したのは 2026-10-03）。
  - 任務欄（いまやることとゲージ）は左上の時計の下に置く（ユーザー決定 2026-10-03）。
  - 視点は3つのボタン（斜め/真上/真横）を並べた押し分け式で、押したボタンの色が変わる。V で順に切り替える。視点のボタンは縦の角度だけを変え、横の角度は変えない。
  - 横回転と上下の角度は、画面の下に分けて置いた2本のスティック（倒している間回り続け、離すと戻る）と十字キーで変える。WASD は平行移動（ユーザー決定 2026-10-03）。
- **メニューと進行（ユーザー決定 2026-10-03）:** 第一章第2節をクリアすると「艦隊編集」（編成画面）と「技術ツリー」が開く。それまではメニューに鍵付きで並び、解放の条件を出す（隠さない）。メニューには DEBUG 欄（自由に選ぶ、戦闘中の即勝利・即敗北、全作戦クリア、資金、全研究、進行のリセット）を置く。全作戦クリアでは兵科は巡洋艦まで。戦艦・母艦・W.A.S. 部隊は全研究で出る。
- **技術ツリー（ユーザー決定 2026-10-03）:**
  - 艦種と小型機の能力値（`data/ships.js`）は、研究を終えた最終形態（最大）。自分で編成した艦隊は最大の3割から始まり、研究で上がる。自分の編成でない艦隊（ストーリーの決まった艦隊、友軍、クイック戦闘）と敵には効かない。敵も最初は弱く、章が進むと強くなる。
  - 上に「宇宙軍」「地上軍」のタブ（地上軍は将来）。左の細い縦の欄で兵科を選ぶ。未解放の兵科は出さない（今は巡洋艦まで）。
  - 右は、どの研究も〇とアイコンで、始まりが複数あり、相互につながる樹形図。横スクロール。研究の上がり幅と前提の研究は、〇を押すと下の欄に出る。
  - 能力は百分率でなく数で出す。強化の上限（最大の値）は見せない。
  - 全兵科に対空照準の研究。艦載機の機体の研究は母艦に、W.A.S. の機体の研究は W.A.S. 部隊に出す（強襲母艦の艦載機にも母艦の研究が効く）。母艦系には同時に出撃できる隊の数と補給の研究も置く。
- **ユニット階層:**
  - 戦区軍: 打撃群を最大5個。5×5×5 の立方体に配置して保存する。戦闘中もドラッグで打撃群を出し入れでき、最も遅い艦に速度を合わせるかを選べる。旗艦を決めると、設定した陣形を旗艦を中心に組む（ユーザー決定 2026-10-02）。戦闘中も新しい戦区軍を作れる: Shift+クリックで艦隊をまとめて選び、「＋」を押す。戦区軍ごとに陣形の ON/OFF を切り替え、ON は陣形を保って動き、OFF は指示した一点に全軍が集まる（ユーザー決定 2026-10-03）。陣形ON のときは、出撃時の陣形と用意した3つの型（横陣・縦陣・輪形陣）から選べ、選ぶとすぐ組み直す。陣形は最初 OFF。陣形のまま動くときは進む向きを正面にし、各打撃群は目的地の持ち場へ直接向かう（旗艦を追わない）。攻撃は陣形ON でも全軍がそれぞれ寄って撃つ。型の陣形では、旗艦も含めて艦種で並べる（表の上の方が前衛、下の方が後衛。突撃揚陸艦は駆逐艦と同じ。重い艦は後ろと中央）（ユーザー決定 2026-10-03）。
  - **出撃と配置（ユーザー決定 2026-10-04。これからの作戦もすべてこの決まり）:** 戦区軍で出撃する作戦では、戦区軍をいくつでもまとめて出撃できる。条件は、選んだ戦区軍の艦の合計が、兵科ごとの出撃上限（技術ツリー）を超えないこと。同じ打撃群を含む戦区軍は一緒に選べず、片方を選ぶともう片方は暗くなり「同一支隊を含みます」と出る。戦闘は、出撃前の会話のあと時間が止まった「配置」から始まり、作戦ごとに決めた展開範囲の中なら、戦区軍を好きな場所に置ける。「作戦開始」で時間が動き出す。決まった艦隊で戦う作戦（第一章第1・2節）は物語の配置のまま。
  - 打撃群: 戦闘で操作する艦隊。支隊を最大5個持ち、編成によってボーナスが付く。
  - 支隊: 戦闘中は編成を変えられない。
- **艦種:** コルベット、フリゲート、駆逐艦、巡洋艦、戦艦、戦闘母艦、突撃揚陸艦、強襲母艦の8種。
  - 戦闘母艦は艦載機（W.A.S. ではない）を積む。
  - 突撃揚陸艦は W.A.S. を運ぶ。
  - 強襲母艦は W.A.S. が主力で、艦載機も出せる。
- **部隊の名前（ユーザー決定 2026-10-04）:** 「第N 役割 規模」。規模の言葉は階層ごとに1つに固定する。
  - 地球連合（米中方式）: 戦区軍（大戦略・方面）／打撃群（主力作戦・艦隊）／支隊（前線戦術・最小の複合単位）。画面の階層名もこの3つ（以前の 軍集団／軍／戦闘団）。
  - 惑星共和国の軍「惑星自治軍」（露日方式）: 戦線／エスカドラ／戦闘隊。敵の部隊名に使う。
  - 艦種ごとの役割と番号の表は `data/ships.js` の `unitNames`（例: コルベット 第1 警備哨戒 戦区軍・第3 局地警戒 打撃群・第12 沿岸哨戒 支隊、惑星自治軍の戦艦 第4 決戦突破 戦線・第1 主力砲撃 エスカドラ・第2 砲戦突破 戦闘隊）。複数の艦種の部隊は主力（旗艦）の艦種で付ける。
  - 通称のある部隊は、通称を役割の位置に入れる（第2 ネオ信濃駐屯 戦区軍、第20 ドナウ残存 支隊、第5 要塞近衛 エスカドラ）。会話や地の文では「駐屯隊」「ドナウ残存隊」のような呼び方のままでよい。
- **W.A.S.:** Weaponed Armored Shell（武装装甲化外骨格）。以前の名前「M.A.S.」は使わない。
- **ステータス:** 攻撃、防御、回避、射程、視界、隠蔽性、対空照準（と速度）。対空照準は艦の砲が艦載機と W.A.S. に当てる力（ユーザー決定 2026-10-03）。
- **デザインの方向性（ユーザー決定 2026-10-03。次の見た目の作業はこれに合わせる）:**
  - 進め方: アイコンや形などの見た目は、まず見本の画像（大きく線を細くした拡大図と、ゲームでの実際の大きさ）を見せ、ユーザーが直しを重ねて許可を出してから、ゲームに入れる。案を出すときは複数並べる（A・B…）。採用しなかった案も残すよう言われたら `docs/icons/` に SVG で残す。
  - 絵文字は使わない（鍵の絵文字は「ダサい」として、文字色の細い線の絵に替えた）。アイコンは文字色の細い線で描き、面は薄く塗る程度。同じ系統（同じ武器の型違いなど）は同じアイコンでよい。
  - 形はスタイリッシュに: 曲線より、三角や多角形の角を使った、細身でとがった形を好む（W.A.S. のアイコンで、曲線の案から角の案に変わった）。部品の接合部は細い線でつなぐ。
  - メニューのボタンは縦幅を詰め、すっきりさせる。
  - 名前にフレーバーを入れる: 技術は「開発年（A.E.）式＋名前」（38式 誘導魚雷、42式改 荷電粒子砲、試製47式 偏向力場装甲）、機体は「型番＋名前」（F-38 アクィラ、W-21 ルクス）。
  - 戦闘画面のウィンドウ（時刻・任務・作戦概要・会話・結果・艦隊の名札・宙域の名前・艦隊一覧）は、左の太い縦線をやめ、四隅に細い L 字の括弧を置く形（案 B、ユーザー決定 2026-10-03。参考にした映像に近すぎたため）。名札はチーム色をうっすら敷き、左上と右下だけに括弧。艦隊の紋章（丸いアイコン）はそのまま。友軍（AI が動かす味方）の色は緑がかった青 #8fe8c0（案 B、ユーザー決定 2026-10-03）。
  - W.A.S. の姿は `docs/story.md` の「4. W.A.S.」。技術ツリーのアイコンは案 C（`docs/icons/was-c.svg`）。
- **索敵:** 見つけていない敵は見えず、攻撃もできない。
  - 視界はストレスがない程度に広めにする。偵察が要るのは必要な場面だけにする。
- **艦載機と W.A.S.:**
  - 射程内に敵が入ると自動で出撃する。出撃にはクールタイムと上限がある。
  - 燃料があるので帰還が必要。
  - 帰還すると、失った数の半分を予備から補充する。予備がなければ増えない。例: 1隊30機×3隊、収容120。
  - 艦載機は W.A.S. より射程が長い。
  - 艦載機は W.A.S. より当たりやすい（ユーザー決定 2026-10-03）。今の当たりやすさが研究を終えた最終形態で、研究前は艦の対空照準が低く、小型機にかなり当たらない。
  - 小型機は相手側の要塞を自分からは狙わず、母艦が要塞の射程の外なら外の敵、内なら内の敵だけを狙う。母艦に攻撃を命じた相手は優先し、母艦を移動させても、倒れるか別の攻撃を命じるまで狙い続ける。敵も同じ（ユーザー決定 2026-10-02）。
  - 空母系だけの打撃群は、攻撃のとき敵が発進距離（短いほう）の0.8倍に入ったら止まる。混ざった打撃群は艦砲の射程で止まり、空母系は隊形の最後尾に並ぶ（ユーザー決定 2026-10-02）。
  - 艦砲は、攻撃を命じた敵が射程内なら優先して撃つ（ユーザー決定 2026-10-02）。
  - 小型機は、敵の小型機を見つけたら艦より先に狙い、お互いの小型機がぶつかる所が前線になる。敵の小型機が攻めてくると、自分の母艦に近いものから迎え撃つ（前線が下がる）。母艦に攻撃を命じた相手はそれより先（ユーザー決定 2026-10-02）。
- **要塞カリュブディス（最初の要塞戦）:** 要塞から艦載機が迎撃に出る。装甲が75%を切ると第5 要塞近衛 エスカドラ、50%を切ると防空隊が自軍に近い隊から順に迎撃に出る（ユーザー決定 2026-10-02）。
  - 艦載機だけの戦闘母艦は、巡洋艦以下を相手の射程に入らずに攻撃できる。艦載機が当たりやすくなったので、母艦が少し被弾するのはよい（ユーザー決定 2026-10-03。前は「一方的に」）。空母系だけの打撃群は、敵がその射程に近づくと下がりながら戦い、艦載機に攻撃されている艦隊は遅くなる（ユーザー決定 2026-10-02）。命令優先のときは、攻撃を命じた相手からだけ距離を取る。ほかの敵が近づいても、攻撃中の場所や移動先から下がらない（ユーザー決定 2026-10-03）。
