# 天体とマップの作り方

第4節「デナリの盾」（2026-10-09〜10）で、資源衛星・岩くずの雲・民間区画・地表の砲台・段階のある作戦を作った。そのときに覚えたことを、次のマップ（第5節以降の衛星、ステーション、雲など）を作るときのためにまとめる。決まった仕様は `docs/spec.md`、第4節の数値と経緯は `docs/campaign.md`。

## 1. 座標と大きさの目安

- 戦場は x が東（+）、z が南（+）。北（火星側）は z がマイナス。高度は y（作戦データでは `alt`）。作戦データの位置は `[x, z]` と `alt` で書く。
- 第4節の大きさ: 衛星の半径30（ユーザー決定: 大きめ）、居住区の民間区画は半径18、展開は南の [0,110]、離脱点は [-100,100]、岩くずの雲は中心から 92〜110。
- 視点は作戦の `view:{target, dist, dir}`。`dist` 230 で全体が入る。
- 場所の名前（`sectors`）は平面に出る小さな名札。天体、居住区、港は `state.js` の `reset()` が自動で足す。

## 2. 天体（`op.body`）

### データ
```
body:{name, sub, r, lobe:{c:[x,y,z], r}, craterA, mine:{dir, a, depth, steps}, groove:{w, depth},
      blocks:[{name, sub, pos:[x,z], alt}], port:{name, sub, pos:[x,z], alt, r}}
```
- `blocks` は居住区。町はその方向のクレーターの底に建つ。`port` は宇宙港の輪（戦闘母艦の着陸点）。
- `lobe` はこぶ。半径 `r` の球を足す（ユーザーの画像2枚目の形）。`mine` は段々の露天掘り。`groove` は町どうしと鉱山を結ぶ溝（鉄道）。

### 形の作り方（`battle/scene.js` の `makeBodyShape`）
- 形は「中心からの向き d → 半径 R(d)」の式で表す。表面の高さはどこでも式で分かる（`bodyShape.R`、`bodySurface`）。艦を表面の外へ押し出す処理（`keepOffBody`）は、毎フレーム光線を飛ばさずに済む。
- 光線（`bodyHit`）を使うのは、砲台を岩の面に置くときだけ。置く1回だけなので重くない。
- R(d) の中身は上から順に:
  1. 押しつぶした楕円体（`sq`）に、なめらかな sin の凹凸をかける。
  2. こぶとの和（大きいほうの半径を取る）。
  3. 割れた平らな面（ランダムな向きの平面70枚で少しずつ削る）。ゴツゴツして見えるのはこれが一番効く。
  4. 細かいとがった凹凸。
  5. 小さなクレーターと岩の盛り上がり48個。町と鉱山の上には置かない。
  6. 町のクレーターと、段々の鉱山。
  7. 溝（大円に沿って削る）。クレーターの中は削らない。
- メッシュは `IcosahedronGeometry(1,56)` の頂点を R(d) まで動かす。`flatShading` の岩の色。

### 町・チューブ・港（`buildBody`）
- 町はクレーターの底に、小さな住居モジュールを 5×4 のゆるい格子で並べる。
- 低いところは丸いチューブ、上は橋だけでつなぐ（ユーザー決定）。窓の灯りを粒で足す。
- 溝がクレーターから出るところに、トンネルの口を置く。
- 町と町の間には細いチューブを2本、溝の横に通す。
  - 表面から0.45浮かせる。小さな穴の上は、前後2点の高いほうに合わせて水平に渡す。
  - 支柱で支える（ユーザー決定）。
- 鉱山には作業灯と機械、港には腕・台座・輪を置く。

### 気をつけること（失敗したこと）
- **Three.js r128 の `IcosahedronGeometry` の detail は分割数**。細かい溝やクレーターを出すには 50 以上が要る（2〜4 では角ばる）。
- **ハッシュの乱数を丸めた凹凸は段々（ブロック状）に見える**。sin の重ね合わせか、平面で削るほうがよい。
- **細かすぎる凹凸**（周波数30くらい）は、メッシュの細かさと干渉して縞になる。
- 溝をクレーターの中まで掘ると、町が穴に埋まる。
- 名前のぶつかり: `battle/*.js` は外側の名前を共有する。`scene` のような短い名前は `scene.js` のシーンとぶつかって、全部が止まる（`playScene` に改名した）。

## 3. 岩くずの雲（`op.debris`、`op.debrisTilt`）

- 球を重ねて塊にする（`[{pos:[x,z], alt, r}]`）。第4節では作戦データの中で関数で作っている。中心からの角度と距離を少しずつ変え、太さを始まりから先へ細くする。
- `debrisTilt` は東西の軸のまわりの傾き（度）。見た目の傾きで、各球の `alt` も同じ傾きで計算する。
- 見通し: 見る艦と見られる艦を結ぶ線が雲の球を通ると、見えない（`sim.js` の `debrisBlocks`）。20以内（`DEBRIS_NEAR`）なら見える。中の艦は速度0.75倍。雲に隠れた敵は、出るまで見えない（奇襲に使う）。
- 岩は `rock()` で作った、いびつな形4種類。色の薄い霞（`dustMat`）を重ねる。

**置き方でユーザーに言われたこと**
- まっすぐな「隕石帯」はだめ。地球の軌道上の衛星のそばに、まっすぐな帯がすぐ横にあるのは不自然。
- 採掘で出た砂利や鉱滓が、衛星を中心に弧を描いて巻く形にした（ユーザーが図に赤い線を描いた）。
- 距離は「離れすぎ」「もっと近く」を3回やりとりして、185 → 170 → 140 → 110 になった。最初は近めに置くほうがよい。
- 傾きは30〜40度。平面の下に出てもよい。

## 4. 民間区画（`op.civil`）

- 居住区のまわり半径 `r` の球。
- 被害（`civHit`）が出るのは次のとき。上限 `cap` を超えると負け。
  - こちら（駐屯隊と本軍）の砲が区画の中の敵艦を撃ったとき（打撃1につき `perDmg` 人、艦載機は `perCraft` 人）。
  - 区画の中で敵艦が沈んだとき（`perSink` 人）。
  - 敵の `ai:'raid'` が居住区を撃ったとき（`perRaid` 人）。
- **地表の砲台（`fixed`）は撃っても被害なし**（岩の上。ユーザー決定 2026-10-10）。
- 本軍（友軍）は区画の中の艦を撃たない（`fireTargetOf` の ok、`allyAI` の foes）。砲台は撃つ。
- 自軍の艦載機は、命令がなければ区画の中の艦を狙わない（`craftTarget`）。
- 区画の縁は琥珀色のフレネルの殻と輪で見せる（`zoneMat`）。

**学んだこと**: 「味方は区画の中を撃たない」と「敵は区画の中に入れる」が重なると、敵が区画に居座り、味方は棒立ちで沈む。敵に `keepOut:true` を付けて区画の縁へ押し出すと、撃ち合いになる（`keepOutOfZones`）。守備隊がわざと区画に逃げ込むとき（`ai:'shield'`）は付けない。これは物語の「住民を盾にする」の場面。

## 5. 地表の砲台

- 作戦の敵に `type:'aa', speed:0, fixed:true` で置く。
- `reset()` で `bodyHit` を使い、岩の面に付ける。`s.base` と `s.up` に、置いた点と面の向きを持つ。
- 描画は `loop.js` の `groundGun`。付け根は面にぴったり付ける（ユーザー決定）。
- 小さめに作る（scale 1.1）。形は `shapes.js` の `SHAPES.aa`。
- 対空照準を高くすると（`aa:9`）、艦載機をよく落とす役になる。

## 6. 段階のある作戦の部品（第4節）

### 作戦の時計
- `clockScale`: その作戦だけ時計の速さを変える（第4節は0.5）。

### 戦闘母艦の流れ（`op.carrier`）
- 着陸: 港の輪で止まる → 占領（`landPhase`）。
- 作戦変更（`evac`）: 友軍の隊が全滅、戦艦の隊（`line`）が `lost` の割合だけ沈む、または `max` 分たったとき。ここで収容が始まる。
- 収容: 1時間に `rate` 人、上限は `people` 人。
- 切り上げ（`cut`）: 戦艦の隊が `sunk` の割合だけ沈むか、母艦の耐久が `carrier` の割合を切ったとき。満員でも終わる。そのあと撤退で、離脱点に着けば勝ち。
- 乗せた人数で遅くなる（`slowFull`）。
- 着陸と作戦変更を起点にした出来事（`landEvents`、`evacEvents`）。
- 場面の会話（`evacLogs`、`doneLogs`、`fullLogs`）は、`playScene` で戦闘を止めて見せる。通知だけだと3件しか残らず、大事な台詞がすぐ消える。
- 会話の中の `{boarded}`（乗せた人数）と `{remain}`（残った住民）は、表示するときに埋まる（`fillText`）。

### 出来事で隊の動きを変える
`events` の `ai:{fleets, ai, leash, spare, keepOut}` で、名前を挙げた隊の動きを変えられる。友軍は `mode` が変わる。

### 動きの種類
| 名前 | 動き |
|---|---|
| `hunt` | 見えている敵をどこまでも追う |
| `guard` | 持ち場から `leash` 以内だけ相手にする |
| `shield` | 損害が出ると、受け持ちの居住区のそばへ逃げ込む |
| `raid` | 居住区を撃つ。間に艦がいれば、その艦を先に撃つ |
| `protect`（友軍） | 受け持ち（`protect:'carrier'` / `'block:N'`）と、それを狙う敵、または近くの敵の真ん中との間に立つ。区画の外に立つ。向きはゆっくり変える |
| `leave`（友軍） | 母艦を前と横から送って離脱点へ |
| `hold:true`（友軍） | 相手がいなくなったら、その場で止まる（持ち場へ戻らない）。そのあと砲台を壊しに行く |
| `prey:'ally'` | 友軍を先に狙う |
| `prey:'carrier'` | 母艦を、区画の外の届く位置から、時間の4分の1だけ撃つ |
| `spare:['carrier']` | 母艦を狙わない |
| `letGo` / `ace` | 撤退になると追わない。小型機も戻す |

### つまずいたこと
- **覚えていた攻撃目標（`f.strike`）を消し忘れる**と、「もう撃たない」にしたあとも、前の目標を撃ち続ける。
- **`prey` の一覧が `spare` の除外を素通りしていた**。狙わない相手を足し直すときは、`spares()` を通す。
- **一番近いものを守らせると偏る**（4隊が同じ居住区へ行った）。受け持ちはデータで決める。
- 友軍が相手を失うと持ち場（出撃位置）へ戻り、「後ろに下がった」と言われた。`hold` を付ける。

## 7. 確かめ方（`tools/`）

| コマンド | 中身 | かかる時間 |
|---|---|---|
| `node tools/body-shots.cjs <作戦id> <出力フォルダ> <向き...>` | 天体の見本の画像を撮る。向きは `top` `south` `east` `mine` `townN` `linkNM` | 1分ほど |
| `node tools/denali-sim.cjs a` / `b` | 第4節を最後まで早送りし、時刻ごとの被害、本軍の残り、乗せた人数、勝ち負けを出す。a は駐屯隊が攻める、b は逃がす | 3〜4分 |

- 出力はスクラッチパッドに置く（リポジトリに画像を足さない）。
- 2本を並べて走らせると、時間を節約できる。
- 釣り合わせは「戦艦の7割が沈む」「約5,000人」のような、物語の数字を早送りで合わせる。
  - 効くつまみ: 友軍の耐久、収容の速さ、切り上げの割合、敵の数と出る時刻。
  - a と b の両方で、母艦が離脱できることを確かめる。
- 1つの動きを深く見たいときは、着陸直後から始める短い診断を書くと速い。テストの書き方（`tests/smoke.cjs` のデナリの部分）が手本になる。

## 8. ユーザーの好み（見た目と配置）

- 見た目は、必ず見本の画像を見せて「ok」をもらってから入れる。前後の比較を並べると返事が早い。
- 岩はいびつで、ゴツゴツ（割れた面、クレーター、盛り上がり）。なめらかな球はだめ。
- 建物は小さく、数を多く。丸いチューブでつなぎ、橋は上だけ。砲台も小さく、付け根は地面にぴったり。
- 町はクレーターの中にあり、溝と内部のトンネル（鉄道）でつながる。一か所は露天掘りの鉱山。
- 配置は世界設定に照らして自然に（地球の軌道上か、月より遠いか）。距離は近めから始める。
- サブエージェントに「ストラテジーゲームとして適切か」を評価させると、問題（偏り、棒立ち、台詞と動きのずれ）が具体的に出る。直す前に、ユーザーの決定と食い違う点を選択肢にして聞く。
