# 地上・海上再設計の最終確認

2026-11-11。作業表の段階6〜9を航空・広域・操作案内まで統合。段階1〜5はPR #382〜#386でmainへ反映済み。最終統合の全作戦CI・マージ状態は `claude/ground-integration` のPRを正とする。

## 実装した内容

- 海上のみ高速艇／イージス艦へ統合、bb戦艦と揚陸艦は別判定。旧typeと宇宙艦表を維持。直接照準の地平線と海面への間接砲撃を接続。
- 戦闘機は仮2km・前方半角36度で継続旋回・追尾。支援機は高高度で地点／範囲へ自動進入し、実位置・速度・高度で無誘導投下を再計算する。停止・帰投・予約・Undoは未発射分を保持し、発射済み弾を復活させない。
- 150×100km／300×200kmの別設計の隠し検証場を追加。演習48×36kmは維持。地形と道路は設計図から生成し、寸法・描画格子・物理を統一。
- 可射計算をフレームへ分散。通常速度の安全な直線は最短コストを検証してA*を省く。自動対空は装填中の全目標への射線再探索を省き、実射時に厳密に確認する。
- 現在の兵科・高度で攻撃能力を確認し、無効な攻撃で予約・Undoを消さない。混成は対応隊だけに命令。チュートリアルと操作案内を更新。SVG・配置・ボタン寸法は変更しない。

## 広域の実測

最終統合版で、53.3kmの安全な直線経路は約3.4ms、143.1kmは約3.5ms（このMacで各1回のCPU実測）。修正前は約132.7ms／1095.5msだった。可射計算は総計約40〜51msを11〜14回へ分散し、1回最大約4.2〜6.5ms。3.5msは協調予算で、1個の計算や確保を途中で中断する厳密な上限ではない。

両広域ともメッシュ300×200、地表2048×1366px、fog192×128、占領膜480×320、ロケット50kmを実画面確認。森770／1375の代表モデルと380／480棟の局在を設計どおり生成。旧演習48×36・格子192と、宇宙へ戻る際の解除も確認。

これはCPU処理時間でFPSではない。ネイティブrequestAnimationFrame間隔の採取は終了せず中止したため、FPSの数値は報告しない。複雑な障害経路は従来の探索を使う。全条件の処理時間保証とは扱わない。
