作成: 2026-10-02。**実装はまだ**（ユーザー決定 2026-10-02: 「前に作った要塞攻略戦はチュートリアルにする。今は実装しなくていい」）。
ここに書いた中身は Claude の叩き台で、名前・数値・順番はすべて仮。

## 1. 決まったこと

- 試作の作戦「要塞カリュブディス攻略戦」（`data/operations.js` の `charybdis`。出撃画面のクイック出撃もこれ）を、操作を覚えるためのチュートリアルにする。
- 以前のロードマップでは「第一章の最初の作戦に操作説明を溶け込ませる」としていた。これをやめて、操作はチュートリアルで覚える形に変える。ネオ信濃奇襲の通信の案内（ハッダード曹長）は、短い補足にとどめる。

## 2. 今の要塞攻略戦にあるもの

チュートリアルの材料は、ほとんどそろっている。

| 要素 | 今の中身 | チュートリアルで教えられること |
|---|---|---|
| 自軍 | 突撃艇隊（コルベット24）、戦隊2つ（巡洋艦10ずつ）、機動部隊（戦闘母艦3、艦載機120） | 艦隊の選択、艦種の違い、艦載機の自動出撃 |
| 敵 | 防空4隊（東西南北）、第5 要塞近衛 エスカドラ、要塞（装甲3200、射程46） | 攻撃、各個撃破、射程の外から近づく |
| 索敵 | 防空隊は視界に入るまで見えない | 見えない敵、視界の輪、撃つと見つかる |
| 増援 | 900分後（戦闘の60秒後）に北から第6 本国増援 エスカドラ | 時刻の出来事、追撃してくる敵への対処 |
| 勝敗 | 要塞の装甲を0にすれば勝ち、全滅で負け | 任務欄の見方 |

## 3. 設定上の扱い（案）

日付が「宙暦0412」のままで、キャンペーンの年表（A.E.）と合っていない。そこで、本編の戦いではなく**演習**として扱う案を出す。

- **案A: 士官学校の演習シミュレーション（ユーザー決定 2026-10-02）**
  - A.E. 44（開戦の前年）。主人公ミナセが士官候補生として受ける、艦隊指揮の卒業演習。
  - 要塞カリュブディスは、演習用に作られた架空の要塞。教官が通信で案内する。
  - 本編の前日譚として自然につながる。日付は「演習記録 A.E. 44」などにする。
- **案B: 本編の後半の実戦**
  - 第五章（火星）で、本物のカリュブディスを攻める。チュートリアル版はその予告になる。
  - チュートリアルと本編で同じ敵を2回攻めることになる。

## 4. 教える順番（案）

1段ずつ、プレイヤーがその操作をしたら次へ進む。どの段も、画面の端の通信ログ（たためる）で1〜2行だけ案内し、ポップアップは使わない。「とばす」でいつでも普通の戦闘に移れる。

| 段 | 教えること | 進む条件 | 使う操作 |
|---|---|---|---|
| 1 | 視点 | 視点を回すか、ボタンで切り替える | ドラッグ、ホイール、斜め/真上/真横、V、WASD、十字キー |
| 2 | 選んで動かす | 艦隊を選び、移動させる | クリック、1〜9 キー、右クリック |
| 3 | 高度 | 高度を変えて動かす | 左の高度バー、Q/E |
| 4 | 索敵 | 防空隊を視界に入れる | 視界の輪、見えない敵、最終確認位置 |
| 5 | 攻撃 | 防空隊を1つ攻撃する | 敵のクリック →「攻撃」「ここへ移動」 |
| 6 | 予約指示 | 経由地か攻撃を予約する | Shift+クリック |
| 7 | 艦載機 | 機動部隊の艦載機が出撃する | 自動出撃、燃料、帰還 |
| 8 | 交戦と回避 | 回避に切り替える | 高度バーの下のボタン、R |
| 9 | 時間 | 一時停止か倍速を使う | Space、停止・1×・2×・4× |
| 10 | 仕上げ | 要塞の装甲を0にする | 任務欄、各個撃破、増援への対処 |

- 戦区軍（G キー、ドラッグでの出し入れ、速度同期）は、編成を覚えたあとで使うので、チュートリアルの後半か別の短い演習に回す（仮）。
- 最初の数段は、敵が動かない（または戦闘を止めた）状態で練習できるようにする。

## 5. 作るもの

| 仕組み | 中身 |
|---|---|
| 条件で進む出来事 | 今の「時刻の出来事」に加えて、「艦隊を選んだ」「移動させた」「高度を変えた」「敵を見つけた」などの条件で次の案内を出す |
| 段の進み具合 | 左上の任務欄に「チュートリアル 3/10　高度」のように出す |
| 敵を待たせる | 段が進むまで敵の AI と増援を止めておく |
| メニューの入口 | タイトルメニューに「チュートリアル」を置く。初めて起動したときに勧める（押し付けない） |
| クリア記録 | 終えたかどうかを保存し、メニューに印を付ける |
| 作戦データ | `charybdis` を演習用に直す（日付、会話、教官の通信、段ごとの案内文） |
