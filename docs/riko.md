# リコ軍曹（人物と話し方）

ゲームの会話と通信をひとりで受け持つ、女性のオペレーター。台詞を書く・直すときは、まずこのファイルを読む。ここに書いたことはユーザーの指示（2026-11-06）からまとめたもの。指示が増えたら、ここを直して育てる。

## 決まったこと（ユーザー決定 2026-11-06）

- 名前はリコ、階級は軍曹。話し手の表示は「リコ軍曹」。前は「ハッダード曹長」だった人物を女性にし、名前を変えた。
- 新人の尉官ミナセの副官。最初の登場（演習のチュートリアルの段1）で、副官として配属されたと自己紹介する: 「本日付で、少尉の副官に配属されました。リコ軍曹です。……よろしくお願いします」。
- 作戦の前後の会話と戦闘中の通信は、すべて彼女の通信の形。ほかの人物はほとんど話さず、命令や知らせは彼女が取り次ぐ（`docs/spec.md`「会話の形」）。ミナセも話さない。
- チュートリアルの案内（演習・準備画面）も彼女が言う。
- 口調の土台は「丁寧で短く、感情は間だけ」。その上で、ユーザーが例に書いた雰囲気（下の「手本」）に合わせる。

## 手本（ユーザーが書いた例。第1節、司令室がやられたとき）

> 司令室…応答なし、状況を照会します、お待ちを……。どうやら敵の砲撃が司令室ごと貫いたみたいです。指揮系統システムが最上位階級を検索中です。……結果出ました。……少尉指揮を取ってください。

## 話し方の型

1. **手順を口に出す。** 状況 → していること（照会します・照合します・解析します・検索中です・計算しました）→ 待つ間（お待ちを……）→ 結果（結果、出ました／識別、出ました）→ 読み取り → 頼み。全部の行に入れるのではなく、知らせが重いとき・確かめが要るときに使う。
2. **推測は柔らかく。** 「どうやら〜みたいです」「〜みたいです」「〜のようです」。確かめた事実だけを言い切る。確かめられないときは「確かめようがありません」。
3. **丁寧語。** です・ます。頼みは「〜してください」「お待ちを」。上官は「少尉」（第3節から「中尉」）と呼ぶ。
4. **感情は間で出す。** 「……」で言いよどむ、言葉を切る。「！」は使わない。叫ばない。急ぐときは文を短く切る（「右前方にもう1隊」）。
5. **数と位置が先、意味があと。** 方角・高さ・隊の数を言ってから、狙いや読み（「船団の横腹を狙っているみたいです」）。
6. **取り次ぎは引用で分け、「〜とのことです」で結ぶ**（ユーザーのコメント 2026-11-06「こことかは、とのことです。みたいな口調で」）。「本軍から入電です。読み上げます。『…』」「白鷺から。……『少尉、頼みます』とのことです」「本軍から。撃て、とのことです」「敵の通信を拾いました。……アルバレス隊です。『…』」。「〜と。」で切らない。伝え聞きは「〜そうです」でもよい。戦闘中の通信（全体が「」で囲まれる）の中の引用は『』、会話の中の引用は「」。人の名前は出さず、所属（本軍・総基地・ナイル司令部・白鷺・デナリ管制室）で呼ぶ。
7. **よく使う言葉。** 反応、照会、照合、識別、解析、検索、計算、確認、入電、傍受、通信を拾う、読み上げる、指揮系統システム。
8. **避けること。** 乱暴な語尾（〜もんです、〜ってことです、ばれます）、男っぽい言い回し、強い女言葉（〜わ、〜のよ）、長い説明、冗談の連発。

## 節ごとに知っていること（ユーザー決定 2026-11-06）

- **第1節**: W.A.S. も突撃揚陸艦も、まだ誰も知らない。「登録にない艦」「人の形をしています」と見たままを言い、名前で呼ばない。作戦を選ぶ画面の敵戦力も「未確認の艦」。
- **第2節**: どちらも「新型」と呼ぶ（「新型の大型艦」「新型の人型」）。どの記録とも照合できなかった、と話す。
- **第3節から**: ナイルで合流し、司令部から情報をもらった（出撃前の会話で「人型は W.A.S.、武装装甲化外骨格。運んでくる大型艦は、突撃揚陸艦」）。これ以降は W.A.S.・突撃揚陸艦（揚陸艦）と呼ぶ。
- **アルバレス隊**: 傍受でだけ知っていた敵。第3節でネオ信濃の隊と結びつけ、第4節で第6 巡洋護衛を数分で沈めた強さと、赤い隊長機の一撃の重さを知る。勝ったあと「惑星先進装備開発局の部隊。機体も腕も別物」。第5節で工廠の解析（赤い隊の機体は試作機）。第6節でローウェルへ戻ると聞き「正直、助かります」。

## 考え方（性格）

- 確かめてから言う。機械と手順を信じ、わからないことはわからないと言う。
- 自分の気持ちより、まず状況を伝える。それでも人の生き死にには間が空く（「第6 巡洋護衛、反応なし。……全滅です」）。
- 新人の上官を支える立場。操作の案内はするが、判断は上官に返す（「指揮を取ってください」）。
- 皮肉や感想は、言っても一言だけ（「……皮肉ですね」）。
